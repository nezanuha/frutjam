CSS 専用の Tailwind CSS UI ライブラリである Frutjam を数分でインストールします。 2 つのインポート、ゼロ JavaScript、すぐに使える WCAG アクセス可能なコンポーネント。 Django、HTMX、Laravel、React、およびあらゆる Tailwind CSS v4 プロジェクトで動作します。

## Tailwind CSS プロジェクトに Frutjam UI ライブラリをインストールするにはどうすればよいですか?

動作していることを確認してください [追い風 CSS](https://tailwindcss.com/docs/installation/using-vite) プロジェクトがインストールされているだけでなく、 [ノード](https://nodejs.org/en/download) および NPM をコンピュータ上にインストールします。 Frutjam は Tailwind バージョン 4 で動作します。

### 次のコマンドを実行して、frutjam をノード パッケージとしてインストールします。

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

フルーツジャムを追加 `input.css` を使用して `@plugin` 指令：

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

## Tailwind なし: UnoCSS、Vite、Astro、またはプレーン CSS

Frutjam は Tailwind を使用して構築されていますが、コンポーネントはカスタム プロパティを読み取る通常の CSS にコンパイルされます。プロジェクトで UnoCSS を使用する場合、またはユーティリティ エンジンをまったく使用しない場合は、プラグインの代わりにスタイルシートをインポートします。

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

それが全体のセットアップです。すべてのコンポーネントクラスが機能し、テーマが切り替わります `data-theme` いつものように、他には何も必要ありません。これは gzip 圧縮された 30 KB で、基本スタイル、テーマ、および 65 以上のすべてのコンポーネントが含まれています。

代わりに、必要なものだけを取り込みます。

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

または、ビルドステップをまったく行わない場合:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## JavaScript と React: オプション、必須ではありません

Frutjam は **ネイティブ ファーストかつ CSS ファースト**です。ボタン、バッジ、カード、フォーム、アラートなどのコンポーネントの大部分は、純粋な HTML と CSS で動作し、JavaScript は必要ありません。次のようなネイティブ HTML 要素 `<dialog>`, `<details>`、 そして `<input type="checkbox">` ブラウザーがすでにサポートしている対話性を処理します。すべてのコンポーネントはすぐに WCAG AA にアクセスでき、Django、HTMX、Laravel、React、Next.js、およびあらゆるスタックで動作します。

少数のコンポーネントには、ネイティブ HTML に相当するものがありません (トースト通知、コンボボックス フィルタリング、カルーセル コントロール)。そのような場合にのみ、Frutjam には軽量のオプション ヘルパーが付属しています。

### バニラ JS: `frutjam/js`

必要なコンポーネント用のフレームワークに依存しない ES モジュール ヘルパー。フレームワークは必要なく、任意の DOM 要素に接続できます。

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### 反応フック: `frutjam/react`

同じネイティブ DOM 呼び出しを囲む Thin React ラッパー。各フックは、 `ref` 要素とそれを制御するメソッドにアタッチするだけで、React 自体以外の追加の依存関係はありません。

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

利用可能な用途: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.

### CDN の使用

frutjam UI ライブラリの CDN バージョンを使用すると、ローカル設定なしで迅速かつ簡単に統合できます。 frutjam のこの CDN バージョンは、運用環境ではなく、開発目的でのみ使用してください。

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>
