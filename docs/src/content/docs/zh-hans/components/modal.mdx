CSS-only Tailwind CSS modal使用原生 `<dialog>` 元素。响应大小、背景和焦点陷阱。没有用于基本用途的JavaScript。WCAG AA可访问，适用于Django、HTMX、Laravel、React和任何堆栈。

模态组件在聚焦的叠加窗口中显示重要信息或请求用户操作。基于语义HTML对话框元素，模态支持动画、可自定义的定位和背景叠加。Frutjam模式系统通过键盘导航和陷阱对焦完全可访问，使其成为确认、表单和提醒对话的理想选择。

仅限CSS ，无需JavaScript。WCAG AA可访问且框架不可知—适用于Django、HTMX、Laravel、React和任何堆栈。

## 基本用法

将唯一ID添加到 `<dialog id="myModal">` HTML元素，然后使用JavaScript中的该ID调用 `myModal.showModal()` 打开模态框， `myModal.close()` 关闭此弹窗

<Snippet>

```html
<dialog class="modal modal-center lg:modal-middle modal-slide-end lg:modal-slide-down" id="toggleModal">
  <div class="modal-content">
    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Dialog modal</div>
      <button type="button" class="btn btn-xs btn-square btn-rounded btn-ghost" onclick="toggleModal.close()">
        <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
          <path d="M18 6 6 18"></path>
          <path d="m6 6 12 12"></path>
        </svg>
      </button>
    </div>
    <div class="divider my-3"></div>
    <p class="para">Press Esc key or close button to close the modal</p>
  </div>
  <button type="button" class="modal-backdrop" onclick="toggleModal.close()">Close Modal via Backdrop</button>
</dialog>
<button type="button" class="btn btn-xs" onclick="toggleModal.showModal()">Show Modal</button>
```

## 模态幻灯片动画

使用以下定向效用类从顶部、底部、开始（ LTR中向左， RTL中向右）或结束（ LTR中向右， RTL中向左）平滑地滑入和滑出： `modal-slide-top`, `modal-slide-bottom`, `modal-slide-start`和 `modal-slide-end` 在模态组件中。这些动画通过使用基于模态位置的动态转换来改善用户体验。

### 模态幻灯片从开始（水平）

添加 `modal-slide-start` 实用程序从开始侧水平滑动模态；在从左到右（ LTR ）布局中，它从左边出现，在从右到左（ RTL ）布局中从右边出现。

<Snippet>

```html
<dialog class="modal modal-center lg:modal-middle modal-slide-start" id="slideStartModal">
  <div class="modal-content">
    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Slide start modal</div>
      <button type="button" class="btn btn-xs btn-square btn-rounded btn-ghost" onclick="slideStartModal.close()">
        <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
          <path d="M18 6 6 18"></path>
          <path d="m6 6 12 12"></path>
        </svg>
      </button>
    </div>
    <div class="divider my-3"></div>
    <p class="para">Horizontally slides the modal in and out from the start side.</p>
  </div>
</dialog>
<button type="button" class="btn btn-xs" onclick="slideStartModal.showModal()">Show Modal</button>
```

</Snippet>

## 模态放置

默认情况下，模态组件位于屏幕的中心，但可以根据使用情况使用水平类将其放置 `modal-start`, `modal-center`，或 `modal-end`和垂直类 `modal-top`, `modal-middle`，或 `modal-bottom`。放置的设计考虑了RTL和LTR的兼容性，使模态能够适应不同的语言方向和布局。

使用 `modal-start`, `modal-center`，或 `modal-end` 用于水平放置和 `modal-top`, `modal-middle`，或 `modal-bottom` 用于垂直放置。这些类应用于模态组件。

    </div>

      Changing
      <code>dir="rtl"</code>
      in the HTML will have no effect on the modal's the position because the layout is controlled by utility classes:

      for the LTR variant and
      <code>modal-start</code>
      for the RTL variant.
    </p>
  </div>

  </button>
