Tylko CSS Maska Tailwind CSS do przycinania obrazów w kształty — okrąg, wiewiórka, serce, sześciokąt i inne. Dostępny WCAG AA, współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

Komponenty maski nakładają geometryczne lub niestandardowe kształty na obrazy i elementy, tworząc atrakcyjne wizualnie i niepowtarzalne projekty. Zbudowane na podstawie właściwości masek CSS, maski umożliwiają kreatywne kadrowanie obrazu i dekoracyjną stylizację. System masek Frutjam obsługuje wiele kształtów — idealnie nadaje się do ramek awatarów, prezentacji w galeriach i układów artystycznych.

Tylko CSS, nie wymaga JavaScript. Dostępny w WCAG AA i niezależny od frameworka — współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

## Podstawowe użycie

Utwórz prostą okrągłą maskę z gradientowym tłem.

<Snippet>

```html
<div class="mask mask-circle h-24 w-24">
  <div class="w-full h-full bg-linear-to-br from-primary to-secondary"></div>
</div>
```

```jsx
<div className="mask mask-circle h-24 w-24">
  <div className="w-full h-full bg-linear-to-br from-primary to-secondary"></div>
</div>
```

</Snippet>
