Zainstaluj Frutjam, bibliotekę CSS Tailwind CSS UI w ciągu kilku minut. Dwa importy, zero komponentów JavaScript, WCAG dostępnych po wyjęciu z pudełka. Współpracuje z projektami Django, HTMX, Laravel, React i dowolnym projektem Tailwind CSS v4.

## Zainstaluj

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Następnie wybierz poniższy wiersz, który pasuje do Twojej konfiguracji. Każdy z nich daje te same komponenty.

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Twoja konfiguracja | Co dodać | Statki |
| --- | --- | --- |
| [Tylny wiatr CSS v4](#tailwind-css-v4) | `@plugin "frutjam";` | tylko to, czego używasz |
| [UnoCSS](#unocss) | `presetFrutjam()` | tylko to, czego używasz |
| [Vite, Astro, Rails, zwykły CSS](#no-utility-engine) | `import 'frutjam/css'` | wszystkie komponenty, 30 KB gzipped |
| [Brak kroku kompilacji](#no-build-step) | n `<link>` etykieta | Wszystkie komponenty |

</DocTable>

## Tylny wiatr CSS v4

Potrzebujesz działającego [Tylny wiatr CSS](https://tailwindcss.com/docs/installation/using-vite) projektu, plus [Węzeł](https://nodejs.org/en/download) i npm. Frutjam wymaga Tailwind 4.

Dodaj Frutjam do swojego `input.css` z nastawioną `@plugin` Dyrektywa:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

Na tym polega cała konfiguracja. Wszystkie ponad 65 komponentów są dostępne natychmiast, a Tailwind wysyła tylko te, których używa Twój znacznik.

## UnoCSS

Frutjam wysyła ustawienie wstępne, więc UnoCSS generuje tylko komponenty, których używasz, tak samo jak wtyczka Tailwind.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Każda klasa działa tak, jak w Tailwind, podobnie jak warianty:

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

Dodaj `presetAttributify()` a nazwa komponentu staje się atrybutem, przy czym każda wartość traktowana jest jako jej wariant:

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

Druga linia wymaga `transformerVariantGroup()` dla składni nawiasów. Zauważ, że atrybut taki jak `btn` nie jest prawidłowym kodem HTML, więc jeśli zweryfikujesz swoje znaczniki, użyj formularza klasy lub UnoCSS `un-` prefiks

### Opcje

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Opcja | Domyślna | Cel |
| --- | --- | --- |
| `preflight` | `true` | Emituje tokeny Frutjam, resetuje i motywy. Ustaw na `false` jeśli już importujesz `frutjam/css/base`  siebie.  |
| `prefix` | `''` | Pasuje do wtyczki Tailwind `prefix`Więc, `'fj'` daje ci: `fj-btn` i `fj-btn="error"`. |
| `layer` | `'frutjam'` | Warstwa kaskadowa, do której emitowane są komponenty. Sortuje poniżej narzędzi, więc narzędzie zawsze wygrywa z komponentem bez względu na kolejność ustawień wstępnych. |

</DocTable>

### Komponent łącza wymaga jednej linii konfiguracji

Smakołyki UnoCSS `link` jako wariant, dla CSS `:link` pseudoklasy, a jej domyślnymi separatorami są m.in. `-`A więc  `link-2xl` otrzymuje brzmienie „`2xl`, gdy nie jest odwiedzany ”, a nie jako nazwa klasy, i nic nie jest generowane. Wpływa tylko na ten komponent i tylko `link-*` Modyfikacje:

Każ UnoCSS dzielić się tylko na dwukropki:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Lub użyj prefiksu, który stawia coś innego niż `link` z przodu imienia:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

Każdy inny komponent pozostaje nienaruszony. `link` jest jedyną z 57, której nazwa zderza się z pseudoklasą.

## Brak silnika użytkowego

Frutjam jest zbudowany z Tailwind, ale komponenty kompilują się ze zwykłym CSS, który odczytuje niestandardowe właściwości. Jeśli Twój projekt w ogóle nie używa silnika narzędziowego, zaimportuj arkusz stylów zamiast wtyczki:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Na tym polega cała konfiguracja. Każda klasa komponentów działa, motywy przełączają się za pomocą `data-theme` jak zwykle i nic więcej nie jest wymagane. Ma 30 KB gzip i zawiera podstawowe style, zarówno motywy, jak i wszystkie ponad 65 komponentów.

Zamiast tego wybierz tylko to, czego potrzebujesz:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

Lub w ogóle bez etapu kompilacji:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## Brak kroku kompilacji

Wrzuć tag i zacznij pisać znaczniki. Użyj go do prototypu lub strony, której nie budujesz, nie do produkcji, ponieważ dostarcza każdy komponent.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

Aby eksperymentować z narzędziami Tailwind na tej samej stronie, dodaj do niej przeglądarkę Tailwind:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript i React: opcjonalne, niewymagane

Frutjam jest **native-first i CSS-first**. Zdecydowana większość komponentów: przyciski, odznaki, karty, formularze, alerty i nie tylko: praca z czystym HTML i CSS, zero potrzeby JavaScript. Natywne elementy HTML, takie jak `<dialog>`, `<details>`prób wykorzystywania naszych usług do nielegalnej działalności, a także o `<input type="checkbox">` obsługują interaktywność tam, gdzie przeglądarki już ją obsługują. Wszystkie komponenty są WCAG AA dostępne od ręki i współpracują z Django, HTMX, Laravel, React, Next.js i dowolnym stosem.

Niewielka liczba komponentów nie ma natywnego odpowiednika HTML (powiadomienia o tostach, filtrowanie pola kombi, kontrolki karuzeli). Tylko w takich przypadkach Frutjam wysyła lekkich, opcjonalnych pomocników.

### Vanilla JS: `frutjam/js`

Framework-agnostic ES module helpers for the components that need them. Przyłącz do dowolnego elementu DOM, nie jest wymagana struktura.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### React Hooks: `frutjam/react`

Cienkie owijki React wokół tych samych rodzimych wywołań DOM. Każdy haczyk zwraca `ref` dołączasz do elementu i metod jego kontrolowania, żadnych dodatkowych zależności poza samą Reakcją.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Dostępne dla: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
