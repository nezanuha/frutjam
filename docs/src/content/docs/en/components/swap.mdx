CSS-only Tailwind CSS swap for toggling between two elements. Flip, rotate, and fade animations, no JavaScript. WCAG AA accessible, works with Django, HTMX, Laravel, React, and any stack.

Swap components toggle between two content states with smooth animations in response to user interaction. Built with semantic HTML and CSS transitions, swaps enable elegant state changes without JavaScript. The Frutjam swap system supports multiple animation styles—ideal for theme toggles, mode switches, loading states, and interactive illustrations.

CSS-only, no JavaScript required. WCAG AA accessible and framework-agnostic — works with Django, HTMX, Laravel, React, and any stack.

<DocTable wrapper="overflow-y-auto max-h-72" table="table table-sm not-prose">

| Class | Type | Description |
| --- | --- | --- |
| swap | <span class="badge badge-xs">Base</span> | Checkbox-driven two-state toggle wrapper |
| swap-rotate | <span class="badge badge-xs badge-success badge-soft">Style</span> | Rotates between states |
| swap-flip | <span class="badge badge-xs badge-success badge-soft">Style</span> | Flips between states with a 3D effect |

</DocTable>

## Basic Usage

Create a simple swap with emoji or text content using a checkbox to toggle states.

<Snippet>

```html
<label class="swap">
  <input type="checkbox" />
  <div class="swap-on">☀️</div>
  <div class="swap-off">🌙</div>
</label>
```

```jsx
<label className="swap">
  <input type="checkbox" />
  <div className="swap-on">☀️</div>
  <div className="swap-off">🌙</div>
</label>
```

</Snippet>
