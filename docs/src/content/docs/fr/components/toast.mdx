Toast CSS Tailwind uniquement CSS pour le positionnement des notifications : placement en haut, en bas, au début, à la fin et au centre. Pas de JavaScript pour la mise en page. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants Toast affichent des notifications brèves et non intrusives positionnées sur les bords de l'écran. Construits avec des composants de positionnement et d'alerte fixes, les toasts communiquent des commentaires du système tels que des confirmations de réussite, des messages d'erreur ou des mises à jour de statut. Le système de toast Frutjam prend en charge six positions de placement, idéales pour les soumissions de formulaires, les opérations asynchrones et les notifications en temps réel.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

## Utilisation de base

<Snippet>

```html
<div class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>
