Menu vertikal Tailwind CSS khusus CSS untuk daftar navigasi. Status item aktif, nonaktif, dan ikon. Varian ukuran. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen menu menampilkan daftar tindakan atau opsi navigasi yang terorganisir. Dibangun dengan daftar HTML semantik dan elemen tautan, sistem menu Frutjam mendukung tata letak vertikal dan horizontal, menu bersarang, ikon, dan status aktif. Dapat diakses sepenuhnya dengan navigasi keyboard, menu terintegrasi secara mulus dengan dropdown, sidebar, dan pola navigasi kontekstual.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
