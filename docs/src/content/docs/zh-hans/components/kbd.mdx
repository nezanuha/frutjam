仅 CSS Tailwind CSS kbd 组件，用于显示键盘快捷键和组合键。尺寸变体。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

键盘按键组件直观地表示键盘输入，对于记录快捷键、热键和键盘导航很有用。 kbd 元素采用语义 HTML 构建，传达用户操作和交互模式。 Frutjam kbd 系统支持多种尺寸和样式，非常适合快捷方式文档、教程覆盖和键盘指南。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

## 基本用法

<Snippet>

```html
<kbd class="kbd">A</kbd>
<kbd class="kbd">B</kbd>
<kbd class="kbd">C</kbd>
```

```jsx
<kbd className="kbd">A</kbd>
<kbd className="kbd">B</kbd>
<kbd className="kbd">C</kbd>
```

</Snippet>
