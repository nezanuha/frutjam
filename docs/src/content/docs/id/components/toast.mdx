CSS - only Tailwind CSS bersulang untuk posisi notifikasi: penempatan atas, bawah, awal, akhir, dan tengah. Tidak ada JavaScript untuk tata letak. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen roti panggang menampilkan pemberitahuan singkat dan tidak mengganggu yang diposisikan di tepi layar. Dibangun dengan komponen pemosisian dan peringatan tetap, roti panggang menyampaikan umpan balik sistem seperti konfirmasi keberhasilan, pesan kesalahan, atau pembaruan status. Sistem roti panggang Frutjam mendukung enam posisi penempatan, ideal untuk pengiriman formulir, operasi asinkron, dan pemberitahuan real - time.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan kerangka kerja - agnostik: bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Penggunaan Dasar

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## Animasi Entri

Setiap roti panggang memudar dan naik ke tempatnya sendiri. Tidak ada yang perlu ditambahkan untuk itu, dan tidak ada kelas untuk mengaktifkannya.

Panduan kebijakan ini `toast-slide-*` pengubah adalah untuk saat Anda menginginkan arah yang berbeda dari kenaikan default. Pilih tepi tempat bersulang, sehingga masuk dari luar layar daripada menyeberanginya: `toast-slide-end` milik `toast-end`, `toast-slide-down` dengan `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

Jaraknya adalah lebar atau tinggi roti panggang itu sendiri, bukan jarak ke tepi layar, jadi roti panggang terpusat dimulai di dekat bagian tengah daripada di luar layar.

Tidak ada animasi keluar. Roti panggang menghilang saat dihapus dari halaman, karena CSS tidak memiliki status untuk beralih. Memudarkannya berarti menyimpannya di Dom dan menjiwainya sendiri.

Animasi dilewati untuk siapa saja yang telah meminta pengurangan gerak.

## Lebar

Setiap roti panggang dibatasi pada `24rem` jadi pesan panjang tidak menjangkau layar ponsel. Timpa `--toast--width` untuk mengubahnya.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
