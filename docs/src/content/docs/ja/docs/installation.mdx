CSS 専用の Tailwind CSS UI ライブラリである Frutjam を数分でインストールします。 2 つのインポート、ゼロ JavaScript、すぐに使える WCAG アクセス可能なコンポーネント。 Django、HTMX、Laravel、React、およびあらゆる Tailwind CSS v4 プロジェクトで動作します。

## インストール

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

次に、設定に一致する以下の行を選択します。どれも同じコンポーネントを提供します。

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| あなたのセットアップ | 何を追加するか | 船 |
| --- | --- | --- |
| [テイルウィンド CSS v4](#tailwind-css-v4) | `@plugin "frutjam";` | 自分が使うものだけを |
| [UnoCSS](#unocss) | `presetFrutjam()` | 自分が使うものだけを |
| [Vite、Astro、Rails、プレーン CSS](#no-utility-engine) | `import 'frutjam/css'` | すべてのコンポーネント、30 KB gzip圧縮 |
| [ビルドステップがありません](#no-build-step) | ある `<link>` タグ | すべてのコンポーネント |

</DocTable>

## テイルウィンド CSS v4

作業が必要です [追い風 CSS](https://tailwindcss.com/docs/installation/using-vite) プロジェクト、プラス [ノード](https://nodejs.org/en/download) そしてnpm。 Frutjam には Tailwind 4 が必要です。

フルーツジャムを追加 `input.css` と `@plugin` 指令：

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

それが全体のセットアップです。 65 以上のコンポーネントはすべてすぐに利用でき、Tailwind はマークアップで使用するコンポーネントのみを出荷します。

## UnoCSS

Frutjam にはプリセットが同梱されているため、Tailwind プラグインと同じように、UnoCSS は使用するコンポーネントのみを生成します。

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

すべてのクラスは Tailwind での場合と同様に機能し、バリアントも同様に機能します。

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

追加 `presetAttributify()` そしてコンポーネント名は属性になり、各値はそのバリアントとして扱われます。

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

2行目に必要なのは `transformerVariantGroup()` 括弧構文については。次のような属性に注意してください `btn` は有効な HTML ではないため、マークアップを検証する場合は、クラス フォームまたは UnoCSS の `un-` 接頭語。

### オプション

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| オプション | デフォルト | 目的 |
| --- | --- | --- |
| `preflight` | `true` | Frutjam のトークン、リセット、テーマを発行します。に設定します `false` すでにインポートしている場合 `frutjam/css/base` あなた自身。 |
| `prefix` | `''` | Tailwind プラグインと一致します `prefix`、 それで `'fj'` あなたに与えます `fj-btn` そして `fj-btn="error"`. |
| `layer` | `'frutjam'` | コンポーネントが放出されるカスケード レイヤー。ユーティリティの下にソートされるため、プリセットの順序に関係なく、ユーティリティは常にコンポーネントよりも優先されます。 |

</DocTable>

### リンクコンポーネントには 1 行の設定が必要です

UnoCSS の扱い `link` CSS のバリアントとして `:link` 疑似クラス、およびそのデフォルトの区切り文字には以下が含まれます。 `-`。それで `link-2xl` 「」と読みます`2xl`、未訪問時」をクラス名としてではなく、何も生成されません。このコンポーネントのみに影響し、 `link-*` 修飾子。

UnoCSS にコロンのみで分割するように指示します。

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

または、プレフィックスを使用して、他のものを置きます `link` 名前の前に:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

他のすべてのコンポーネントは影響を受けません。 `link` 57 個の中で名前が疑似クラスと衝突する唯一のクラスです。

## ユーティリティエンジンなし

Frutjam は Tailwind を使用して構築されていますが、コンポーネントはカスタム プロパティを読み取る通常の CSS にコンパイルされます。プロジェクトでユーティリティ エンジンをまったく使用しない場合は、プラグインの代わりにスタイルシートをインポートします。

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

それが全体のセットアップです。すべてのコンポーネントクラスが機能し、テーマが切り替わります `data-theme` いつものように、他には何も必要ありません。これは gzip 圧縮された 30 KB で、基本スタイル、テーマ、および 65 以上のすべてのコンポーネントが含まれています。

代わりに、必要なものだけを取り込みます。

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

または、ビルドステップをまったく行わない場合:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## ビルドステップがありません

タグをドロップしてマークアップの作成を開始します。これは、すべてのコンポーネントを同梱するため、運用環境ではなく、プロトタイプまたは作成しないページに使用してください。

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

同じページでTailwindのユーティリティを試すには、Tailwindのブラウザビルドを一緒に追加します。

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScriptとReact ：オプション、必須ではありません

Frutjamは**ネイティブファーストとCSSファースト**です。ボタン、バッジ、カード、フォーム、アラートなどのコンポーネントの大部分：純粋なHTMLとCSSで動作し、JavaScriptは必要ありません。次のようなネイティブHTML要素 `<dialog>`, `<details>`、および `<input type="checkbox">` ブラウザがすでにサポートしているインタラクティブ性を処理します。すべてのコンポーネントは、すぐにアクセスできるWCAG AAであり、Django、HTMX、Laravel、React、Next.js、および任意のスタックで動作します。

少数のコンポーネントには、ネイティブのHTML同等物（ TOAST通知、コンボボックスフィルタリング、カルーセルコントロール）がありません。これらのケースでのみ、フルジャムは軽量のオプションのヘルパーを出荷します。

### バニラJS ： `frutjam/js`

それらを必要とするコンポーネントのためのフレームワークに依存しないESモジュールヘルパー。任意のDOM要素に添付します。フレームワークは必要ありません。

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Reactフック： `frutjam/react`

同じネイティブDOM呼び出しの周りのシンReactラッパー。各フックは、 `ref` 要素とそれを制御するメソッドにアタッチし、React自体以外の依存関係はありません。

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

で利用可能です `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
