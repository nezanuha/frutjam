Tombol radio Tailwind CSS khusus CSS dengan varian warna primer, sekunder, aksen, dan semantik. Ukuran XS-XL. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen tombol radio memungkinkan pengguna untuk memilih tepat satu pilihan dari serangkaian pilihan yang saling eksklusif. Dibuat dengan elemen masukan HTML asli dan disempurnakan dengan Tailwind CSS, tombol radio mendukung berbagai ukuran, warna, dan status. Dapat diakses dan dinavigasi dengan keyboard, radio ideal untuk pemilihan preferensi, pemfilteran, dan pertanyaan formulir pilihan tunggal.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
