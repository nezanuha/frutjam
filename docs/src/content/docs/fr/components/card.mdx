Carte CSS Tailwind uniquement CSS avec styles de contour, d'ombre et plat. Tailles compactes, par défaut et grandes. Emplacements pour le contenu de la carte, le titre de la carte et le pied de page de la carte. WCAG AA, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants de carte sont des conteneurs polyvalents permettant de combiner des informations associées en une seule unité visuellement cohérente. Construites avec du HTML sémantique et des zones de contenu flexibles, les cartes organisent le contenu de manière hiérarchique et s'adaptent à diverses mises en page. Le système de cartes Frutjam propose plusieurs variantes de couleurs, tailles et styles pour les présentations de produits, les articles de blog, les témoignages et les éléments de tableau de bord.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

## Carte avec actions

Utilisez `card-actions` pour ajouter une zone de pied de page pour les boutons et les contrôles d'action.

<Snippet>

```html
<div class="card card-md shadow w-88">
  <div class="card-content">
    <h2 class="card-title">Card Title</h2>
    <p>A card with an actions footer for user interactions like buttons and links.</p>
    <div class="card-actions">
      <button class="btn btn-primary">Accept</button>
      <button class="btn">Dismiss</button>
    </div>
  </div>
</div>
```

</Snippet>

## Disposition de carte réactive

<Snippet>

```html
<div class="card card-lg w-160 shadow-sm">
  <div class="grid grid-cols-12 gap-0">
    <div class="col-span-12 lg:col-span-5">
      <figure class="h-64">
        <picture>
          <source media="(max-width: 1024px)" srcset="https://cdn.frutjam.com/images/photo-4.jpg?format=webp&width=640&height=427">
          <img src="https://cdn.frutjam.com/images/photo-4.jpg?format=webp&width=600&height=400" alt="Layout Image" class="w-full h-full object-cover" loading="lazy" />

      </figure>
    </div>
    <div class="col-span-12 lg:col-span-7">
      <div class="card-content">
        <h2 class="card-title">Responsive Layout</h2>
        <p>On desktop, image and content display side by side. On mobile, they stack vertically for optimal viewing experience.</p>
      </div>
    </div>
  </div>
</div>
```
