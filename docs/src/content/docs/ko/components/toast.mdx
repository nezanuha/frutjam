알림 포지셔닝을 위한 CSS 전용 Tailwind CSS 토스트: 상단, 하단, 시작, 끝 및 중앙 배치. 레이아웃에 대한 자바스크립트가 없습니다. WCAG AA에 액세스할 수 있으며 Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.

토스트 구성 요소는 화면 가장자리에 위치한 간단한 비침입성 알림을 표시합니다. 고정된 포지셔닝과 경고 구성 요소로 제작된 토스트는 성공 확인, 오류 메시지 또는 상태 업데이트와 같은 시스템 피드백을 전달합니다. Frutjam TOAST 시스템은 양식 제출, 비동기 작업 및 실시간 알림에 이상적인 6개의 배치 위치를 지원합니다.

CSS 전용, 자바스크립트는 필요하지 않습니다. WCAG AA 액세스 가능 및 프레임워크에 구애받지 않음: Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.

## 기본 사용

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## 엔트리 애니메이션

모든 토스트는 저절로 사라지고 제자리에 솟아오릅니다. 더할 것도 없고, 켤 클래스도 없습니다.

결과 `toast-slide-*` 수정자는 기본 상승과 다른 방향을 원할 때 사용할 수 있습니다. 토스트가 놓인 가장자리를 선택하여 화면이 아닌 바깥에서 들어갑니다. `toast-slide-end` 소속: `toast-end`, `toast-slide-down` 와 `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

거리는 화면 가장자리까지의 거리가 아닌 토스트 자체의 너비 또는 높이이므로 화면이 아닌 중간 근처에서 중앙 토스트가 시작됩니다.

종료 애니메이션이 없습니다. CSS에서 전환할 상태가 없기 때문에 페이지에서 제거되는 순간 토스트가 사라집니다. 하나를 페이드 아웃하는 것은 DOM에 유지하고 직접 애니메이션을 적용하는 것을 의미합니다.

움직임을 줄여달라고 요청한 사람은 애니메이션을 건너뜁니다.

## 너비

각 토스트는 `24rem` 따라서 긴 메시지는 전화 화면에 걸쳐 있지 않습니다. 재정의 `--toast--width` 변경할 수 있습니다.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
