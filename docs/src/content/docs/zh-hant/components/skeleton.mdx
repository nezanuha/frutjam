純 CSS Tailwind CSS 骨架載入器，用於佔位符 UI。帶有脈衝動畫的圓形、矩形和文字線形狀。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

骨架元件在內容載入時顯示佔位符佈局，提供視覺回饋並提高感知效能。骨架螢幕採用語義 HTML 和脈衝動畫構建，可防止佈局變更並設定使用者期望。 Frutjam 骨架系統支援多種形狀和尺寸，非常適合內容預覽、漸進加載和優雅降級。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
