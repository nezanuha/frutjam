Lien CSS Tailwind uniquement CSS avec des variantes de couleurs primaires, secondaires, accentuées et neutres. Survolez les styles soulignés et simples. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Liez les éléments d’ancrage de style des composants avec une hiérarchie visuelle et une signification sémantique. Le système de liens Frutjam prend en charge plusieurs couleurs, effets de survol, tailles et options de décoration via les classes utilitaires CSS Tailwind. Parfaits pour les liens texte, la navigation et les éléments d'appel à l'action, les liens maintiennent les normes d'accessibilité avec une gestion appropriée de la mise au point et des options de bascule de soulignement.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

## Couleurs des liens

Appliquez des couleurs de lien sémantique pour correspondre à votre thème ou pour transmettre un sens (par exemple en utilisant `link-error` pour les actions destructrices ou `link-success` pour la confirmation).

<Snippet>

```html
<a class="link link-primary">Primary link</a>
<a class="link link-secondary">Secondary link</a>
<a class="link link-accent">Accent link</a>
<a class="link link-success">Success link</a>
<a class="link link-info">Info link</a>
<a class="link link-warning">Warning link</a>
<a class="link link-error">Error link</a>
<a class="link link-neutral">Neutral link</a>
```

</Snippet>

## Tailles des liens

Adaptez vos **liens hypertextes** pour qu'ils correspondent à la typographie environnante. Ces classes utilitaires vont de très petite pour le texte « légal » de pied de page à 2X grande pour les sections de héros à fort impact.

<Snippet>

```html
<a class="link link-xs">Primary link</a>
<a class="link link-sm">Secondary link</a>
<a class="link link-md">Accent link</a>
<a class="link link-lg">Success link</a>
<a class="link link-xl">Info link</a>
<a class="link link-2xl">Warning link</a>
```

</Snippet>

## État de survol du lien

Par défaut, vous pouvez choisir de masquer le soulignement et de le révéler uniquement au survol. Il s'agit d'un modèle de conception courant pour des **menus de navigation** et des barres latérales de tableau de bord plus propres.

<Snippet>

```html
<a class="link link-hover">Hover this link</a>
```

</Snippet>
