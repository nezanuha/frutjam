Instale o Frutjam, a biblioteca de interface do usuário CSS Tailwind somente para CSS, em minutos. Duas importações, zero JavaScript, componentes acessíveis WCAG prontos para uso. Funciona com Django, HTMX, Laravel, React e qualquer projeto Tailwind CSS v4.

## Install

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Em seguida, escolha a linha abaixo que corresponde à sua configuração. Cada um lhe dá os mesmos componentes.

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| A sua configuração | O que adicionar | Navios |
| --- | --- | --- |
| [Tailwind CSS v4](#tailwind-css-v4) | `@plugin "frutjam";` | apenas o que usa |
| [UnoCSS](#unocss) | `presetFrutjam()` | apenas o que usa |
| [Vite, astro, Rails, CSS simples](#no-utility-engine) | `import 'frutjam/css'` | todos os componentes, 30 KB gzipped |
| [Nenhuma etapa de compilação](#no-build-step) | a `<link>` etiqueta | Components |

</DocTable>

## Tailwind CSS v4

Precisa de um trabalho [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite) project, plus [Nó](https://nodejs.org/en/download) e npm. Frutjam requer Tailwind 4.

Adicione Frutjam ao seu `input.css` com a `@plugin` diretiva

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

Essa é toda a configuração. Todos os mais de 65 componentes estão disponíveis imediatamente, e a Tailwind envia apenas os que sua marcação usa.

## UnoCSS

O Frutjam envia uma predefinição, então o UnoCSS gera apenas os componentes que você usa, da mesma forma que o plugin Tailwind.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Cada classe funciona como no Tailwind, assim como as variantes:

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

Add `presetAttributify()` e o nome do componente se torna um atributo, com cada valor tratado como uma variante dele:

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

A segunda linha precisa `transformerVariantGroup()` para a sintaxe de colchetes. Observe que um atributo como `btn` não é HTML válido, portanto, se você validar sua marcação, use o formulário de classe ou o UnoCSS `un-` prefixo

### Opções

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| opções | Padrão | Objeto |
| --- | --- | --- |
| `preflight` | `true` | Emite tokens, redefinições e temas do Frutjam. Defina como `false` se já importou `frutjam/css/base` você mesmo. |
| `prefix` | `''` | Corresponde ao plugin Tailwind `prefix`Assim  `'fj'` Este regime dá-lhe `fj-btn` e `fj-btn="error"`. |
| `layer` | `'frutjam'` | A camada em cascata na qual os componentes são emitidos. Ele classifica abaixo dos utilitários, portanto, um utilitário sempre vence um componente, independentemente da ordem em que as predefinições estão. |

</DocTable>

### O componente link precisa de uma linha de configuração

Guloseimas UnoCSS `link` como uma variante, para o CSS `:link` pseudo-classe, e os seus separadores padrão incluem `-`Então... `link-2xl` é lido como "`2xl`, quando não visitado"e não como um nome de classe, e nada é gerado. Afeta apenas este componente, e apenas o `link-*` Modificadores

Diga ao UnoCSS para dividir apenas em dois pontos:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Ou use um prefixo, que coloca algo diferente de `link` na frente do nome:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

Todos os outros componentes não são afetados. `link` é o único dos 57 cujo nome colide com uma pseudoclasse.

## Sem motor utilitário

O Frutjam é construído com Tailwind, mas os componentes compilam para CSS comum que lê propriedades personalizadas. Se o seu projeto não usa nenhum mecanismo utilitário, importe a folha de estilo em vez do plugin:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Essa é toda a configuração. Cada classe de componente funciona, os temas mudam com `data-theme` como de costume, e nada mais é necessário. Tem um gzip de 30 KB e carrega os estilos básicos, ambos os temas e todos os mais de 65 componentes.

Em vez disso, adicione apenas o que precisa:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

Ou sem nenhuma etapa de construção:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## Nenhuma etapa de compilação

Solte uma tag e comece a escrever a marcação. Use isso para um protótipo ou uma página que você não constrói, não para produção, pois ele envia todos os componentes.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

Para experimentar os utilitários da Tailwind na mesma página, adicione a compilação do navegador da Tailwind:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript e React: opcional, não obrigatório

Frutjam é **nativo-primeiro e CSS-primeiro**. A grande maioria dos componentes: botões, crachás, cartões, formulários, alertas e muito mais: funciona com HTML e CSS puros, sem necessidade de JavaScript. Elementos HTML nativos como `<dialog>`, `<details>`, e `<input type="checkbox">` lidar com a interatividade onde os navegadores já a suportam. Todos os componentes são WCAG AA acessíveis imediatamente e funcionam com Django, HTMX, Laravel, React, Next.js e qualquer pilha.

Um pequeno número de componentes não possui equivalente HTML nativo (notificações do sistema, filtragem de caixa de combinação, controles de carrossel). Apenas para esses casos, a Frutjam envia ajudantes opcionais leves.

### Baunilha JS: `frutjam/js`

Auxiliares de módulo ES independentes de estrutura para os componentes que precisam deles. Anexe a qualquer elemento DOM, sem necessidade de estrutura.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Ganchos de reação: `frutjam/react`

Wrappers Thin React em torno das mesmas chamadas DOM nativas. Cada gancho retorna um `ref` você anexa ao elemento e métodos para controlá-lo, sem dependências extras além do próprio React.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Disponível para: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
