Chú giải công cụ CSS Tailwind chỉ dành cho CSS với các vị trí trên cùng, dưới cùng, bên trái và bên phải. Các biến thể màu sắc, không cần JavaScript. WCAG AA có thể truy cập được, hoạt động với Django, HTMX, Laravel, React và bất kỳ ngăn xếp nào.

Các thành phần chú giải công cụ hiển thị thông tin bổ sung khi người dùng di chuột qua hoặc tập trung vào một phần tử. Được xây dựng bằng các thuộc tính HTML ngữ nghĩa và CSS, chú giải công cụ nâng cao trải nghiệm người dùng bằng cách cung cấp trợ giúp theo ngữ cảnh cụ thể mà không làm lộn xộn giao diện. Hệ thống chú giải công cụ Frutjam hỗ trợ nhiều vị trí, nội dung tùy chỉnh và hình ảnh động mượt mà để khám phá thông tin liền mạch.

Chỉ CSS, không cần JavaScript. WCAG AA có thể truy cập và không phụ thuộc vào khung — hoạt động với Django, HTMX, Laravel, React và bất kỳ ngăn xếp nào.

**Lưu ý:** Chú giải công cụ dựa trên `:hover` và `:focus`, những tính năng này **không khả dụng trên thiết bị cảm ứng/di động**. Đối với bố cục ưu tiên thiết bị di động, hãy sử dụng biến thể đáp ứng `lg:tooltip` để chú giải công cụ chỉ kích hoạt trên máy tính để bàn (màn hình lớn trở lên). Trên màn hình nhỏ hơn, hãy cân nhắc sử dụng mẫu tiết lộ khác, chẳng hạn như [popover](https://frutjam.com/components/popover) hoặc [phương thức](https://frutjam.com/components/modal).

## Chú giải công cụ

<Snippet>

```html
<div class="tooltip" data-tip="Tooltip">
   <button class="btn">Hover me</button>
</div>
```

```jsx
<div className="tooltip" data-tip="Tooltip">
   <button className="btn">Hover me</button>
</div>
```

</Snippet>

## JS & React Helper

Sử dụng `createTooltip` từ `frutjam/js` hoặc `useTooltip` từ `frutjam/react` để hiển thị hoặc ẩn chú giải công cụ theo chương trình — hữu ích cho các chuyến tham quan có hướng dẫn hoặc văn bản trợ giúp được kích hoạt.

<Snippet>

```html
<div class="flex gap-2 mb-4">
  <button class="btn btn-sm" id="tip-show">Show</button>
  <button class="btn btn-sm" id="tip-hide">Hide</button>
  <button class="btn btn-sm" id="tip-toggle">Toggle</button>
</div>
<div class="tooltip" data-tip="Programmatic tooltip" id="js-tooltip">
  <button class="btn">Target</button>
</div>
<script type="module">
  import { createTooltip } from 'frutjam/js'
  const tip = createTooltip(document.getElementById('js-tooltip'))
  document.getElementById('tip-show').onclick = () => tip.show()
  document.getElementById('tip-hide').onclick = () => tip.hide()
  document.getElementById('tip-toggle').onclick = () => tip.toggle()
</script>
```

```jsx
import { useTooltip } from 'frutjam/react'

export default function TooltipDemo() {
  const tooltip = useTooltip()
  return (
    <>
      <div className="flex gap-2 mb-4">
        <button className="btn btn-sm" onClick={tooltip.show}>Show</button>
        <button className="btn btn-sm" onClick={tooltip.hide}>Hide</button>
        <button className="btn btn-sm" onClick={tooltip.toggle}>Toggle</button>
      </div>
      <div ref={tooltip.ref} className="tooltip" data-tip="Programmatic tooltip">
        <button className="btn">Target</button>
      </div>
    </>
  )
}
```

</Snippet>
