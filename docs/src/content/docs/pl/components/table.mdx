Tabela CSS Tailwind tylko dla CSS z paskami zebry, kompaktowymi i domyślnymi rozmiarami, przypiętymi kolumnami i stanami najechania wierszem. Dostępny WCAG AA, współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

Komponenty tabeli organizują i wyświetlają uporządkowane dane w wierszach i kolumnach. Zbudowane z semantycznych elementów tabel HTML i stylów CSS Tailwind, tabele obsługują sortowanie, wiersze w paski, efekty najechania kursorem i responsywną obsługę przepełnienia. System tabel Frutjam jest dostępny z odpowiednimi powiązaniami nagłówków i bezproblemowo współpracuje ze frameworkami wizualizacji danych.

Tylko CSS, nie wymaga JavaScript. Dostępny w WCAG AA i niezależny od frameworka — współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

## Rozmiary stołów

### Tabela bardzo mała `(table-xs)`

W poniższym przykładzie rozmiaru tabeli używamy `table-xs` (bardzo mały). Rozmiar tabeli można dostosować za pomocą klas narzędzi `table-{size}`, w tym `table-xs`, `table-sm`, `table-md`, `table-lg` i `table-xl`, które obejmują zarówno wyjątkowo kompaktowe układy, jak i bardziej przestronne, czytelne tabele.
