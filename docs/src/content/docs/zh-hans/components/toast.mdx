仅 CSS Tailwind CSS toast 用于通知定位：顶部、底部、开始、结束和中心放置。没有用于布局的 JavaScript。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

Toast 组件在屏幕边缘显示简短的、非侵入性的通知。 Toast 采用固定定位和警报组件构建，可传达系统反馈，例如成功确认、错误消息或状态更新。 Frutjam toast 系统支持六个放置位置，非常适合表单提交、异步操作和实时通知。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关：适用于 Django、HTMX、Laravel、React 和任何堆栈。

## 基本用法

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## 入场动画

每片吐司都会自行褪色并升起。没有什么可以添加的，也没有类可以打开它。

这 `toast-slide-*` 当您想要与默认上升不同的方向时，可以使用修改器。选择吐司所在的边缘，这样它就会从屏幕外部进入，而不是穿过屏幕： `toast-slide-end` 属于 `toast-end`, `toast-slide-down` 和 `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

该距离是 toast 自身的宽度或高度，而不是到屏幕边缘的距离，因此居中的 toast 从中间附近开始，而不是在屏幕外。

没有退出动画。 Toast 从页面中删除后就会消失，因为 CSS 没有可以转换的状态。淡出一个意味着将其保留在 DOM 中并自己为其设置动画。

对于任何要求减少动作的人来说，动画都会被跳过。

## 宽度

每个吐司的上限为 `24rem` 因此长消息不会跨越手机屏幕。覆盖 `--toast--width` 改变它。

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
