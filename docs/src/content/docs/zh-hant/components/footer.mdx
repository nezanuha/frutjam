純 CSS Tailwind CSS 頁腳，具有多列佈局、標誌、連結和版權插槽。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 專案配合使用。

頁腳元件在頁面底部組織和呈現網站範圍的信息，例如連結、版權和聯絡資訊。頁腳採用語意 HTML 構建，可改善導覽並提供重要的元資訊。 Frutjam 頁腳系統支援多種佈局、方向和樣式，非常適合網站頁尾、文件頁尾和底部導覽。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
