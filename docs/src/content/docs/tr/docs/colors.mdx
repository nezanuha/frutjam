Frutjam'ın renk sistemi, WCAG AA kontrast oranlarını kutudan çıkar çıkmaz karşılamak üzere tasarlanmış anlamsal CSS belirteçlerini kullanır. JavaScript yok, karanlık mod uyumlu, Tailwind CSS v4 ile uyumlu. Django, HTMX, Laravel ve yalnızca CSS yığınlarıyla çalışır.

Frutjam, tüm renkler için tasarım belirteçleri olarak CSS özel özelliklerini kullanır. Her renk, temaya göre tanımlanır ve Tailwind CSS yardımcı program sınıflarıyla otomatik olarak çalışır; ekstra yapılandırmaya gerek yoktur. Yalnızca CSS, JavaScript gerekmez. WCAG AA kontrastı her renk çiftinde garanti edilir; Django, HTMX, Laravel, React ve herhangi bir Tailwind CSS v4 projesiyle çalışır.

## Renk İsimleri

Frutjam aşağıdaki anlamsal renk rollerini tanımlar. Her rengin, erişilebilir ön plan metni için eşleşen bir `on-{color}` belirteci vardır.

## Renk Yardımcı Program Sınıfları

Tüm Frutjam renkleri herhangi bir Tailwind CSS renk yardımcı programıyla çalışır. `{color}`'i yukarıdaki tablodaki herhangi bir renk adıyla değiştirin.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Sınıf | Tanım |
| --- | --- |
| `bg-{color}` | Arka plan rengi |
| `text-{color}` | Metin rengi |
| `border-{color}` | Kenarlık rengi |
| `ring-{color}` | Halka rengi |
| `outline-{color}` | Anahat rengi |
| `shadow-{color}` | Gölge rengi |
| `fill-{color}` | SVG dolgu rengi |
| `stroke-{color}` | SVG kontur rengi |
| `decoration-{color}` | Metin dekorasyon rengi |
| `caret-{color}` | Giriş düzeltme işareti rengi |
| `placeholder-{color}` | Yer tutucu metin rengi |
| `divide-{color}` | Bölücü kenarlık rengi |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### Opaklık Değiştirici

Herhangi bir Tailwind renginde olduğu gibi, renk opaklığını `/{value}` değiştiricisiyle kontrol edin.

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## Tema CSS Değişkenleri

| `--color-on-neutral` | Nötr yüzeylerde metin rengi |

| `--color-on-primary` | Birincil arka planlarda metin rengi |
| `--color-secondary` | İkincil marka rengi |
| `--color-on-secondary` | İkincil arka planlarda metin rengi |
| `--color-accent` | Vurgu rengi |
| `--color-on-accent` | Vurgulu arka planlarda metin rengi |
| `--color-info` | Bilgi rengi |
| `--color-on-info` | Bilgi arka planlarındaki metin rengi |
| `--color-success` | Başarı rengi |
| `--color-on-success` | Başarı arka planlarındaki metin rengi |
| `--color-warning` | Uyarı rengi |
| `--color-on-warning` | Uyarı arka planlarındaki metin rengi |

## Hesaplanan Renk Belirteçleri

Frutjam bu belirteçleri kök tema değişkenlerinizden otomatik olarak hesaplar; bunları manuel olarak ayarlamazsınız. Özel CSS'de kullanılabilirler.

### Ölçek (50–950)

Her renk, 11 adımlı tam bir renk tonu/gölge ölçeği oluşturur. `{color}`'i herhangi bir renk adıyla değiştirin.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS Değişkeni | Tanım |
| --- | --- |
| `--color-{color}-50` | Lightest tint (4% color mix) |
| `--color-{color}-100` | Çok hafif renk tonu |
| `--color-{color}-200` | Açık renk tonu |
| `--color-{color}-300` | Orta-açık renk tonu |
| `--color-{color}-400` | Hafif renk tonu |
| `--color-{color}-500` | Temel renk (`--color-{color}` ile aynı) |
| `--color-{color}-600` | Hafif gölge |
| `--color-{color}-700` | Orta gölge |
| `--color-{color}-800` | Koyu gölge |
| `--color-{color}-900` | Çok koyu gölge |
| `--color-{color}-950` | En koyu gölge |

</DocTable>

### Yumuşak ve Aktif

Açık ve koyu temalara otomatik olarak uyum sağlayan, etkileşimli öğeler için durum bilinçli değişkenler.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS Değişkeni | Tanım |
| --- | --- |
| `--color-{color}-soft` | Yumuşak çeşitler için ince renkli arka plan |
| `--color-on-{color}-soft` | Yumuşak arka planlarda kullanım için metin rengi |
| `--color-{color}-active` | Fareyle üzerine gelme ve etkin durumlar için koyulaştırılmış/açıklaştırılmış gölge |
| `--color-body` | Hesaplanan gövde metni rengi (`on-base`'den biraz yumuşatılmıştır) |

</DocTable>

## Özel Tema Örneği

Özel bir tema oluşturmak için kök belirteçlerini geçersiz kılın. Frutjam tüm ölçekleri ve durumları otomatik olarak hesaplar.

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
