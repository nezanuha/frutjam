Metrikleri görüntülemek için yalnızca CSS'ye özgü Tailwind CSS istatistiği. Değer, etiket, açıklama ve simge yuvaları. Duyarlı ızgara düzeni. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

İstatistik bileşenleri temel metrikleri ve sayısal verileri açık ve düzenli bir biçimde görüntüler. Anlamsal HTML ve esnek düzenlerle oluşturulan istatistikler, önemli iş ölçümlerini ve analizlerini iletir. Frutjam istatistik sistemi birden fazla düzenlemeyi ve stili destekler; gösterge tabloları, performans raporları ve veri özetleri için idealdir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
