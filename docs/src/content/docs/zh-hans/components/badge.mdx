仅 CSS Tailwind CSS 徽章，包含主要、次要、重音、信息、成功、警告和错误变体。柔和、轮廓和幻影样式，尺寸为 xs-lg。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

徽章组件是小型、紧凑的标签，用于突出显示、分类或显示状态信息。徽章采用语义 HTML 和 Tailwind CSS 构建，支持多种尺寸、颜色和样式，可灵活集成到表格、卡片、用户配置文件和通知系统中。徽章重量轻且易于使用，可增强信息层次结构，而不会增加视觉混乱。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。
