Çok sütunlu düzen, logo, bağlantılar ve telif hakkı yuvalarına sahip, yalnızca CSS'ye özel Tailwind CSS altbilgisi. WCAG AA'ya erişilebilir, Django, HTMX, Laravel, React ve herhangi bir Tailwind CSS v4 projesiyle çalışır.

Alt bilgi bileşenleri, sayfaların alt kısmında bağlantılar, telif hakkı ve iletişim bilgileri gibi site genelindeki bilgileri düzenler ve sunar. Anlamsal HTML ile oluşturulan alt bilgiler, gezinmeyi geliştirir ve önemli meta bilgiler sağlar. Frutjam altbilgi sistemi birden fazla düzeni, yönü ve stili destekler; site altbilgileri, belge altbilgileri ve alt gezinme için idealdir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
