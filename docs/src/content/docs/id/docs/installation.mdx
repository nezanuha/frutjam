Instal pustaka Frutjam UI khusus CSS dengan Tailwind CSS v4, UnoCSS, atau tanpa langkah pembuatan sama sekali. 65+ komponen yang dapat diakses, tanpa JavaScript, WCAG AA. Bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Memasang

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Kemudian pilih baris di bawah yang cocok dengan pengaturan Anda. Masing-masing memberi Anda komponen yang sama.

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Pengaturan Anda | Apa yang harus ditambahkan | Kapal |
| --- | --- | --- |
| [CSS penarik v4](#tailwind-css-v4) | `@plugin "frutjam";` | hanya apa yang Anda gunakan |
| [UnoCSS](#unocss) | `presetFrutjam()` | hanya apa yang Anda gunakan |
| [Vite, Astro, Rails, CSS biasa](#no-utility-engine) | `import 'frutjam/css'` | semua komponen, 30 KB di-gzip |
| [Tidak ada langkah membangun](#no-build-step) | A `<link>` menandai | semua komponen |

</DocTable>

## CSS penarik v4

Anda membutuhkan yang berfungsi [CSS penarik](https://tailwindcss.com/docs/installation/using-vite) proyek, ditambah [simpul](https://nodejs.org/en/download) dan npm. Frutjam membutuhkan Tailwind 4.

Tambahkan Frutjam ke Anda `input.css` dengan `@plugin` direktif:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

Itulah keseluruhan pengaturannya. Keseluruhan 65+ komponen segera tersedia, dan Tailwind hanya mengirimkan komponen yang digunakan markup Anda.

## UnoCSS

Frutjam mengirimkan preset, jadi UnoCSS hanya menghasilkan komponen yang Anda gunakan, sama seperti plugin Tailwind.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Setiap kelas berfungsi seperti pada Tailwind, begitu pula variannya:

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

Menambahkan `presetAttributify()` dan nama komponen menjadi atribut, dengan setiap nilai diperlakukan sebagai variannya:

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

Kebutuhan baris kedua `transformerVariantGroup()` untuk sintaks braket. Perhatikan bahwa atribut seperti `btn` bukan HTML yang valid, jadi jika Anda memvalidasi markup Anda, gunakan formulir kelas atau UnoCSS `un-` awalan.

### Pilihan

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Pilihan | Bawaan | Tujuan |
| --- | --- | --- |
| `preflight` | `true` | Memancarkan token, reset, dan tema Frutjam. Setel ke `false` jika Anda sudah mengimpor `frutjam/css/base` dirimu sendiri. |
| `prefix` | `''` | Cocok dengan plugin Tailwind `prefix`, Jadi `'fj'` memberimu `fj-btn` Dan `fj-btn="error"`. |
| `layer` | `'frutjam'` | Lapisan kaskade tempat komponen dipancarkan. Ini diurutkan di bawah utilitas, sehingga utilitas selalu menang atas komponen apa pun urutan presetnya. |

</DocTable>

### Komponen tautan memerlukan satu baris konfigurasi

suguhan UnoCSS `link` sebagai varian, untuk CSS `:link` kelas semu, dan pemisah defaultnya termasuk `-`. Jadi `link-2xl` dibaca sebagai "`2xl`, ketika belum dikunjungi" bukan sebagai nama kelas, dan tidak ada yang dihasilkan. Ini hanya mempengaruhi komponen ini, dan hanya `link-*` pengubah.

Entah memberitahu UnoCSS untuk membagi pada titik dua saja:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Atau gunakan awalan, yang menempatkan sesuatu selain `link` di depan nama:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

Setiap komponen lainnya tidak terpengaruh. `link` adalah satu-satunya dari 57 yang namanya bertabrakan dengan kelas semu.

## Tidak ada mesin utilitas

Frutjam dibuat dengan Tailwind, tetapi komponennya dikompilasi ke CSS biasa yang membaca properti khusus. Jika proyek Anda tidak menggunakan mesin utilitas sama sekali, impor stylesheet dan bukan plugin:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Itulah keseluruhan pengaturannya. Setiap kelas komponen berfungsi, tema diganti `data-theme` seperti biasa, dan tidak ada lagi yang diperlukan. Ini berukuran 30 KB gzip dan membawa gaya dasar, baik tema dan semua 65+ komponen.

Tarik hanya apa yang Anda perlukan saja:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

Atau tanpa langkah pembuatan sama sekali:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## Tidak ada langkah membangun

Masukkan tag dan mulailah menulis markup. Gunakan ini untuk prototipe atau halaman yang tidak Anda buat, bukan untuk produksi, karena ini mengirimkan setiap komponen.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

Untuk bereksperimen dengan utilitas Tailwind di halaman yang sama, tambahkan versi browser Tailwind di sampingnya:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript dan React: opsional, tidak wajib

Frutjam adalah **yang mengutamakan native dan mengutamakan CSS**. Sebagian besar komponen: tombol, lencana, kartu, formulir, peringatan, dan banyak lagi: berfungsi dengan HTML dan CSS murni, tidak memerlukan JavaScript. Elemen HTML asli seperti `<dialog>`, `<details>`, Dan `<input type="checkbox">` menangani interaktivitas di mana browser sudah mendukungnya. Semua komponen adalah WCAG AA yang dapat diakses langsung dan bekerja dengan Django, HTMX, Laravel, React, Next.js, dan tumpukan apa pun.

Sejumlah kecil komponen tidak memiliki padanan HTML asli (notifikasi toast, pemfilteran kotak kombo, kontrol carousel). Hanya untuk kasus-kasus tersebut, Frutjam mengirimkan pembantu opsional yang ringan.

### vanila JS: `frutjam/js`

Pembantu modul ES framework-agnostic untuk komponen yang membutuhkannya. Lampirkan ke elemen DOM apa pun, tidak diperlukan kerangka kerja.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Kait Reaksi: `frutjam/react`

Pembungkus React yang tipis di sekitar panggilan DOM asli yang sama. Setiap kait mengembalikan a `ref` Anda melampirkan elemen dan metode untuk mengendalikannya, tidak ada ketergantungan tambahan di luar React itu sendiri.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Tersedia untuk: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
