僅 CSS Tailwind CSS 星級和心率組件。尺寸 xs-xl，半星支持，無需 JavaScript。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

評級組件允許使用者透過為產品、服務或內容分配星級或數位評級來提供回饋。評級採用語意 HTML 輸入和互動式樣式構建，可傳達使用者滿意度和品質回饋。 Frutjam 評級系統支援多種樣式、顏色和尺寸，非常適合產品評論、使用者回饋表和滿意度調查。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
