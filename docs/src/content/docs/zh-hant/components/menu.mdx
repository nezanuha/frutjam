僅限 CSS Tailwind CSS 導覽清單垂直選單。活動、禁用和圖示項目狀態。尺寸變體。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

選單組件顯示有組織的操作或導覽選項清單。 Frutjam 選單系統採用語義 HTML 清單和連結元素構建，支援垂直和水平佈局、嵌套選單、圖示和活動狀態。選單完全可以透過鍵盤導航進行訪問，與下拉式選單、側邊欄和上下文導航模式無縫整合。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
