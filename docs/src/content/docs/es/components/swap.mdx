Intercambio de CSS Tailwind solo para CSS para alternar entre dos elementos. Voltear, rotar y atenuar animaciones, sin JavaScript. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes de intercambio alternan entre dos estados de contenido con animaciones fluidas en respuesta a la interacción del usuario. Construidos con transiciones semánticas de HTML y CSS, los intercambios permiten cambios de estado elegantes sin JavaScript. El sistema de intercambio de Frutjam admite múltiples estilos de animación, ideal para alternar temas, cambios de modo, estados de carga e ilustraciones interactivas.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.

## Uso básico

Cree un intercambio simple con emoji o contenido de texto usando una casilla de verificación para alternar estados.

<Snippet>

```html
<label class="swap">
  <input type="checkbox" />
  <div class="swap-on">☀️</div>
  <div class="swap-off">🌙</div>
</label>
```

```jsx
<label className="swap">
  <input type="checkbox" />
  <div className="swap-on">☀️</div>
  <div className="swap-off">🌙</div>
</label>
```

</Snippet>

## Intercambiar animaciones

Aplique diferentes estilos de animación para transiciones visuales: desvanecer (predeterminado), rotar y voltear.

<Snippet>

```html
<label class="swap">
  <input type="checkbox" />
  <div class="swap-on">Online</div>
  <div class="swap-off">Offline</div>
</label>

<label class="swap swap-rotate">
  <input type="checkbox" />
  <div class="swap-on">➕</div>
  <div class="swap-off">✖️</div>
</label>

<label class="swap swap-flip">
  <input type="checkbox" />
  <div class="swap-on">Yes</div>
  <div class="swap-off">No</div>
</label>
```

</Snippet>

  <div class="swap-off">Dark Mode</div>

</Snippet>
