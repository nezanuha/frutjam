Yalnızca CSS'ye özel Tailwind CSS kullanıcı arayüzü kitaplığı olan Frutjam'ı birkaç dakika içinde yükleyin. İki içe aktarma, sıfır JavaScript, kutudan çıktığı gibi WCAG ile erişilebilen bileşenler. Django, HTMX, Laravel, React ve herhangi bir Tailwind CSS v4 projesiyle çalışır.

## Düzenlemek

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Daha sonra aşağıdan kurulumunuza uygun satırı seçin. Her biri size aynı bileşenleri verir.

## Arka rüzgar CSS v4

Çalışmaya ihtiyacın var [Arka rüzgar CSS](https://tailwindcss.com/docs/installation/using-vite) proje artı [Düğüm](https://nodejs.org/en/download) ve npm. Frutjam, Tailwind 4'ü gerektirir.

Frutjam'ı ekleyin `input.css` ile `@plugin` direktif:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

Bütün kurulum budur. 65'ten fazla bileşenin tamamı anında mevcuttur ve Tailwind yalnızca işaretlemenizin kullandığı bileşenleri gönderir.

## UnoCSS

Frutjam bir ön ayar gönderir; böylece UnoCSS, Tailwind eklentisinin yaptığı gibi yalnızca kullandığınız bileşenleri oluşturur.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Her sınıf ve çeşitleri Tailwind altında olduğu gibi çalışır:

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

Eklemek `presetAttributify()` ve bileşen adı bir öznitelik haline gelir ve her değer onun bir çeşidi olarak değerlendirilir:

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

İkinci satıra ihtiyaç var `transformerVariantGroup()` braket sözdizimi için. Gibi bir özelliğin olduğunu unutmayın `btn` geçerli bir HTML değil, bu nedenle işaretlemenizi doğrulayacaksanız sınıf formunu veya UnoCSS'yi kullanın. `un-` önek.

### Seçenekler

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Seçenek | Varsayılan | Amaç |
| --- | --- | --- |
| `preflight` | `true` | Frutjam'ın jetonlarını, sıfırlamalarını ve temalarını yayar. Şuna ayarla: `false` zaten içe aktarıyorsanız `frutjam/css/base` kendin. |
| `prefix` | `''` | Tailwind eklentisininkilerle eşleşir `prefix`, Bu yüzden `'fj'` sana verir `fj-btn` Ve `fj-btn="error"`. |
| `layer` | `'frutjam'` | Bileşenlerin yayıldığı basamaklı katman. Yardımcı programların altında sıralanır, böylece ön ayarlar hangi sırada olursa olsun bir yardımcı program her zaman bir bileşeni kazanır. |

</DocTable>

### Bağlantı bileşeninin bir yapılandırma satırına ihtiyacı var

UnoCSS işlemleri `link` CSS için bir varyant olarak `:link` sözde sınıf ve onun varsayılan ayırıcıları şunları içerir: `-`. Bu yüzden `link-2xl` " şeklinde okunur`2xl`", ziyaret edilmediğinde" bir sınıf adı olarak değil, hiçbir şey üretilmez. Yalnızca bu bileşeni etkiler ve yalnızca `link-*` değiştiriciler

UnoCSS'ye yalnızca iki nokta üst üste bölünmesini söyleyin:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Veya şunun dışında bir şey koyan bir önek kullanın: `link` ismin önünde:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

Diğer hiçbir bileşen etkilenmez. `link` 57 kişiden adı sahte sınıfla çatışan tek kişidir.

## Yardımcı motor yok

Frutjam, Tailwind ile oluşturulmuştur ancak bileşenler, özel özellikleri okuyan sıradan CSS'ye derlenir. Projeniz hiçbir yardımcı motor kullanmıyorsa eklenti yerine stil sayfasını içe aktarın:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Bütün kurulum budur. Her bileşen sınıfı çalışır, temalar değişir `data-theme` her zamanki gibi ve başka hiçbir şeye gerek yok. 30 KB gzip'lidir ve temel stilleri, hem temaları hem de 65'ten fazla bileşeni taşır.

Bunun yerine yalnızca ihtiyacınız olanı çekin:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

Veya hiçbir derleme adımı olmadan:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## Oluşturma adımı yok

Bir etiket bırakın ve işaretleme yazmaya başlayın. Bunu, her bileşeni gönderdiğinden üretim için değil, oluşturmadığınız bir prototip veya sayfa için kullanın.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

Aynı sayfada Tailwind'in yardımcı programlarını denemek için Tailwind'in tarayıcı yapısını da yanına ekleyin:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript ve React: isteğe bağlı, gerekli değil

Frutjam **yerel öncelikli ve CSS önceliklidir**. Bileşenlerin büyük çoğunluğu: düğmeler, rozetler, kartlar, formlar, uyarılar ve daha fazlası: saf HTML ve CSS ile çalışır, sıfır JavaScript gerektirir. Yerel HTML öğeleri gibi `<dialog>`, `<details>`, Ve `<input type="checkbox">` Tarayıcıların zaten desteklediği etkileşimi yönetin. Tüm bileşenlere WCAG AA kullanıma hazırdır ve Django, HTMX, Laravel, React, Next.js ve herhangi bir yığınla çalışır.

Az sayıda bileşenin yerel HTML eşdeğeri yoktur (kısmen bildirimler, birleşik giriş kutusu filtreleme, atlıkarınca kontrolleri). Frutjam yalnızca bu durumlar için hafif, isteğe bağlı yardımcılar gönderir.

### Vanilya JS: `frutjam/js`

İhtiyaç duyan bileşenler için çerçeveden bağımsız ES modülü yardımcıları. Herhangi bir DOM öğesine ekleyin; çerçeve gerekmez.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Tepki Kancaları: `frutjam/react`

Aynı yerel DOM çağrılarının etrafındaki ince React sarmalayıcıları. Her kanca bir değer döndürür `ref` öğeye ve onu kontrol etmek için yöntemlere bağlanırsınız, React'ın kendisi dışında ekstra bir bağımlılık yoktur.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Şunlar için kullanılabilir: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
