Üst, alt, sol ve sağ yerleşime sahip, yalnızca CSS'ye özel Tailwind CSS araç ipucu. Renk çeşitleri, JavaScript gerekmez. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Araç ipucu bileşenleri, kullanıcılar bir öğenin üzerine geldiğinde veya bir öğeye odaklandığında ek bilgiler görüntüler. Anlamsal HTML nitelikleri ve CSS ile oluşturulan araç ipuçları, arayüzü karmaşıklaştırmadan bağlama özel yardım sağlayarak kullanıcı deneyimini geliştirir. Frutjam araç ipucu sistemi, kusursuz bilgi keşfi için birden fazla konumu, özel içeriği ve akıcı animasyonları destekler.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.

**Not:** Araç ipuçları, **dokunmatik/mobil cihazlarda bulunmayan** `:hover` ve `:focus` öğelerini kullanır. Mobil öncelikli düzenler için, duyarlı değişken `lg:tooltip`'i kullanın, böylece araç ipucu yalnızca masaüstünde (büyük ekranlar ve üstü) etkinleştirilir. Daha küçük ekranlarda, [popover](https://frutjam.com/components/popover) veya [modal](https://frutjam.com/components/modal) gibi farklı bir açıklama modeli kullanmayı düşünün.

## JS ve Tepki Yardımcısı

Bir araç ipucunu programlı olarak göstermek veya gizlemek için `frutjam/js`'den `createTooltip`'i veya `frutjam/react`'tan `useTooltip`'i kullanın; rehberli turlar veya tetiklenen yardım metni için kullanışlıdır.

<Snippet>

```html
<div class="flex gap-2 mb-4">
  <button class="btn btn-sm" id="tip-show">Show</button>
  <button class="btn btn-sm" id="tip-hide">Hide</button>
  <button class="btn btn-sm" id="tip-toggle">Toggle</button>
</div>
<div class="tooltip" data-tip="Programmatic tooltip" id="js-tooltip">
  <button class="btn">Target</button>
</div>
<script type="module">
  import { createTooltip } from 'frutjam/js'
  const tip = createTooltip(document.getElementById('js-tooltip'))
  document.getElementById('tip-show').onclick = () => tip.show()
  document.getElementById('tip-hide').onclick = () => tip.hide()
  document.getElementById('tip-toggle').onclick = () => tip.toggle()
</script>
```

```jsx
import { useTooltip } from 'frutjam/react'

export default function TooltipDemo() {
  const tooltip = useTooltip()
  return (
    <>
      <div className="flex gap-2 mb-4">
        <button className="btn btn-sm" onClick={tooltip.show}>Show</button>
        <button className="btn btn-sm" onClick={tooltip.hide}>Hide</button>
        <button className="btn btn-sm" onClick={tooltip.toggle}>Toggle</button>
      </div>
      <div ref={tooltip.ref} className="tooltip" data-tip="Programmatic tooltip">
        <button className="btn">Target</button>
      </div>
    </>
  )
}
```

</Snippet>
