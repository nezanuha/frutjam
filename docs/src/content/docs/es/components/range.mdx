Control deslizante de rango CSS Tailwind solo para CSS con variantes de color primario, secundario, de acento y semántico. Tallas xs-xl. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes de rango permiten a los usuarios seleccionar un valor numérico dentro de un rango definido mediante un control deslizante interactivo. Construidos con entradas de rango HTML nativas y un estilo suave, los controles deslizantes de rango brindan control intuitivo sobre valores continuos. El sistema de gama Frutjam admite múltiples tamaños, colores y estados, ideal para controles de volumen, filtros de precios y limpieza de líneas de tiempo.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.
