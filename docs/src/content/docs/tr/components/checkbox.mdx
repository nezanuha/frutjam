Birincil, ikincil, vurgulu ve anlamsal renk çeşitlerine sahip yalnızca CSS Tailwind CSS onay kutusu. Boyutlar xs-xl, belirsiz durum. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Onay kutusu bileşenleri, kullanıcıların bir kümeden bir veya daha fazla seçeneği seçmesine olanak tanır. Yerel HTML giriş öğeleriyle oluşturulmuş ve Tailwind CSS ile geliştirilmiş onay kutuları birden çok boyutu, rengi ve durumu destekler. Klavye gezintisi ve ekran okuyucu desteğiyle tamamen erişilebilen onay kutuları, formlarda, filtre seçeneklerinde ve izin yönetimi arayüzlerinde sorunsuz bir şekilde çalışır.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.

### Daire / Yuvarlak Onay Kutusu

`checkbox-circle` ve `checkbox-rounded` sınıflarının her ikisi de aynı görsel stille sonuçlanır ve esnek adlandırma kurallarına olanak tanır.

<Snippet>

```html

<input type="checkbox" class="checkbox checkbox-rounded" checked="checked">
```

</Snippet>
