System kolorów Frutjam wykorzystuje semantyczne tokeny CSS zaprojektowane tak, aby od razu spełniać współczynniki kontrastu WCAG AA. Brak JavaScript, obsługa trybu ciemnego, kompatybilność z Tailwind CSS v4. Działa z Django, HTMX, Laravel i dowolnym stosem obsługującym tylko CSS.

Frutjam wykorzystuje niestandardowe właściwości CSS jako tokeny projektu dla wszystkich kolorów. Każdy kolor jest zdefiniowany dla motywu i automatycznie współpracuje z klasami narzędzi CSS Tailwind, bez konieczności dodatkowej konfiguracji. Tylko CSS, nie wymaga JavaScript. Kontrast WCAG AA gwarantowany dla każdej pary kolorów, współpracuje z Django, HTMX, Laravel, React i dowolnym projektem Tailwind CSS v4.

## Nazwy kolorów

Frutjam definiuje następujące semantyczne role kolorów. Każdy kolor ma odpowiednik `on-{color}` token dla dostępnego tekstu na pierwszym planie.

## Skala kolorów (50–950)

Każdy kolor generuje 11-stopniową skalę obliczoną na podstawie głównych zmiennych motywu `color-mix()` w OKLCH, a nie w czasie kompilacji. Set a brand color and all eleven steps follow from it, so you never set them by hand.

Każdy krok jest jednocześnie zmienną CSS i narzędziem Tailwind: użyj `var(--color-primary-700)` we własnym CSS lub `bg-primary-700` w znacznikach. Najedź kursorem na próbkę, aby zobaczyć oba imiona.

<ColorScale />

Ponieważ kroki są obliczane na podstawie motywu, a nie zakodowane na stałe, ta siatka nie jest obrazem kolorów Frutjama. To Twoje kolory. Zmień motyw, a każda powyższa próbka przesunie się wraz z nim, dlatego też obok nich nie są drukowane żadne wartości szesnastkowe.

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

## Zajęcia z użyteczności kolorów

Wszystkie kolory Frutjam współpracują z dowolnym narzędziem do tworzenia kolorów CSS Tailwind. Zastępować `{color}` z dowolną nazwą koloru z tabeli powyżej, opcjonalnie z krokiem ze skali 50-950: `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Klasa | Opis |
| --- | --- |
| `bg-{color}` | Kolor tła |
| `text-{color}` | Kolor tekstu |
| `border-{color}` | Kolor obramowania |
| `ring-{color}` | Kolor pierścionka |
| `outline-{color}` | Kolor konturu |
| `shadow-{color}` | Kolor cienia |
| `fill-{color}` | Kolor wypełnienia SVG |
| `stroke-{color}` | Kolor obrysu SVG |
| `decoration-{color}` | Kolor dekoracji tekstu |
| `caret-{color}` | Wprowadź kolor karetki |
| `placeholder-{color}` | Kolor tekstu zastępczego |
| `divide-{color}` | Kolor obramowania rozdzielacza |
| `{utility}-{color}-{step}` | Na przykład dowolne z powyższych w kroku skali `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### Modyfikator krycia

Kontroluj przezroczystość kolorów za pomocą `/{value}` modyfikator, tak jak każdy kolor Tailwind.

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## Miękkie i aktywne

Warianty świadome stanu elementów interaktywnych, automatycznie dostosowujące się do jasnych i ciemnych motywów.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Zmienna CSS | Opis |
| --- | --- |
| `--color-{color}-soft` | Subtelnie przyciemnione tło dla miękkich wariantów |
| `--color-on-{color}-soft` | Kolor tekstu do stosowania na miękkim tle |
| `--color-{color}-active` | Przyciemniony/rozjaśniony odcień dla stanów najechania i aktywności |
| `--color-body` | Obliczony kolor tekstu podstawowego (nieco zmiękczony z `on-base`) |

</DocTable>

## Zmienne CSS motywu

Są to tokeny główne, które definiujesz podczas tworzenia niestandardowego motywu. Wszystkie inne żetony kolorów są obliczane automatycznie na ich podstawie.

| `--color-base` | Kolor tła strony |
| `--color-on-base` | Domyślny kolor tekstu na tle bazowym |
| `--color-neutral` | Neutralny kolor powierzchni |
| `--color-on-neutral` | Kolor tekstu na neutralnych powierzchniach |
| `--color-primary` | Podstawowy kolor marki |
| `--color-on-primary` | Kolor tekstu na tle podstawowym |
| `--color-secondary` | Kolor drugorzędny marki |
| `--color-on-secondary` | Kolor tekstu na tle wtórnym |
| `--color-accent` | Kolor akcentujący |
| `--color-on-accent` | Kolor tekstu na akcentowanym tle |
| `--color-info` | Kolor informacji |
| `--color-on-info` | Kolor tekstu na tłach informacyjnych |
| `--color-success` | Kolor sukcesu |
| `--color-on-success` | Kolor tekstu na tle sukcesu |

## Przykład niestandardowego motywu

Zastąp tokeny root, aby utworzyć niestandardowy motyw. Frutjam automatycznie oblicza wszystkie skale i stany.

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
