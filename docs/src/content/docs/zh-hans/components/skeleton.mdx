纯 CSS Tailwind CSS 骨架加载器，用于占位符 UI。带有脉冲动画的圆形、矩形和文本线形状。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

骨架组件在内容加载时显示占位符布局，提供视觉反馈并提高感知性能。骨架屏幕采用语义 HTML 和脉冲动画构建，可防止布局变化并设定用户期望。 Frutjam 骨架系统支持多种形状和尺寸，非常适合内容预览、渐进加载和优雅降级。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。
