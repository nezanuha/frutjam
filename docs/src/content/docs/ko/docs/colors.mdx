Frutjam의 색상 시스템은 기본적으로 WCAG AA 명암비를 충족하도록 설계된 시맨틱 CSS 토큰을 사용합니다. JavaScript가 없고 어두운 모드를 인식하며 Tailwind CSS v4와 호환됩니다. Django, HTMX, Laravel 및 모든 CSS 전용 스택에서 작동합니다.

Frutjam은 모든 색상에 대한 디자인 토큰으로 CSS 사용자 정의 속성을 사용합니다. 모든 색상은 테마별로 정의되며 Tailwind CSS 유틸리티 클래스와 자동으로 작동하므로 추가 구성이 필요하지 않습니다. CSS 전용이며 JavaScript가 필요하지 않습니다. 모든 색상 쌍에서 WCAG AA 대비가 보장되며 Django, HTMX, Laravel, React 및 모든 Tailwind CSS v4 프로젝트에서 작동합니다.

## 색상 이름

Frutjam은 다음과 같은 의미적 색상 역할을 정의합니다. 각 색상마다 어울리는 색상이 있습니다. `on-{color}` 접근 가능한 전경 텍스트를 위한 토큰입니다.

| <span class="badge badge-sm badge-info">정보</span> | `--color-info` | 정보 메시지 |

## 색상 스케일(50-950)

모든 색상은 다음을 사용하여 루트 테마 변수에서 계산된 11단계 척도를 생성합니다. `color-mix()` 빌드 타임이 아닌 OKLCH에서. 브랜드 색상을 설정하면 11단계가 모두 그에 따라 진행되므로 수동으로 설정할 필요가 없습니다.

각 단계는 CSS 변수이자 Tailwind 유틸리티입니다. `var(--color-primary-700)` 자신의 CSS에서 또는 `bg-primary-700` 마크업에서. 두 이름을 모두 보려면 견본을 마우스로 가리키세요.

<ColorScale />

단계는 하드 코딩되지 않고 테마에서 계산되므로 이 그리드는 Frutjam의 색상 그림이 아닙니다. 그것은 당신의 색깔입니다. 테마를 전환하면 위의 모든 견본이 함께 이동하므로 옆에 16진수 값이 인쇄되지 않습니다.

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

<RawHtml html={"<div class=\"not-prose\"><div role=\"alert\" class=\"alert alert-sm alert-warning alert-soft mt-6\"><span><strong>단계는 장식용이지 본문용이 아닙니다.</strong> 배율 단계에 일치하는 항목이 없습니다. <code>on-</code> 색상이므로 대비를 보장할 수 있는 것은 없습니다. 텍스트가 색상 위에 있으면 라이브러리가 테스트하는 쌍을 사용하십시오. <code>bg-primary</code> ~와 함께 <code>text-on-primary</code>.</span></div></div>"} />

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 변수 | 설명 |
| --- | --- |
| `--color-{color}-50` | 밝은색 80%, 색상 20% |
| `--color-{color}-100` | 밝기 65%, 색상 35% |
| `--color-{color}-200` | 50% 빛, 50% 색상 |
| `--color-{color}-300` | 밝기 35%, 색상 65% |
| `--color-{color}-400` | 밝기 18%, 색상 82% |
| `--color-{color}-500` | 색상 자체는 동일합니다 `--color-{color}` |
| `--color-{color}-600` | 어두운 색조 18%, 컬러 82% |
| `--color-{color}-700` | 34% 어두움, 66% 컬러 |
| `--color-{color}-800` | 50% 어두움, 50% 컬러 |
| `--color-{color}-900` | 65% 어두움, 35% 컬러 |
| `--color-{color}-950` | 80% 어두움, 20% 컬러 |

</DocTable>

## 색상 유틸리티 클래스

모든 Frutjam 색상은 Tailwind CSS 색상 유틸리티와 함께 ​​작동합니다. 바꾸다 `{color}` 위 표의 색상 이름을 사용하고 선택적으로 50-950 범위의 단계가 뒤에 올 수 있습니다. `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| 수업 | 설명 |
| --- | --- |
| `bg-{color}` | 배경색 |
| `text-{color}` | 텍스트 색상 |
| `border-{color}` | 테두리 색상 |
| `ring-{color}` | 링 색상 |
| `outline-{color}` | 외곽선 색상 |
| `shadow-{color}` | 그림자 색상 |
| `fill-{color}` | SVG 채우기 색상 |
| `stroke-{color}` | SVG 스트로크 색상 |
| `decoration-{color}` | 텍스트 장식 색상 |
| `caret-{color}` | 캐럿 색상 입력 |
| `placeholder-{color}` | 자리 표시자 텍스트 색상 |
| `divide-{color}` | 구분선 테두리 색상 |
| `{utility}-{color}-{step}` | 예를 들어 규모 단계에서 위의 항목 중 하나 `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### 불투명도 수정자

색상 불투명도를 제어합니다. `/{value}` Tailwind 색상과 마찬가지로 수정자입니다.

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## 소프트 & 액티브

밝은 테마와 어두운 테마에 자동으로 적응하는 대화형 요소에 대한 상태 인식 변형입니다.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 변수 | 설명 |
| --- | --- |
| `--color-{color}-soft` | 부드러운 변형을 위한 미묘한 색조의 배경 |
| `--color-on-{color}-soft` | 부드러운 배경에 사용할 텍스트 색상 |
| `--color-{color}-active` | 호버 및 활성 상태에 대한 어둡거나 밝은 음영 |
| `--color-body` | 계산된 본문 텍스트 색상(약간 부드러워짐) `on-base`) |

</DocTable>

## 테마 CSS 변수

이는 사용자 정의 테마를 생성할 때 정의하는 루트 토큰입니다. 다른 모든 색상 토큰은 이들로부터 자동으로 계산됩니다.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 변수 | 설명 |
| --- | --- |
| `--scheme-color` | 색 구성표: `light` 또는 `dark` |
| `--border-radius` | 구성요소의 기본 테두리 반경 |
| `--color-base` | 페이지 배경색 |
| `--color-on-base` | 기본 배경의 기본 텍스트 색상 |
| `--color-neutral` | 중립 표면 색상 |
| `--color-on-neutral` | 중립 표면의 텍스트 색상 |
| `--color-primary` | 기본 브랜드 색상 |
| `--color-on-primary` | 기본 배경의 텍스트 색상 |
| `--color-secondary` | 보조 브랜드 색상 |
| `--color-on-secondary` | 보조 배경의 텍스트 색상 |
| `--color-accent` | 악센트 색상 |
| `--color-on-accent` | 강조 배경의 텍스트 색상 |
| `--color-info` | 정보 색상 |
| `--color-on-info` | 정보 배경의 텍스트 색상 |
| `--color-success` | 성공 색상 |
| `--color-on-success` | 성공 배경의 텍스트 색상 |
| `--color-warning` | 경고 색상 |
| `--color-on-warning` | 경고 배경의 텍스트 색상 |
| `--color-error` | 오류 색상 |
| `--color-on-error` | 오류 배경의 텍스트 색상 |

</DocTable>

## 사용자 정의 테마 예

사용자 정의 테마를 생성하려면 루트 토큰을 재정의하세요. Frutjam은 모든 스케일과 상태를 자동으로 계산합니다.

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
