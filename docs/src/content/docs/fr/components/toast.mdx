Toast CSS Tailwind CSS uniquement pour le positionnement des notifications : positionnement en haut, en bas, en début, en fin et au centre. Pas de JavaScript pour la mise en page. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants Toast affichent des notifications brèves et non intrusives positionnées sur les bords de l'écran. Construits avec des composants de positionnement et d'alerte fixes, les toasts communiquent les commentaires du système tels que les confirmations de succès, les messages d'erreur ou les mises à jour de statut. Le système de pain grillé Frutjam prend en charge six positions de placement, idéal pour les soumissions de formulaires, les opérations asynchrones et les notifications en temps réel.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework : fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

## Utilisation de base

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## Animation d’entrée

Chaque toast s'estompe et se met en place tout seul. Il n'y a rien à ajouter pour cela, et aucune classe pour l'activer.

La `toast-slide-*` les modificateurs sont pour quand vous voulez une direction différente de la montée par défaut. Choisissez le bord sur lequel repose le pain grillé, de sorte qu'il pénètre de l'extérieur de l'écran plutôt que de le traverser : `toast-slide-end` appartient à `toast-end`, `toast-slide-down` avec `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

La distance est la largeur ou la hauteur du pain grillé, et non la distance jusqu'au bord de l'écran, de sorte qu'un pain grillé centré commence près du milieu plutôt qu'en dehors de l'écran.

Il n'y a pas d'animation de sortie. Un toast disparaît au moment où il est supprimé de la page, car CSS n'a pas d'état de transition. Fading one out signifie le garder dans le Dom et l'animer soi-même.

L'animation est ignorée pour tous ceux qui ont demandé un mouvement réduit.

## Largeur

Chaque toast est plafonné à `24rem` afin qu'un message long ne s'étende pas sur un écran de téléphone. Remplacer `--toast--width` pour le changer.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
