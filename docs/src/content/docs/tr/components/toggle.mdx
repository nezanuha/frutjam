Yalnızca CSS'ye özgü Tailwind Birincil, ikincil, vurgulu ve anlamsal renk çeşitleriyle CSS geçiş anahtarı. Boyutlar xs-xl. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Geçiş bileşenleri, kullanıcıların özellikleri veya ayarları açıp kapatmasına olanak tanıyan ikili anahtarlardır. Yerel HTML onay kutusu girişleriyle oluşturulmuş ve Tailwind CSS animasyonlarıyla geliştirilmiş geçişler, boole durumlarını kontrol etmek için sezgisel bir yol sağlar. Frutjam geçiş sistemi birden fazla rengi, boyutu ve devre dışı bırakma durumunu destekler; ayar panelleri, özellik bayrakları ve tercih kontrolleri için mükemmeldir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
