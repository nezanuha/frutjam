Frutjam 的顏色系統使用語義 CSS 標記，旨在滿足開箱即用的 WCAG AA 對比。無需 JavaScript，支援深色模式，相容於 Tailwind CSS v4。適用於 Django、HTMX、Laravel 和任何純 CSS 堆疊。

Frutjam 使用 CSS 自訂屬性作為所有顏色的設計標記。每種顏色都是根據主題定義的，並自動與 Tailwind CSS 實用程式類別一起使用，無需額外配置。僅 CSS，無需 JavaScript。 WCAG AA 對比度保證每個顏色對，適用於 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 專案。

## 顏色名稱

Frutjam 定義了以下語意顏色角色。每個顏色都有一個搭配 `on-{color}` 可存取前景文字的標記。

## 色階 (50–950)

每種顏色都會產生 11 級比例，根據您的根主題變數計算得出 `color-mix()` 在 OKLCH 中而不是在構建時。設定品牌顏色後，所有十一個步驟都會隨之而來，因此您無需手動設定它們。

每個步驟都是一個 CSS 變數和一個 Tailwind 實用程式：使用 `var(--color-primary-700)` 在你自己的 CSS 中，或者 `bg-primary-700` 在標記中。將滑鼠懸停在樣本上即可查看兩個名字。

<ColorScale />

因為這些步驟是根據您的主題計算的，而不是硬編碼的，所以該網格不是 Frutjam 顏色的圖片。這是你的顏色。切換主題，上面的每個樣本都會隨之移動，這也是為什麼它們旁邊沒有列印十六進位值的原因。

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

| `--color-{color}-700` | 34% 深色，66% 彩色 |

## 顏色實用程式類

所有 Frutjam 顏色均可與任何 Tailwind CSS 顏色實用程式搭配使用。代替 `{color}` 使用上表中的任何顏色名稱，可選地後跟 50-950 範圍內的一個步驟： `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| 班級 | 描述 |
| --- | --- |
| `bg-{color}` | 背景顏色 |
| `text-{color}` | 文字顏色 |
| `border-{color}` | 邊框顏色 |
| `ring-{color}` | 戒指顏色 |
| `outline-{color}` | 輪廓顏色 |
| `shadow-{color}` | 陰影顏色 |
| `fill-{color}` | SVG 填滿顏色 |
| `stroke-{color}` | SVG 描邊顏色 |
| `decoration-{color}` | 文字裝飾顏色 |
| `caret-{color}` | 輸入插入符號顏色 |
| `placeholder-{color}` | 佔位符文字顏色 |
| `divide-{color}` | 分隔線邊框顏色 |
| `{utility}-{color}-{step}` | 例如，在縮放步驟中的任何上述內容 `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### 阻光度修飾符

使用來控制顏色不透明度 `/{value}` 修改器，就像任何順風顏色一樣。

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## Soft & Active

交互式元素的狀態感知變體，可自動適應亮色和暗色主題。

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 變數 | 描述 |
| --- | --- |
| `--color-{color}-soft` | 柔和變體的微妙色調背景 |
| `--color-on-{color}-soft` | 適用於柔和背景的文字顏色 |
| `--color-{color}-active` | 調暗/調亮陰影，適用於懸停和活動狀態 |
| `--color-body` | 計算正文文字顏色（略微軟化自 `on-base`) |

</DocTable>

## 佈景主題CSS變數

這些是建立自訂佈景主題時定義的根權杖。所有其他顏色代幣都是從這些代幣自動計算出來的。

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 變數 | 描述 |
| --- | --- |
| `--scheme-color` | 配色方案: `light` 或 `dark` |
| `--border-radius` | 元件的基本邊框半徑 |
| `--color-base` | 網頁背景顏色 |
| `--color-on-base` | 基本背景上的預設文字顏色 |
| `--color-neutral` | 中性表面顏色 |
| `--color-on-neutral` | 中性表面上的文字顏色 |
| `--color-primary` | 主要品牌顏色 |
| `--color-on-primary` | 主要背景上的文字顏色 |
| `--color-secondary` | 次品牌色 |
| `--color-on-secondary` | 次要背景上的文字顏色 |
| `--color-accent` | 強調色 |
| `--color-on-accent` | 強調背景上的文字顏色 |
| `--color-info` | 訊息顏色 |
| `--color-on-info` | 資訊背景上的文字顏色 |
| `--color-success` | 成功顏色 |
| `--color-on-success` | 成功背景上的文字顏色 |
| `--color-warning` | 警告顏色 |
| `--color-on-warning` | 警告背景上的文字顏色 |
| `--color-error` | 錯誤訊息內容色彩 |
| `--color-on-error` | 錯誤背景上的文字顏色 |

</DocTable>

## 自訂佈景主題範例

覆蓋根權杖以創建自定義主題。Frutjam會自動計算所有比例和狀態。

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
