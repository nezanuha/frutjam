僅 CSS Tailwind CSS 步驟用於多步驟精靈和進度指示器。水平和垂直佈局，每個步驟的顏色變化。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

步驟組件透過顯示連續階段來視覺化多步驟流程、指南或工作流程。步驟採用語意 HTML 和靈活的佈局構建，透過設定精靈、教學課程和複雜的過程顯示進度。 Frutjam 步驟系統支援多種尺寸、顏色、結構和完成狀態，非常適合表單精靈、安裝指南和進度追蹤。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
