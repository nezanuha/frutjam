CSS 전용 Tailwind CSS 별표 및 심박수 구성 요소입니다. xs-xl 크기, 별표 1/2개 지원, JavaScript가 필요하지 않습니다. WCAG AA 액세스 가능하며 Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.

등급 구성 요소를 사용하면 사용자는 제품, 서비스 또는 콘텐츠에 별표 또는 숫자 등급을 지정하여 피드백을 제공할 수 있습니다. 시맨틱 HTML 입력과 대화형 스타일로 구축된 평가는 사용자 만족도와 품질 피드백을 전달합니다. Frutjam 등급 시스템은 다양한 스타일, 색상 및 크기를 지원하므로 제품 리뷰, 사용자 피드백 양식 및 만족도 설문조사에 이상적입니다.

CSS 전용이며 JavaScript가 필요하지 않습니다. WCAG AA 액세스 가능 및 프레임워크에 구애받지 않음 — Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.
