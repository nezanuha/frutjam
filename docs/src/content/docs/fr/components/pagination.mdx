Pagination CSS Tailwind uniquement CSS pour les pages numérotées, les flèches précédent/suivant, les points de suspension, les entrées radio accessibles et une sélection de saut de page. Aucun JavaScript requis. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants de pagination permettent aux utilisateurs de naviguer entre les pages de contenu : résultats de recherche, tableaux de données, archives d'articles et listes de produits. Construite en composant les composants [Join](/components/join) et [Button](/components/button), la pagination Frutjam ne nécessite ni JavaScript ni CSS supplémentaire. Prend en charge les pages numérotées, les flèches précédent/suivant, les espaces de points de suspension, les entrées radio accessibles et une sélection de saut de page.

CSS uniquement, aucun JavaScript requis : créez une pagination accessible avec du HTMX pur et du CSS Tailwind. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React, Next.js et n'importe quelle pile.

## Pagination de base

Une bande de pages numérotées avec une page active. Appliquez **btn-active** pour mettre en surbrillance la page actuelle. Utilisez des balises d'ancrage au lieu de boutons pour les liens de page rendus par le serveur.

<Snippet>

```html
<div class="join">
  <button class="join-item btn">1</button>
  <button class="join-item btn btn-active">2</button>
  <button class="join-item btn">3</button>
  <button class="join-item btn">4</button>
  <button class="join-item btn">5</button>
</div>
```

```jsx

</div>
```

</Snippet>

### Avec points de suspension

Utilisez **btn-disabled** pour les points de suspension entre une large gamme de pages. Les lecteurs d'écran ignorent les boutons désactivés, alors associez-les à `aria-hidden="true"` sur les points de suspension.

<Snippet>

```html
<div class="join">
  <button class="join-item btn">1</button>
  <button class="join-item btn">2</button>
  <button class="join-item btn btn-disabled" aria-hidden="true">...</button>
  <button class="join-item btn btn-active">12</button>
  <button class="join-item btn btn-disabled" aria-hidden="true">...</button>
  <button class="join-item btn">99</button>
  <button class="join-item btn">100</button>
</div>
```


## Pagination radio accessible

Utilisez les entrées `type="radio"` comme éléments de jointure pour une sélection de page entièrement navigable au clavier, uniquement en CSS, sans JavaScript. Chaque entrée agit comme un bouton pressable tout en conservant l’état sélectionné dans son état natif.

<Snippet>

```html
<div class="join">
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="1" />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="2" checked />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="3" />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="4" />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="5" />
</div>
```

```jsx
<div className="join">
  <input className="join-item btn btn-square" type="radio" name="page" aria-label="1" />
  <input className="join-item btn btn-square" type="radio" name="page" aria-label="2" defaultChecked />
  <input className="join-item btn btn-square" type="radio" name="page" aria-label="3" />
  <input className="join-item btn btn-square" type="radio" name="page" aria-label="4" />
  <input className="join-item btn btn-square" type="radio" name="page" aria-label="5" />
</div>
```

</Snippet>

## Pagination avec saut de page

Combinez la jointure, les boutons et la sélection pour obtenir une barre de pagination compacte qui permet aux utilisateurs d'accéder directement à n'importe quelle page, ce qui est courant dans les tableaux de bord d'administration, les interfaces CMS et les applications gourmandes en données. Aucun JavaScript requis pour la sélection elle-même ; associez-le à HTMX ou à un formulaire soumis pour la navigation côté serveur.

<Snippet>

```html
<div class="join">
  <button class="join-item btn btn-sm" aria-label="Previous page">‹</button>
  <select class="join-item select select-sm" aria-label="Go to page">
    <option>Page 1</option>
    <option>Page 2</option>
    <option selected>Page 3</option>
    <option>Page 4</option>
    <option>Page 5</option>
  </select>
  <button class="join-item btn btn-sm" aria-label="Next page">›</button>
</div>
```

```jsx
<div className="join">
  <button className="join-item btn btn-sm" aria-label="Previous page">‹</button>
  <select className="join-item select select-sm" aria-label="Go to page">
    <option>Page 1</option>
    <option>Page 2</option>
    <option>Page 3</option>
    <option>Page 4</option>
    <option>Page 5</option>
  </select>
  <button className="join-item btn btn-sm" aria-label="Next page">›</button>
</div>
```

</Snippet>
