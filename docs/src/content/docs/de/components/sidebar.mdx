Nur CSS-Tailwind-CSS-Seitenleiste für seitliche Navigationsfelder. Zusammenklappbar, mit Navigationselementstatus und Abschnittsüberschriften. WCAG AA zugänglich, funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

Seitenleistenkomponenten organisieren die primäre Navigation und Hilfsinhalte in einem festen oder reduzierbaren Seitenbereich. Mit semantischem HTML erstellte Seitenleisten verbessern die Navigation, ohne den Hauptinhaltsraum zu beanspruchen. Das Frutjam-Seitenleistensystem unterstützt mehrere Layouts, Breiten und Verhaltensweisen – ideal für Admin-Dashboards, Dokumentationsseiten und komplexe Anwendungen.

Nur CSS, kein JavaScript erforderlich. WCAG AA zugänglich und Framework-unabhängig – funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

## Grundlegende Verwendung

Verwenden Sie die Klasse `sidebar` für ein `aside`\-Element. Platzieren Sie es neben Ihrem Hauptinhalt in einem flexiblen Container.

<Snippet>

```html
<div class="flex min-h-90">
  <aside class="sidebar w-64">
    <ul class="menu p-4">
      <li class="menu-title"><span>Menu</span></li>
      <li><a class="menu-item">Sidebar Item 1</a></li>
      <li><a class="menu-item">Sidebar Item 2</a></li>
      <li><a class="menu-item">Sidebar Item 3</a></li>
    </ul>
  </aside>
  <main class="flex-1 p-6">
    <p class="para-base">Main content area</p>
  </main>
</div>
```

## Seitenleistennavigation

Eine vollständige Navigationsseitenleiste mit gruppierten Abschnitten und aktivem Statusstil.

<Snippet>

```html
<div class="flex min-h-105">
  <aside class="sidebar w-64">
    <ul class="menu p-4">
      <li class="menu-title"><span>Dashboard</span></li>
      <li><a class="menu-item menu-item menu-active">Overview</a></li>
      <li><a class="menu-item">Analytics</a></li>
      <li class="menu-title mt-4"><span>Management</span></li>
      <li><a class="menu-item">Users</a></li>
      <li><a class="menu-item">Inventory</a></li>
      <li><a class="menu-item">Settings</a></li>
    </ul>
  </aside>
  <main class="flex-1 p-6">
    <h2 class="heading-2xl">Overview</h2>
    <p class="para-base mt-2">Page content goes here.</p>
  </main>
</div>
```

</Snippet>

## Zusammenklappbare Seitenleiste

Kombinieren Sie für mobile oder Overlay-Seitenleisten die Klasse `sidebar` mit der Dialogkomponente `drawer drawer-start`.

<Snippet>

```html
<button type="button" class="btn btn-primary btn-sm" onclick="sidebarDrawer.show()">Open Sidebar</button>

<dialog class="drawer drawer-start" id="sidebarDrawer">
  <div class="drawer-content">
    <aside class="sidebar h-full w-64">
      <ul class="menu p-4">
        <li class="menu-title"><span>Dashboard</span></li>
        <li><a class="menu-item">Home</a></li>
        <li><a class="menu-item">Profile</a></li>
        <li><a class="menu-item">Settings</a></li>
        <li><a class="menu-item">Logout</a></li>
      </ul>
    </aside>
  </div>
  <button type="button" class="drawer-backdrop" onclick="sidebarDrawer.close()">Close Sidebar via Backdrop</button>
</dialog>
```

</Snippet>
