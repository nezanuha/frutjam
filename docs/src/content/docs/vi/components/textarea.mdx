## Trình chỉnh sửa đánh dấu nâng cao

Sử dụng `markdown-text-editor` để biến bất kỳ vùng văn bản nào thành trình chỉnh sửa đánh dấu đầy đủ. Có hai chế độ: **plain** (cú pháp Markdown thô) và **hybrid** (hiển thị định dạng trực tiếp khi bạn nhập). Để biết thêm tùy chọn cấu hình, hãy xem [tài liệu về plugin](https://frutjam.com/plugins/markdown-editor).

### Chế độ đơn giản

Hiển thị cú pháp Markdown thô. Người dùng viết Markdown trực tiếp trong vùng văn bản.

<Snippet>

```html
<textarea id="plain-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#plain-markdown-editor');
```

</Snippet>

### Chế độ kết hợp

Hiển thị định dạng trực tiếp khi bạn nhập — in đậm, tiêu đề, danh sách, v.v. xuất hiện theo kiểu nội tuyến.

<Snippet>

```html
<textarea id="hybrid-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#hybrid-markdown-editor', { mode: 'hybrid' });
```

</Snippet>
