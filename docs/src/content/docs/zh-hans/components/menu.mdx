仅限 CSS Tailwind CSS 导航列表垂直菜单。活动、禁用和图标项目状态。尺寸变体。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

菜单组件显示有组织的操作或导航选项列表。 Frutjam 菜单系统采用语义 HTML 列表和链接元素构建，支持垂直和水平布局、嵌套菜单、图标和活动状态。菜单完全可以通过键盘导航进行访问，与下拉菜单、侧边栏和上下文导航模式无缝集成。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。
