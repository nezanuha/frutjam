Kartu CSS Tailwind khusus CSS dengan gaya kerangka, bayangan, dan datar. Ukuran ringkas, standar, dan besar. Isi kartu, judul kartu, slot kaki kartu. WCAG AA, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen kartu adalah wadah serbaguna untuk menggabungkan informasi terkait menjadi satu unit yang kohesif secara visual. Dibangun dengan HTML semantik dan area konten yang fleksibel, kartu mengatur konten secara hierarki dan beradaptasi dengan berbagai tata letak. Sistem kartu Frutjam menawarkan berbagai varian warna, ukuran, dan gaya untuk etalase produk, postingan blog, testimonial, dan elemen dasbor.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Kartu dengan Tindakan
