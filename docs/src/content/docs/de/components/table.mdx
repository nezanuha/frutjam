Nur CSS-Tailwind-CSS-Tabelle mit Zebrastreifen, kompakten und Standardgrößen, angehefteten Spalten und Zeilen-Hover-Zuständen. WCAG AA zugänglich, funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

Tabellenkomponenten organisieren und zeigen strukturierte Daten in Zeilen und Spalten an. Tabellen basieren auf semantischen HTML-Tabellenelementen und Tailwind-CSS-Stil und unterstützen Sortierung, gestreifte Zeilen, Hover-Effekte und reaktionsfähige Überlaufbehandlung. Auf das Frutjam-Tabellensystem kann mit geeigneten Header-Zuordnungen zugegriffen werden und es funktioniert nahtlos mit Datenvisualisierungs-Frameworks.

Nur CSS, kein JavaScript erforderlich. WCAG AA zugänglich und Framework-unabhängig – funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

### Tabelle extra klein `(table-xs)`

Im folgenden Beispiel für die Tabellengröße verwenden wir `table-xs` (extra klein). Sie können die Tabellengröße mithilfe der Dienstprogrammklassen `table-{size}` anpassen, einschließlich `table-xs`, `table-sm`, `table-md`, `table-lg` und `table-xl`, die von besonders kompakten Layouts bis hin zu geräumigeren, lesbareren Tabellen reichen.
