Yalnızca CSS'ye özgü Tailwind CSS sayfa başlığı — marka, gezinme ve eylem yuvalarını içeren üst çubuk düzeni. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Başlık bileşenleri, web siteniz veya uygulamanız için tutarlı üst gezinme ve markalama alanları oluşturur. Anlamsal HTML başlık öğeleriyle oluşturulan Frutjam başlık sistemi, logoları, gezinme bağlantılarını ve kullanıcı eylemlerini uyumlu, duyarlı bir çubukta birleştirir. Birden fazla düzeni, hizalama seçeneğini destekler ve açılır menüler ve arama işlevleriyle sorunsuz bir şekilde bütünleşir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
