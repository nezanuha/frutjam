Installieren Sie Frutjam, die reine CSS-UI-Bibliothek von Tailwind, in wenigen Minuten. Zwei Importe, kein JavaScript, WCAG-zugängliche Komponenten sofort einsatzbereit. Funktioniert mit Django, HTMX, Laravel, React und jedem Tailwind CSS v4-Projekt.

## Wie installiere ich die Frutjam-UI-Bibliothek im Tailwind-CSS-Projekt?

Stellen Sie sicher, dass Sie über eine funktionierende verfügen [Rückenwind-CSS](https://tailwindcss.com/docs/installation/using-vite) Projekt installiert, sowie [Knoten](https://nodejs.org/en/download) und NPM auf Ihrem Computer. Frutjam funktioniert mit Tailwind Version 4.

### Installieren Sie frutjam als Node-Paket, indem Sie den folgenden Befehl ausführen:

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Fügen Sie Frutjam zu Ihrem hinzu `input.css` mit der `@plugin` Direktive:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

## Ohne Rückenwind: UnoCSS, Vite, Astro oder einfaches CSS

Frutjam wird mit Tailwind erstellt, aber die Komponenten werden zu gewöhnlichem CSS kompiliert, das benutzerdefinierte Eigenschaften liest. Wenn Ihr Projekt UnoCSS oder überhaupt keine Utility-Engine verwendet, importieren Sie das Stylesheet anstelle des Plugins:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Das ist der ganze Aufbau. Jede Komponentenklasse funktioniert, die Themen wechseln mit `data-theme` wie gewohnt, es ist nichts anderes erforderlich. Es ist 30 KB groß und enthält die Basisstile, beide Themen und alle über 65 Komponenten.

Ziehen Sie stattdessen nur das ein, was Sie brauchen:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

Oder ganz ohne Build-Schritt:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## JavaScript & Reagieren: Optional, nicht erforderlich

Frutjam ist **Native-First und CSS-First**. Die überwiegende Mehrheit der Komponenten: Schaltflächen, Abzeichen, Karten, Formulare, Benachrichtigungen und mehr: funktionieren mit reinem HTML und CSS, kein JavaScript erforderlich. Native HTML-Elemente wie `<dialog>`, `<details>`, Und `<input type="checkbox">` Bewältigen Sie die Interaktivität dort, wo Browser sie bereits unterstützen. Alle Komponenten sind sofort einsatzbereit und funktionieren mit Django, HTMX, Laravel, React, Next.js und jedem Stack.

Für eine kleine Anzahl von Komponenten gibt es kein natives HTML-Äquivalent (Toast-Benachrichtigungen, Combobox-Filterung, Karussell-Steuerelemente). Nur für diese Fälle liefert Frutjam leichte optionale Helfer mit.

### Vanille JS: `frutjam/js`

Framework-unabhängige ES-Modulhelfer für die Komponenten, die sie benötigen. An ein beliebiges DOM-Element anhängen, kein Framework erforderlich.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Reaktionshaken: `frutjam/react`

Thin React-Wrapper um dieselben nativen DOM-Aufrufe. Jeder Hook gibt a zurück `ref` Sie fügen dem Element und Methoden hinzu, um es zu steuern, keine zusätzlichen Abhängigkeiten über React selbst hinaus.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Verfügbar für: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.

### Verwendung eines CDN

Nutzen Sie die CDN-Version der frutjam-UI-Bibliothek für eine schnelle und einfache Integration ohne lokale Einrichtung. Verwenden Sie diese CDN-Version von frutjam nur für Entwicklungszwecke, nicht in der Produktion.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>
