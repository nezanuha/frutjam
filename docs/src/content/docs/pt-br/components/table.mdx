Tabela CSS Tailwind somente CSS com listras de zebra, tamanhos compactos e padrão, colunas fixadas e estados de foco de linha. WCAG AA acessível, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes da tabela organizam e exibem dados estruturados em linhas e colunas. Construídas com elementos de tabela HTML semânticos e estilo Tailwind CSS, as tabelas suportam classificação, linhas distribuídas, efeitos de foco e manipulação de overflow responsivo. O sistema de tabelas Frutjam é acessível com associações de cabeçalho adequadas e funciona perfeitamente com estruturas de visualização de dados.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.

## Tamanhos de mesa

### Tabela extra pequena `(table-xs)`

No exemplo de tamanho de tabela abaixo, usamos `table-xs` (extra pequeno). Você pode ajustar o tamanho da tabela usando as classes utilitárias `table-{size}`, incluindo `table-xs`, `table-sm`, `table-md`, `table-lg` e `table-xl`, que variam de layouts extracompactos a tabelas mais espaçosas e legíveis.
