CSS-only Tailwind CSS toast for notification positioning: top, bottom, start, end, and center placement. No JavaScript for layout. WCAG AA accessible, works with Django, HTMX, Laravel, React, and any stack.

Toast components display brief, non-intrusive notifications positioned at the edges of the screen. Built with fixed positioning and alert components, toasts communicate system feedback like success confirmations, error messages, or status updates. The Frutjam toast system supports six placement positions, ideal for form submissions, async operations, and real-time notifications.

CSS-only, no JavaScript required. WCAG AA accessible and framework-agnostic: works with Django, HTMX, Laravel, React, and any stack.

## Basic Usage

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

### Centered

A horizontal and a vertical modifier combine, so `toast-center toast-middle` puts a toast in the middle of the screen.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-middle toast-center">
  <div class="alert alert-info"><span>Middle Center</span></div>
</div>
```

</Snippet>

## Entry Animation

Every toast fades and rises into place on its own. There is nothing to add for that, and no class to turn it on.

The `toast-slide-*` modifiers are for when you want a different direction from the default rise. Pick the edge the toast sits on, so it enters from outside the screen rather than across it: `toast-slide-end` belongs with `toast-end`, `toast-slide-down` with `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

The distance is the toast's own width or height, not the distance to the edge of the screen, so a centered toast starts near the middle rather than off-screen.

There is no exit animation. A toast disappears the moment it is removed from the page, because CSS has no state to transition out of. Fading one out means keeping it in the DOM and animating it yourself.

The animation is skipped for anyone who has asked for reduced motion.

## Width

Each toast is capped at `24rem` so a long message does not span a phone screen. Override `--toast--width` to change it.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
