Componente de burbuja de chat CSS Tailwind solo para CSS. Posiciones inicial y final para mensajes enviados y recibidos, con avatar y espacios de marca de tiempo. WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes de chat muestran mensajes conversacionales en un formato organizado y legible. Construidas con HTML semántico y diseños flexibles, las burbujas de chat representan mensajes tanto del usuario como del sistema. El sistema de chat Frutjam admite múltiples colores, alineaciones y estilos, ideal para interfaces de mensajería, paneles de atención al cliente y UI conversacional.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.
