Paginacja CSS Tailwind tylko dla CSS dla ponumerowanych stron, strzałek poprzedniej/następnej, przerw w wielokropkach, dostępnych wejść radiowych i wyboru przeskoku strony. Nie wymaga JavaScriptu. Dostępny WCAG AA, współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

Komponenty paginacji umożliwiają użytkownikom nawigację pomiędzy stronami treści — wynikami wyszukiwania, tabelami danych, archiwami artykułów i listami produktów. Zbudowany przez połączenie komponentów [Join](/components/join) i [Button](/components/button), paginacja Frutjam nie wymaga JavaScript ani dodatkowego CSS. Obsługuje numerowane strony, strzałki poprzedniej/następnej, przerwy w wielokropkach, dostępne wejścia radiowe i wybór przeskakiwania między stronami.

Tylko CSS, nie wymaga JavaScript — twórz przystępną paginację za pomocą czystego HTMX i CSS Tailwind. Dostępny w WCAG AA i niezależny od frameworka — współpracuje z Django, HTMX, Laravel, React, Next.js i dowolnym stosem.

## Podstawowa paginacja

Numerowany pasek strony z jedną aktywną stroną. Zastosuj **btn-active**, aby podświetlić bieżącą stronę. Używaj tagów zakotwiczeń zamiast przycisków dla linków do stron renderowanych przez serwer.

<Snippet>

```html
<div class="join">
  <button class="join-item btn">1</button>
  <button class="join-item btn btn-active">2</button>
  <button class="join-item btn">3</button>
  <button class="join-item btn">4</button>
  <button class="join-item btn">5</button>
</div>
```


### Z elipsą

Użyj opcji **btn-disabled** w przypadku odstępu wielokropka między dużym zakresem stron. Czytniki ekranu pomijają wyłączone przyciski, więc sparuj je z `aria-hidden="true"` w wielokropku.

<Snippet>

```html
<div class="join">

  <button class="join-item btn btn-disabled" aria-hidden="true">...</button>
```

## Dostępna paginacja radia

Użyj danych wejściowych `type="radio"` jako elementów łączenia, aby w pełni poruszać się za pomocą klawiatury i wybierać strony wyłącznie za pomocą CSS, bez JavaScript. Każde wejście działa jak przycisk, który można nacisnąć, utrzymując wybrany stan w stanie natywnym.

<Snippet>

```html
<div class="join">
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="1" />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="2" checked />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="3" />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="4" />
  <input class="join-item btn btn-square" type="radio" name="page" aria-label="5" />
```

## Paginacja za pomocą przeskoku strony

Połącz łączenie, przyciski i opcję wyboru, aby uzyskać kompaktowy pasek stronicowania, który pozwala użytkownikom przejść bezpośrednio do dowolnej strony — często w panelach administracyjnych, interfejsach CMS i aplikacjach przetwarzających duże ilości danych. Dla samego zaznaczenia nie jest wymagana obsługa JavaScript; sparuj z HTMX lub formularzem przesłanym do nawigacji po stronie serwera.

<Snippet>

```html
<div class="join">
  <button class="join-item btn btn-sm" aria-label="Previous page">‹</button>
  <select class="join-item select select-sm" aria-label="Go to page">
    <option>Page 1</option>
    <option>Page 2</option>
    <option selected>Page 3</option>
    <option>Page 4</option>
    <option>Page 5</option>
  </select>
  <button class="join-item btn btn-sm" aria-label="Next page">›</button>
</div>
```

```jsx
<div className="join">
  <button className="join-item btn btn-sm" aria-label="Previous page">‹</button>
```

</Snippet>
