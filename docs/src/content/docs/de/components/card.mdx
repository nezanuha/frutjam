Nur CSS-Tailwind-CSS-Karte mit Umriss-, Schatten- und Flachstilen. Kompakte, Standard- und große Größen. Karteninhalt, Kartentitel, Kartenfußzeilen. WCAG AA, funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

Kartenkomponenten sind vielseitige Behälter zum Kombinieren zusammengehöriger Informationen zu einer einzigen, optisch zusammenhängenden Einheit. Mit semantischem HTML und flexiblen Inhaltsbereichen erstellte Karten organisieren Inhalte hierarchisch und passen sich an verschiedene Layouts an. Das Frutjam-Kartensystem bietet mehrere Farbvarianten, Größen und Stile für Produktpräsentationen, Blogbeiträge, Testimonials und Dashboard-Elemente.

Nur CSS, kein JavaScript erforderlich. WCAG AA zugänglich und Framework-unabhängig – funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

## Karte mit Aktionen

Verwenden Sie `card-actions`, um einen Fußzeilenbereich für Schaltflächen und Aktionssteuerelemente hinzuzufügen.

<Snippet>

```html
<div class="card card-md shadow w-88">
  <div class="card-content">
    <h2 class="card-title">Card Title</h2>
    <p>A card with an actions footer for user interactions like buttons and links.</p>
    <div class="card-actions">
      <button class="btn btn-primary">Accept</button>
      <button class="btn">Dismiss</button>
    </div>
  </div>
</div>
```

</Snippet>
