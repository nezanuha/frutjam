Pie de página CSS de Tailwind solo para CSS con diseño de varias columnas, logotipo, enlaces y espacios para derechos de autor. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier proyecto Tailwind CSS v4.

Los componentes de pie de página organizan y presentan información de todo el sitio, como enlaces, derechos de autor y detalles de contacto en la parte inferior de las páginas. Construidos con HTML semántico, los pies de página mejoran la navegación y proporcionan metainformación importante. El sistema de pie de página de Frutjam admite múltiples diseños, direcciones y estilos, ideal para pies de página de sitios, pies de página de documentación y navegación inferior.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.
