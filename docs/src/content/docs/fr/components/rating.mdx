Composant d'étoile et d'évaluation cardiaque Tailwind CSS uniquement. Tailles xs-xl, support demi-étoile, aucun JavaScript requis. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants de notation permettent aux utilisateurs de fournir des commentaires en attribuant des notes par étoiles ou numériques aux produits, services ou contenus. Construites avec des entrées HTML sémantiques et un style interactif, les évaluations communiquent la satisfaction des utilisateurs et la qualité des commentaires. Le système d'évaluation Frutjam prend en charge plusieurs styles, couleurs et tailles, idéal pour les avis sur les produits, les formulaires de commentaires des utilisateurs et les enquêtes de satisfaction.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.
