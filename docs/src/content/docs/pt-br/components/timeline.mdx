Linha do tempo CSS de Tailwind somente CSS para listas de eventos cronológicos. Layout vertical com ícone, conteúdo e slots de linha do conector. WCAG AA acessível, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes da linha do tempo exibem uma sequência de eventos, marcos ou progressão narrativa em ordem cronológica. Construídos com HTML semântico, os cronogramas ajudam os usuários a entender a progressão histórica e as fases do projeto. O sistema de linha do tempo Frutjam suporta várias direções, cores e estilos de itens - ideal para o histórico do projeto, notas de versão e mapas de jornada.

Apenas CSS, não é necessário JavaScript. WCAG AA acessível e independente de estrutura — funciona com Django, HTMX, Laravel, React e qualquer pilha.
