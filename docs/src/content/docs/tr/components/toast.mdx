Bildirim konumlandırma için yalnızca CSS Tailwind CSS tostu: üst, alt, başlangıç, bitiş ve orta yerleşim. Düzen için JavaScript yok. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Toast bileşenleri, ekranın kenarlarına yerleştirilmiş kısa, müdahaleci olmayan bildirimler görüntüler. Sabit konumlandırma ve uyarı bileşenleriyle oluşturulan tostlar, başarı onayları, hata mesajları veya durum güncellemeleri gibi sistem geri bildirimlerini iletir. Frutjam tost sistemi, form gönderimleri, eşzamansız işlemler ve gerçek zamanlı bildirimler için ideal olan altı yerleştirme konumunu destekler.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız: Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

## Temel Kullanım

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## Giriş Animasyonu

Her tost kendi kendine solar ve yerine oturur. Bunun için eklenecek hiçbir şey yok ve onu açacak bir sınıf yok.

The `toast-slide-*` değiştiriciler, varsayılan artıştan farklı bir yön istediğinizde kullanılır. Tostun oturduğu kenarı seçin, böylece ekranın karşısından değil dışından girer: `toast-slide-end` aittir `toast-end`, `toast-slide-down` ile `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

Mesafe, ekranın kenarına olan mesafe değil, tostun kendi genişliği veya yüksekliğidir, bu nedenle ortalanmış bir tost, ekran dışında değil, ortasına yakın bir yerde başlar.

Çıkış animasyonu bulunmamaktadır. Bir tost, sayfadan kaldırıldığı anda kaybolur, çünkü CSS'nin geçiş yapacak bir durumu yoktur. Birini soldurmak, onu DOM'da tutmak ve kendiniz canlandırmak anlamına gelir.

Hareketin azaltılmasını isteyen herkes için animasyon atlanır.

## Genişlik

Her tostun başlığı şu şekildedir: `24rem` bu nedenle uzun bir mesaj bir telefon ekranını kapsamaz. Geçersiz kıl `--toast--width` değiştirmek için.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
