Tailwind CSS khusus CSS untuk pemosisian notifikasi — penempatan atas, bawah, awal, akhir, dan tengah. Tidak ada JavaScript untuk tata letak. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen Toast menampilkan notifikasi singkat dan tidak mengganggu yang ditempatkan di tepi layar. Dibangun dengan posisi tetap dan komponen peringatan, toast mengkomunikasikan umpan balik sistem seperti konfirmasi keberhasilan, pesan kesalahan, atau pembaruan status. Sistem toast Frutjam mendukung enam posisi penempatan—ideal untuk pengiriman formulir, operasi asinkron, dan notifikasi real-time.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Penggunaan Dasar

<Snippet>

```html
<div class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>
