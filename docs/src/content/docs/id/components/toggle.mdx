Sakelar pengalih Tailwind CSS khusus CSS dengan varian warna primer, sekunder, aksen, dan semantik. Ukuran XS-XL. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen sakelar adalah sakelar biner yang memungkinkan pengguna mengaktifkan dan menonaktifkan fitur atau pengaturan. Dibuat dengan input kotak centang HTML asli dan disempurnakan dengan animasi Tailwind CSS, tombol alih memberikan cara intuitif untuk mengontrol status boolean. Sistem sakelar Frutjam mendukung berbagai warna, ukuran, dan status nonaktif—sempurna untuk panel pengaturan, tanda fitur, dan kontrol preferensi.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
