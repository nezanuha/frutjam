Instale Frutjam, la biblioteca de interfaz de usuario CSS de Tailwind solo para CSS, en minutos. Dos importaciones, cero JavaScript, componentes accesibles WCAG listos para usar. Funciona con Django, HTMX, Laravel, React y cualquier proyecto Tailwind CSS v4.

## Instalar

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Luego elija la línea a continuación que coincida con su configuración. Todos te dan los mismos componentes.

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Tu configuración | Que agregar | Barcos |
| --- | --- | --- |
| [Viento de cola CSS v4](#tailwind-css-v4) | `@plugin "frutjam";` | solo lo que usas |
| [UnoCSS](#unocss) | `presetFrutjam()` | solo lo que usas |
| [Vite, Astro, Rails, CSS simple](#no-utility-engine) | `import 'frutjam/css'` | todos los componentes, 30 KB comprimidos con gzip |
| [Sin paso de construcción](#no-build-step) | a `<link>` etiqueta | todos los componentes |

</DocTable>

## Viento de cola CSS v4

Necesitas un trabajo [CSS de viento de cola](https://tailwindcss.com/docs/installation/using-vite) proyecto, además [Nodo](https://nodejs.org/en/download) y npm. Frutjam requiere Tailwind 4.

Añade Mermelada de Frutos a tu `input.css` con el `@plugin` directiva:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

Esa es toda la configuración. Los más de 65 componentes están disponibles de inmediato y Tailwind envía solo los que utiliza su marcado.

## UnoCSS

Frutjam incluye un ajuste preestablecido, por lo que UnoCSS genera solo los componentes que usa, de la misma manera que lo hace el complemento Tailwind.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Cada clase funciona como lo hace en Tailwind, al igual que las variantes:

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

Agregar `presetAttributify()` y el nombre del componente se convierte en un atributo, y cada valor se trata como una variante del mismo:

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

La segunda línea necesita `transformerVariantGroup()` para la sintaxis del corchete. Tenga en cuenta que un atributo como `btn` no es HTML válido, por lo que si valida su marcado, utilice el formulario de clase o UnoCSS `un-` prefijo.

### Opciones

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Opción | Por defecto | Objetivo |
| --- | --- | --- |
| `preflight` | `true` | Emite tokens, reset y temas de Frutjam. Empezar a `false` si ya importas `frutjam/css/base` tú mismo. |
| `prefix` | `''` | Coincide con el complemento Tailwind `prefix`, entonces `'fj'` te da `fj-btn` y `fj-btn="error"`. |
| `layer` | `'frutjam'` | La capa de cascada a la que se emiten los componentes. Se clasifica debajo de las utilidades, por lo que una utilidad siempre prevalece sobre un componente, independientemente del orden en que se encuentren los ajustes preestablecidos. |

</DocTable>

### El componente de enlace necesita una línea de configuración.

Delicias UnoCSS `link` como variante, para el CSS `:link` pseudoclase, y sus separadores predeterminados incluyen `-`. Entonces `link-2xl` se lee como "`2xl`, cuando no se visita" en lugar de como un nombre de clase, y no se genera nada. Afecta sólo a este componente y sólo al `link-*` modificadores.

O dígale a UnoCSS que se divida solo con dos puntos:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

O use un prefijo, que pone algo distinto a `link` al frente del nombre:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

Todos los demás componentes no se ven afectados. `link` es el único de los 57 cuyo nombre choca con una pseudoclase.

## Sin motor utilitario

Frutjam está construido con Tailwind, pero los componentes se compilan en CSS normal que lee propiedades personalizadas. Si su proyecto no utiliza ningún motor de utilidad, importe la hoja de estilo en lugar del complemento:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Esa es toda la configuración. Cada clase de componente funciona, los temas cambian con `data-theme` como de costumbre, y no se requiere nada más. Tiene 30 KB comprimidos con gzip y contiene los estilos básicos, ambos temas y los más de 65 componentes.

En su lugar, introduzca solo lo que necesita:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

O sin ningún paso de construcción:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## Sin paso de construcción

Coloque una etiqueta y comience a escribir marcas. Úselo para un prototipo o una página que no cree, no para producción, ya que incluye todos los componentes.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

Para experimentar con las utilidades de Tailwind en la misma página, agregue la compilación del navegador de Tailwind junto a ella:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript y React: opcional, no obligatorio

Frutjam es **primero nativo y primero CSS**. La gran mayoría de los componentes: botones, insignias, tarjetas, formularios, alertas y más: funcionan con HTML y CSS puros, no se necesita JavaScript. Elementos HTML nativos como `<dialog>`, `<details>`, y `<input type="checkbox">` Manejar la interactividad donde los navegadores ya la admiten. Se puede acceder a todos los componentes WCAG AA desde el primer momento y funcionan con Django, HTMX, Laravel, React, Next.js y cualquier pila.

Una pequeña cantidad de componentes no tienen equivalente HTML nativo (notificaciones de sistema, filtrado de cuadros combinados, controles de carrusel). Sólo para esos casos, Frutjam envía ayudantes opcionales livianos.

### vainilla js: `frutjam/js`

Asistentes de módulo ES independientes del marco para los componentes que los necesitan. Adjunte a cualquier elemento DOM, no se requiere marco.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Ganchos de reacción: `frutjam/react`

Envoltorios Thin React alrededor de las mismas llamadas DOM nativas. Cada gancho devuelve un `ref` usted adjunta al elemento y los métodos para controlarlo, sin dependencias adicionales más allá de React.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Disponible para: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
