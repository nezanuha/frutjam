Composant kbd CSS Tailwind uniquement CSS pour afficher les raccourcis clavier et les combinaisons de touches. Variantes de taille. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants des touches du clavier représentent visuellement la saisie au clavier, ce qui est utile pour documenter les raccourcis, les raccourcis clavier et la navigation au clavier. Construits avec du HTML sémantique, les éléments kbd communiquent les actions des utilisateurs et les modèles d'interaction. Le système Frutjam kbd prend en charge plusieurs tailles et styles, idéal pour la documentation des raccourcis, les superpositions de didacticiels et les guides de clavier.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.
