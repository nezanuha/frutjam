仅 CSS 的 Tailwind CSS 文本区域，具有主要、次要、重音和语义颜色变体。尺寸 xs-xl，幽灵风格。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

文本区域组件捕获用户的多行文本输入，非常适合消息、评论、描述和长格式内容。文本区域采用原生 HTML 文本区域元素构建，并通过 Tailwind CSS 样式进行增强，支持多种尺寸、颜色和状态。它们可访问且完全可定制，可无缝集成到表单和通信界面中。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

## 高级 Markdown 编辑器

使用 `markdown-text-editor` 将任何文本区域变成完整的 Markdown 编辑器。 有两种模式可用：**纯文本**（原始 Markdown 语法）和**混合**（在您键入时实时呈现格式）。 有关更多配置选项，请参阅[插件文档](https://frutjam.com/plugins/markdown-editor)。

### 普通模式

显示原始 Markdown 语法。用户直接在文本区域中编写 Markdown。

<Snippet>

```html
<textarea id="plain-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#plain-markdown-editor');
```

</Snippet>

### 混合模式

在您键入时实时呈现格式 — 粗体、标题、列表等以内联样式显示。

<Snippet>

```html
<textarea id="hybrid-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#hybrid-markdown-editor', { mode: 'hybrid' });
```

</Snippet>
