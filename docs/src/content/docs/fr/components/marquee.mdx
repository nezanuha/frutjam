Marquee CSS Tailwind uniquement CSS pour le contenu et les logos à défilement horizontal. Contrôle de vitesse et de direction via CSS, pas de JavaScript. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants de chapiteau créent des bandes de contenu infinies à défilement continu, idéales pour les logos de marque, les bannières d'annonces, les témoignages ou les nuages ​​de tags. Construit entièrement avec des animations CSS, le chapiteau Frutjam prend en charge les directions horizontales et verticales, la pause en survol, la lecture réversible et le contrôle de la vitesse. Dupliquez l'élément `marquee-track` (avec `aria-hidden`) pour une boucle transparente et sans interruption.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

| Classe | Taper | Description |
| --- | --- | --- |

| marquee-track | <span class="badge badge-xs badge-secondary badge-soft">Modificateur</span> | Défilement de la rangée intérieure ; dupliquer avec `aria-hidden` pour une boucle transparente |

| marquee-reverse | <span class="badge badge-xs badge-secondary badge-soft">Modificateur</span> | Défile dans la direction opposée |
| marquee-vertical | <span class="badge badge-xs badge-secondary badge-soft">Modificateur</span> | Fait défiler de haut en bas au lieu de gauche à droite |
| marquee-slow | <span class="badge badge-xs badge-info badge-soft">Speed</span> | Défilement lent (cycle de 40 s) |
| marquee-normal | <span class="badge badge-xs badge-info badge-soft">Speed</span> | Vitesse par défaut (cycle de 20 s) |
| marquee-fast | <span class="badge badge-xs badge-info badge-soft">Speed</span> | Défilement rapide (cycle de 10 s) |

## Utilisation de base

Ajoutez deux éléments `marquee-track` identiques — le second (avec `aria-hidden="true"`) comble le vide lorsque le premier défile hors de l'écran.

<Snippet>

```html
<div class="marquee">
  <div class="marquee-track">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
  <div class="marquee-track" aria-hidden="true">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
</div>
```

```jsx
const items = ["Item 1", "Item 2", "Item 3", "Item 4", "Item 5"]

export default function MarqueeDemo() {
  return (
    <div className="marquee">
      <div className="marquee-track">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
      <div className="marquee-track" aria-hidden="true">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
    </div>
  )
}
```

</Snippet>
