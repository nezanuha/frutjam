僅 CSS Tailwind CSS toast 用於通知定位：頂部、底部、開始、結束和中心放置。沒有用於佈局的 JavaScript。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

Toast 元件在螢幕邊緣顯示簡短的、非侵入性的通知。 Toast 採用固定定位和警報組件構建，可傳達系統回饋，例如成功確認、錯誤訊息或狀態更新。 Frutjam toast 系統支援六個放置位置，非常適合表單提交、非同步操作和即時通知。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關：適用於 Django、HTMX、Laravel、React 和任何堆疊。

## 基本用法

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## 入場動畫

每片吐司都會自行褪色併升起。沒有什麼可以添加的，也沒有類別可以打開它。

這 `toast-slide-*` 當您想要與預設上升不同的方向時，可以使用修改器。選擇吐司所在的邊緣，這樣它就會從螢幕外部進入，而不是穿過螢幕： `toast-slide-end` 屬於 `toast-end`, `toast-slide-down` 和 `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

該距離是 toast 本身的寬度或高度，而不是到螢幕邊緣的距離，因此居中的 toast 從中間附近開始，而不是在螢幕外。

沒有退出動畫。 Toast 從頁面中刪除後就會消失，因為 CSS 沒有可以轉換的狀態。淡出一個意味著將其保留在 DOM 中並自己為其設置動畫。

對於任何要求減少動作的人來說，動畫都會被跳過。

## 寬度

每個吐司的上限為 `24rem` 因此長消息不會跨越手機螢幕。覆蓋 `--toast--width` 改變它。

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
