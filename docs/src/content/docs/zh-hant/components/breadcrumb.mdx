純 CSS Tailwind CSS 麵包屑導航，具有自訂分隔符號和可存取的地標標記。 WCAG AA，適用於 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 專案。

麵包屑組件顯示導航層次結構並幫助使用者了解他們在網站中的位置。麵包屑使用語義 HTML 導航元素和 ARIA 地標建立以實現可訪問性，允許使用者快速導航到父部分，從而提高可用性。 Frutjam 麵包屑系統會自動呈現分隔符號並支援自訂分隔符號以實現靈活的樣式。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

## 基本用法

如果未提供分隔符，則麵包屑項目之間會自動顯示箭頭。

<Snippet>

```html
<nav class="breadcrumb" aria-label="Breadcrumb">
  <ol class="breadcrumb-list">
    <li class="breadcrumb-item">
      <a href="/" class="breadcrumb-link">Home</a>
    </li>
    <li class="breadcrumb-item">
      <span class="breadcrumb-current" aria-current="page">Current Page</span>
    </li>
  </ol>
</nav>
```

```jsx
<nav className="breadcrumb" aria-label="Breadcrumb">
  <ol className="breadcrumb-list">

    </li>

```

## 麵包屑導航輔助功能

為了確保螢幕閱讀器可以存取麵包屑：

- 將結構包裹在 `<nav>` 元素與 `aria-label="Breadcrumb"`.
- 最後一項（目前頁面）應該使用 `aria-current="page"` 並且優選地是 `<span>` 而不是連結。
- 螢幕閱讀器應忽略分隔符號（通常透過 CSS 或 `aria-hidden="true"` 如果使用物理元件）。
