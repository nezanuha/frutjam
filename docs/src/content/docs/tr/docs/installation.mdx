Yalnızca CSS'ye özel Tailwind CSS kullanıcı arayüzü kitaplığı olan Frutjam'ı birkaç dakika içinde yükleyin. İki içe aktarma, sıfır JavaScript, kutudan çıktığı gibi WCAG ile erişilebilen bileşenler. Django, HTMX, Laravel, React ve herhangi bir Tailwind CSS v4 projesiyle çalışır.

## Tailwind CSS projesine Frutjam UI kütüphanesi nasıl kurulur?

Bir çalışmanız olduğundan emin olun [Arka rüzgar CSS](https://tailwindcss.com/docs/installation/using-vite) proje yüklendi, ayrıca [Düğüm](https://nodejs.org/en/download) ve bilgisayarınızda NPM. Frutjam, Tailwind sürüm 4 ile çalışır.

### Aşağıdaki komutu çalıştırarak frutjam'ı Node paketi olarak yükleyin:

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Frutjam'ı ekleyin `input.css` kullanarak `@plugin` direktif:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

## JavaScript ve React – İsteğe Bağlı, Gerekli Değil

Frutjam **yerel öncelikli ve CSS önceliklidir**. Bileşenlerin büyük çoğunluğu (düğmeler, rozetler, kartlar, formlar, uyarılar ve daha fazlası) saf HTML ve CSS ile çalışır, hiçbir JavaScript gerektirmez. Yerel HTML öğeleri gibi `<dialog>`, `<details>`, Ve `<input type="checkbox">` Tarayıcıların zaten desteklediği etkileşimi yönetin. Tüm bileşenlere WCAG AA kullanıma hazırdır ve Django, HTMX, Laravel, React, Next.js ve herhangi bir yığınla çalışır.

Az sayıda bileşenin yerel HTML eşdeğeri yoktur (kısmen bildirimler, birleşik giriş kutusu filtreleme, atlıkarınca kontrolleri). Frutjam yalnızca bu durumlar için hafif, isteğe bağlı yardımcılar gönderir.

### Vanilya JS — `frutjam/js`

İhtiyaç duyan bileşenler için çerçeveden bağımsız ES modülü yardımcıları. Herhangi bir DOM öğesine ekleyin; çerçeve gerekmez.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Tepki Kancaları — `frutjam/react`

Aynı yerel DOM çağrılarının etrafındaki ince React sarmalayıcıları. Her kanca bir değer döndürür `ref` öğeye ve onu kontrol etmek için yöntemlere bağlanırsınız; React'ın kendisi dışında ekstra bir bağımlılık yoktur.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Şunlar için kullanılabilir: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.

### CDN kullanma

Yerel kurulum gerektirmeden hızlı ve kolay entegrasyon için frutjam UI kitaplığının CDN sürümünü kullanın. Frutjam'ın bu CDN sürümünü yalnızca geliştirme amacıyla kullanın, üretimde değil.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>
