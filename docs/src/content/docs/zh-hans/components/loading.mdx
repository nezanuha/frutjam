纯 CSS Tailwind CSS 加载指示器，带有旋转器、点、环和条形动画。颜色和尺寸变体，无需 JavaScript。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

加载组件在获取或处理内容时显示视觉指示器，让用户了解情况并防止感知延迟。加载旋转器采用语义 HTML 和流畅的 CSS 动画构建，可传达活动的后台操作。 Frutjam 加载系统支持多种样式、颜色和尺寸，非常适合数据表、文件上传、表单提交和异步操作。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。
