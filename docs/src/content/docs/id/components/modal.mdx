Modal CSS Tailwind khusus CSS yang menggunakan elemen `<dialog>` asli. Ukuran responsif, latar belakang, dan perangkap fokus. Tidak ada JavaScript untuk penggunaan dasar. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen modal menampilkan informasi penting atau meminta tindakan pengguna dalam jendela overlay yang terfokus. Dibangun di atas elemen dialog HTML semantik, modals mendukung animasi, pemosisian yang dapat disesuaikan, dan hamparan latar belakang. Sistem modal Frutjam dapat diakses sepenuhnya dengan navigasi keyboard dan fokus jebakan, menjadikannya ideal untuk konfirmasi, formulir, dan dialog peringatan.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Penggunaan Dasar

Tambahkan id unik ke elemen HTML `<dialog id="myModal">`, lalu gunakan id tersebut di JavaScript untuk memanggil `myModal.showModal()` untuk membuka modal dan `myModal.close()` untuk menutup modal.

<Snippet>

```html

  <div class="modal-content">
    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Dialog modal</div>
      <button type="button" class="btn btn-xs btn-square btn-rounded btn-ghost" onclick="toggleModal.close()">
        <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
          <path d="M18 6 6 18"></path>

        </svg>
      </button>
    </div>
    <div class="divider my-3"></div>
    <p class="para">Press Esc key or close button to close the modal</p>
  </div>
  <button type="button" class="modal-backdrop" onclick="toggleModal.close()">Close Modal via Backdrop</button>
</dialog>
<button type="button" class="btn btn-xs" onclick="toggleModal.showModal()">Show Modal</button>
```

## Animasi Slide Modal

Geser masuk dan keluar dengan lancar dari atas, bawah, awal (kiri di LTR, kanan di RTL), atau akhir (kanan di LTR, kiri di RTL) dengan kelas utilitas arah berikut: `modal-slide-top`, `modal-slide-bottom`, `modal-slide-start`, dan `modal-slide-end` di komponen modal. Animasi ini meningkatkan pengalaman pengguna melalui penggunaan transisi dinamis berdasarkan posisi modal.

### Modal slide dari awal (Horizontal)

Tambahkan utilitas `modal-slide-start` untuk menggeser modal secara horizontal dari sisi awal; pada tata letak kiri-ke-kanan (LTR), muncul dari kiri, dan pada tata letak kanan-ke-kiri (RTL), muncul dari kanan.

<Snippet>

```html

          <path d="M18 6 6 18"></path>
          <path d="m6 6 12 12"></path>
        </svg>
      </button>
    </div>
```

## Penempatan modal

Komponen modal secara default diposisikan di tengah layar, namun dapat ditempatkan tergantung pada kasus penggunaan menggunakan kelas horizontal `modal-start`, `modal-center`, atau `modal-end`, dan kelas vertikal `modal-top`, `modal-middle`, atau `modal-bottom`. Penempatannya dirancang dengan mempertimbangkan kompatibilitas RTL dan LTR, membuat modal dapat beradaptasi dengan arah dan tata letak bahasa yang berbeda.

Gunakan `modal-start`, `modal-center`, atau `modal-end` untuk penempatan horizontal dan `modal-top`, `modal-middle`, atau `modal-bottom` untuk penempatan vertikal. Kelas-kelas ini diterapkan pada komponen modal.
