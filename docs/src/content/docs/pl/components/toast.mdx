Toast CSS Tailwind tylko dla CSS do pozycjonowania powiadomień: góra, dół, początek, koniec i położenie na środku. Brak JavaScriptu dla układu. Dostępny WCAG AA, współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

Komponenty Toast wyświetlają krótkie, nieinwazyjne powiadomienia umieszczone na krawędziach ekranu. Zbudowane ze stałych elementów pozycjonujących i alertów, tosty przekazują informacje zwrotne od systemu, takie jak potwierdzenia powodzenia, komunikaty o błędach lub aktualizacje statusu. System tostów Frutjam obsługuje sześć pozycji umieszczenia, idealnych do przesyłania formularzy, operacji asynchronicznych i powiadomień w czasie rzeczywistym.

Tylko CSS, nie wymaga JavaScript. Dostępny w WCAG AA i niezależny od frameworka: współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

## Podstawowe użycie

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## Animacja wejścia

Każdy tost zanika i samoczynnie unosi się na swoim miejscu. Nie ma nic do dodania i nie ma klasy, która by to włączyła.

The `toast-slide-*` modyfikatory są przydatne, gdy chcesz mieć inny kierunek niż domyślny wzrost. Wybierz krawędź, na której leży tost, tak aby wchodził spoza ekranu, a nie przez niego: `toast-slide-end` należy z `toast-end`, `toast-slide-down` z `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

Odległość to szerokość lub wysokość tostu, a nie odległość do krawędzi ekranu, zatem toast wyśrodkowany zaczyna się w pobliżu środka, a nie poza ekranem.

Brak animacji wyjścia. Toast znika w momencie usunięcia go ze strony, ponieważ CSS nie ma stanu, z którego można przejść. Wygaszenie jednego oznacza pozostawienie go w DOM i samodzielne animowanie.

Animacja jest pomijana w przypadku każdego, kto poprosił o ograniczenie ruchu.

## Szerokość

Każdy toast jest ograniczony `24rem` więc długa wiadomość nie zajmuje całego ekranu telefonu. Prześcigać `--toast--width` żeby to zmienić.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
