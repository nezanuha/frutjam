通知ポジショニングのためのCSSのみの追い風CSSトースト：上部、下部、開始、終了、および中央配置。レイアウト用のJavaScriptはありません。WCAG AAはアクセス可能で、Django、HTMX、Laravel、React、および任意のスタックで動作します。

Toastコンポーネントは、画面の端に簡潔で邪魔にならない通知を表示します。固定された位置決めとアラートコンポーネントで構築されたToastは、成功確認、エラーメッセージ、ステータス更新などのシステムフィードバックを伝達します。Frutjam Toastシステムは、フォーム送信、非同期操作、リアルタイム通知に最適な6つの配置位置をサポートしています。

CSSのみ、JavaScriptは必要ありません。WCAG AAアクセス可能でフレームワークに依存しない： Django、HTMX、Laravel、React、および任意のスタックで動作します。

## 基本的な使い方

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## 入力アニメーション

すべての乾杯がフェードアウトし、それ自体で上昇します。そのために追加するものは何もなく、それをオンにするクラスもありません。

ページは `toast-slide-*` 修飾子は、デフォルトの上昇とは異なる方向を望む場合に使用します。トーストが置かれている端を選ぶと、画面の向こう側ではなく、画面の外側からトーストが入ってきます。 `toast-slide-end` に属しています `toast-end`, `toast-slide-down` と `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

距離は、画面の端までの距離ではなく、トースト自体の幅または高さであるため、中央のトーストは画面外ではなく中央付近から始まります。

終了アニメーションはありません。CSSには遷移する状態がないため、トーストはページから削除されると消えます。フェードアウトとは、DOMに保存して自分でアニメーション化することを意味します。

縮小された動きを要求した人は、アニメーションがスキップされます。

## 幅

各トーストの上限は `24rem` 長いメッセージが電話の画面に表示されないようにします。上書き `--toast--width` 変更することができます。

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
