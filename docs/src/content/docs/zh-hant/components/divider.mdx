僅 CSS Tailwind CSS 分隔線 — 水平和垂直，帶有可選的居中標籤。顏色和尺寸變體。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

分隔線組件在內容部分之間創建視覺分隔。分隔符號輕量級且語義化，有助於分層建構資訊並提高可讀性。 Frutjam 分隔系統支援水平和垂直方向，並帶有可選文字內容，用於在部分之間進行標記分隔。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

## 基本用法


## 分音器方向

### 水平分隔線

<Snippet>

```html
<div class="divider divider-horizontal"></div>
```

</Snippet>

### 垂直分隔線

<Snippet>

```html
<div class="flex gap-4 w-full">
    <div class="card card-outline w-full">
       <div class="card-content">content 1</div>
    </div>
    <div class="divider divider-vertical"></div>
    <div class="card card-outline w-full">
        <div class="card-content">content 2</div>
    </div>
</div>
```

</Snippet>
