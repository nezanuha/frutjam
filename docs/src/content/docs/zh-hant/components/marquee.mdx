僅 CSS Tailwind CSS 選取框，用於水平捲動內容和標誌。透過 CSS 控制速度和方向，無需 JavaScript。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

Marquee 組件可創建無限、連續滾動的內容條 - 非常適合品牌標誌、公告橫幅、感言或標籤雲。 Frutjam 字幕完全採用 CSS 動畫構建，支援水平和垂直方向、懸停暫停、可逆播放和速度控制。複製 `marquee-track` 元素（與 `aria-hidden`）以獲得無縫、無間隙的循環。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

<DocTable wrapper="overflow-y-auto max-h-72" table="table table-sm not-prose">

| 班級 | 類型 | 描述 |
| --- | --- | --- |
| marquee | <span class="badge badge-xs">根據</span> | 外部容器——剪輯溢出並保存動畫變量 |
| marquee-track | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 滾動內行；重複與 `aria-hidden` 無縫循環 |
| marquee-pause | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 懸停時暫停動畫 |
| marquee-reverse | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 向相反方向滾動 |
| marquee-vertical | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 從上到下滾動而不是從左到右滾動 |
| marquee-slow | <span class="badge badge-xs badge-info badge-soft">速度</span> | 慢速滾動（40秒循環） |
| marquee-normal | <span class="badge badge-xs badge-info badge-soft">速度</span> | 預設速度（20秒循環） |

| marquee-fade | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 在兩側添加漸層淡出邊緣 |

</DocTable>

## 基本用法

添加兩個相同的 `marquee-track` 元素 — 第二個（與 `aria-hidden="true"`）在第一個滾出螢幕時填補空白。

<Snippet>

```html
<div class="marquee">
  <div class="marquee-track">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
  <div class="marquee-track" aria-hidden="true">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
</div>
```

```jsx
const items = ["Item 1", "Item 2", "Item 3", "Item 4", "Item 5"]

export default function MarqueeDemo() {
  return (
    <div className="marquee">
      <div className="marquee-track">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
      <div className="marquee-track" aria-hidden="true">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
    </div>
  )
}
```

</Snippet>

## 懸停時暫停

添加 `marquee-pause` 當使用者將滑鼠懸停在條帶上時停止動畫。

<Snippet>

```html

  <div class="marquee-track">
    <span class="badge badge-primary badge-soft">Hover me</span>
    <span class="badge badge-secondary badge-soft">to pause</span>

    <span class="badge badge-info badge-soft">Animation</span>

  <div class="marquee-track" aria-hidden="true">
    <span class="badge badge-primary badge-soft">Hover me</span>
```
