Popover CSS Tailwind uniquement CSS utilisant l'API popover native. Panneau de contenu flottant pour les info-bulles et les listes déroulantes. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants popover affichent le contenu contextuel à côté des éléments déclencheurs sans occuper d'espace d'écran permanent. Construit sur l'API HTML Popover native, le système de popover Frutjam prend en charge les déclencheurs de clic et de survol, un positionnement personnalisable et des animations fluides. Parfait pour les menus déroulants, les menus contextuels, les menus de profil utilisateur et les options supplémentaires sans navigation dans les pages.

CSS uniquement, aucun JavaScript requis : créez des menus déroulants accessibles et des superpositions contextuelles avec du HTMX pur et du CSS Tailwind. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

## Comportement d'interaction popover

Par défaut, les interactions de clic sont utilisées pour ouvrir et fermer le composant popover. Pour les mégamenus, par exemple, vous pouvez activer l'interaction basée sur le survol en ajoutant la classe `popover-hover` et en supprimant les attributs `popovertarget` et `popover`. Cela permet au popover d'être entièrement contrôlé via la logique de survol plutôt que le comportement de clic natif.

### Déclencheur de clic natif

<Snippet>

```html
<div class="popover">
  <button popovertarget="nativeClickTrigger" type="button" class="popover-toggle btn">Click here</button>
  <div tabindex="0" class="popover-content" popover id="nativeClickTrigger">
      <ul class="menu">
        <li>
          <a class="menu-item">About Us</a>
        </li>
        <li>
          <a class="menu-item">Contact Us</a>
        </li>
        <li>
          <a class="menu-item">Career</a>
        </li>
        <li>
          <a class="menu-item">Terms and conditions</a>
        </li>
      </ul>
  </div>
</div>
```

</Snippet>

### Logique d'interaction de survol

<Snippet>

<div class="popover popover-hover">
