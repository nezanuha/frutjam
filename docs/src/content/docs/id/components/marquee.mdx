Tenda CSS Tailwind khusus CSS untuk menggulir konten dan logo secara horizontal. Kontrol kecepatan dan arah melalui CSS, tanpa JavaScript. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen tenda membuat strip konten yang tak terbatas dan terus bergulir — ideal untuk logo merek, spanduk pengumuman, testimonial, atau tag cloud. Dibangun seluruhnya dengan animasi CSS, tenda Frutjam mendukung arah horizontal dan vertikal, jeda-saat-melayang, pemutaran reversibel, dan kontrol kecepatan. Gandakan elemen `marquee-track` (dengan `aria-hidden`) untuk loop yang mulus dan tanpa celah.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Penggunaan Dasar

Tambahkan dua elemen `marquee-track` yang identik — elemen kedua (dengan `aria-hidden="true"`) mengisi celah saat elemen pertama bergulir keluar layar.

<Snippet>

```html
<div class="marquee">
  <div class="marquee-track">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
  <div class="marquee-track" aria-hidden="true">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
</div>
```

```jsx
const items = ["Item 1", "Item 2", "Item 3", "Item 4", "Item 5"]

export default function MarqueeDemo() {
  return (
    <div className="marquee">
      <div className="marquee-track">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
      <div className="marquee-track" aria-hidden="true">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
    </div>
  )
}
```

</Snippet>
