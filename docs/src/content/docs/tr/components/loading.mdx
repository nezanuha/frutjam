Döndürücü, noktalar, halka ve çubuk animasyonlarıyla yalnızca CSS'ye özgü Tailwind CSS yükleme göstergesi. Renk ve boyut çeşitleri, JavaScript gerekmez. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Yükleme bileşenleri, içerik getirilirken veya işlenirken görsel göstergeler görüntüleyerek kullanıcıları bilgilendirir ve algılanan gecikmeleri önler. Anlamsal HTML ve düzgün CSS animasyonları ile oluşturulan yükleme döndürücüler, aktif arka plan işlemlerini iletir. Frutjam yükleme sistemi birden çok stili, rengi ve boyutu destekler; veri tabloları, dosya yüklemeleri, form gönderimleri ve eşzamansız işlemler için idealdir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
