只需几分钟即可安装 Frutjam，这是纯 CSS 的 Tailwind CSS UI 库。两次导入、零 JavaScript、开箱即用的 WCAG 可访问组件。适用于 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 项目。

## 如何在 Tailwind CSS 项目中安装 Frutjam UI 库？

确保你有一份工作 [顺风CSS](https://tailwindcss.com/docs/installation/using-vite) 项目已安装，以及 [节点](https://nodejs.org/en/download) 和 NPM 在您的计算机上。 Frutjam 可与 Tailwind 版本 4 配合使用。

### 通过运行以下命令将 frutjam 安装为节点包：

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

将Frutjam 添加到您的 `input.css` 使用 `@plugin` 指示：

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

## 乌诺CSS

Frutjam 提供了预设，因此 UnoCSS 只生成您使用的组件，就像 Tailwind 插件一样。

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

每个类都像在 Tailwind 下一样工作，变体也是如此：

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

添加 `presetAttributify()` 组件名称成为一个属性，每个值都被视为它的一个变体：

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

第二行需要 `transformerVariantGroup()` 对于括号语法。请注意，像这样的属性 `btn` 不是有效的 HTML，因此如果您验证标记，请使用类形式或 UnoCSS `un-` 前缀。

预设带有 Frutjam 的令牌并重置。如果您已经导入 `frutjam/css/base` 你自己，把它关掉 `presetFrutjam({ preflight: false })`.

## 没有实用引擎：Vite、Astro、Rails 或纯 CSS

Frutjam 是使用 Tailwind 构建的，但组件编译为读取自定义属性的普通 CSS。如果您的项目根本不使用实用程序引擎，请导入样式表而不是插件：

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

这就是整个设置。每个组件类都可以工作，主题可以切换 `data-theme` 像往常一样，不需要其他任何东西。它压缩后大小为 30 KB，包含基本样式、主题和所有 65 个以上组件。

只拉入您需要的内容：

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

或者根本没有构建步骤：

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## JavaScript 和 React：可选，非必需

Frutjam 是**原生优先和 CSS 优先**。绝大多数组件：按钮、徽章、卡片、表单、警报等：使用纯 HTML 和 CSS，无需任何 JavaScript。原生 HTML 元素如 `<dialog>`, `<details>`， 和 `<input type="checkbox">` 处理浏览器已经支持的交互性。所有组件均可通过 WCAG AA 开箱即用，并可与 Django、HTMX、Laravel、React、Next.js 和任何堆栈配合使用。

少数组件没有本机 HTML 等效项（toast 通知、组合框过滤、轮播控件）。仅针对这些情况，Frutjam 提供了轻量级可选助手。

### 普通JS： `frutjam/js`

与框架无关的 ES 模块助手，用于需要它们的组件。附加到任何 DOM 元素，无需框架。

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### 反应挂钩： `frutjam/react`

围绕相同的本机 DOM 调用的精简 React 包装器。每个钩子返回一个 `ref` 您附加到元素和方法来控制它，除了 React 本身之外没有额外的依赖项。

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

适用于： `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.

### 使用 CDN

使用 frutjam UI 库的 CDN 版本可快速轻松地集成，无需本地设置。将此 CDN 版本的 frutjam 仅用于开发目的，不得用于生产。

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>
