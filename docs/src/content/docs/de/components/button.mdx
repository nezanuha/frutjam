Nur CSS Tailwind CSS-Schaltfläche mit primären, sekundären, Akzent-, Ghost-, Outline- und Soft-Varianten. Größen xs-xl, Ladestatus, deaktiviert und Symbolschaltflächen. Nur CSS, WCAG AA, funktioniert mit Django, HTMX, Laravel, React.

Button-Komponenten sind interaktive Elemente, die Aktionen auslösen oder Benutzer zu neuen Seiten navigieren. Das Frutjam-Schaltflächensystem bietet über Modifikatorklassen mehrere Größen, Farben und Stile – alle mit dem Utility-First-Ansatz von Tailwind CSS für leichte, hochgradig anpassbare Schaltflächen erstellt, die nahtlos über Frameworks und Projekte hinweg funktionieren.

Nur CSS, kein JavaScript erforderlich. WCAG AA zugänglich und Framework-unabhängig – funktioniert mit Django, HTMX, Laravel, React und jedem Stack.
