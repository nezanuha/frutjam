Encabezado de página CSS Tailwind solo para CSS: diseño de la barra superior con espacios para marca, navegación y acción. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes de encabezado crean áreas principales de navegación y marca consistentes para su sitio web o aplicación. Construido con elementos de encabezado HTML semánticos, el sistema de encabezado Frutjam combina logotipos, enlaces de navegación y acciones del usuario en una barra cohesiva y responsiva. Admite múltiples diseños, opciones de alineación y se integra perfectamente con menús desplegables y funciones de búsqueda.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.

## Uso básico

<Snippet>

```html
<header class="header header-sticky header-blur">
  <div class="header-content">
    <div class="header-start">
      <a class="heading-2xl" title="frutjam">Frutjam</a>
    </div>
    <div class="header-center"></div>
    <div class="header-end">

          <li><a class="link link-xs link-hover">Services</a></li>
        </ul>
      </nav>

  </div>
</header>
```
