얼룩말 줄무늬, 컴팩트 및 기본 크기, 고정된 열 및 행 가리키기 상태가 포함된 CSS 전용 Tailwind CSS 테이블입니다. WCAG AA 액세스 가능하며 Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.

테이블 구성 요소는 구조화된 데이터를 행과 열로 구성하고 표시합니다. 의미 있는 HTML 테이블 요소와 Tailwind CSS 스타일로 구축된 테이블은 정렬, 줄무늬 행, 호버 효과 및 반응형 오버플로 처리를 지원합니다. Frutjam 테이블 시스템은 적절한 헤더 연결을 통해 액세스할 수 있으며 데이터 시각화 프레임워크와 원활하게 작동합니다.

CSS 전용이며 JavaScript가 필요하지 않습니다. WCAG AA 액세스 가능 및 프레임워크에 구애받지 않음 — Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.

### 테이블 특소 `(table-xs)`

아래 테이블 크기 예에서는 `table-xs`(매우 작음)를 사용합니다. `table-xs`, `table-sm`, `table-md`, `table-lg`, `table-xl` 등 `table-{size}` 유틸리티 클래스를 사용하여 테이블 크기를 조정할 수 있습니다. 이 클래스는 매우 컴팩트한 레이아웃부터 더 넓고 읽기 쉬운 테이블까지 다양합니다.
