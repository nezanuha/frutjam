CSS-only Tailwind CSS indicator for overlaying badges or dots on any element corner. Color variants and positioning. WCAG AA accessible, works with Django, HTMX, Laravel, React, and any stack.

Indicator components display status, badges, or notifications positioned on other elements. Built with absolute positioning and flexible styling, indicators overlay important information on cards, avatars, and buttons. The Frutjam indicator system supports multiple placements, sizes, and colors—ideal for notification badges, status markers, and visual cues.

CSS-only, no JavaScript required. WCAG AA accessible and framework-agnostic — works with Django, HTMX, Laravel, React, and any stack.

<DocTable wrapper="overflow-y-auto max-h-72" table="table table-sm not-prose">

| Class | Type | Description |
| --- | --- | --- |
| indicator | <span class="badge badge-xs">Base</span> | Relative-positioned wrapper for the indicator item |
| indicator-item | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Absolutely positioned badge or dot element |
| indicator-top | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Positions item at the top edge |
| indicator-middle | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Positions item at the vertical middle |
| indicator-bottom | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Positions item at the bottom edge |
| indicator-start | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Positions item at the left edge |
| indicator-center | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Positions item at the horizontal center |
| indicator-end | <span class="badge badge-xs badge-secondary badge-soft">Modifier</span> | Positions item at the right edge |

</DocTable>

## Basic Usage

<Snippet>

```html
<div class="indicator">
  <span class="indicator-item badge badge-primary">99+</span>
  <button class="btn">Messages</button>
</div>
```

```jsx
<div className="indicator">
  <span className="indicator-item badge badge-primary">99+</span>
  <button className="btn">Messages</button>
</div>
```
