Indicador CSS Tailwind solo para CSS para superponer insignias o puntos en cualquier esquina de elemento. Variantes de color y posicionamiento. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes del indicador muestran el estado, insignias o notificaciones ubicadas en otros elementos. Construidos con posicionamiento absoluto y estilo flexible, los indicadores superponen información importante en tarjetas, avatares y botones. El sistema de indicadores Frutjam admite múltiples ubicaciones, tamaños y colores, ideal para insignias de notificación, marcadores de estado y señales visuales.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.

## Uso básico

<Snippet>

```html

  <button class="btn">Messages</button>
</div>
```

  <button className="btn">Messages</button>
</div>
