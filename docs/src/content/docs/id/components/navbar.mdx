Bilah navigasi CSS Tailwind khusus CSS dengan merek, tautan navigasi, dan slot tindakan. Varian lengket dan transparan. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen Navbar menampilkan daftar navigasi horizontal untuk struktur situs dan navigasi pengguna. Dibangun dengan elemen navigasi dan daftar HTML semantik, sistem navbar Frutjam mendukung banyak tata letak, perilaku responsif, dan integrasi menu bersarang. Dapat diakses dan dinavigasi dengan keyboard, bilah navigasi ideal untuk navigasi situs utama, remah roti, dan antarmuka tab.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Penempatan Navbar

Komponen navbar secara default diposisikan di awal (kiri di LTR). Gunakan `navbar-start`, `navbar-center`, atau `navbar-end` untuk perataan horizontal, dan `navbar-top`, `navbar-middle`, atau `navbar-bottom` untuk perataan vertikal. Penempatannya ramah RTL.

Gunakan kelas penempatan horizontal untuk menyelaraskan daftar bilah navigasi di sepanjang sumbu X, dan kelas penempatan vertikal ketika bilah navigasi memiliki ketinggian khusus.

### Penempatan Horisontal

Kontrol posisi `navbar-list` di sepanjang sumbu X. Ini ramah RTL (Awal/Akhir, bukan Kiri/Kanan).

#### Sejajarkan secara horizontal ke kiri (mulai)
