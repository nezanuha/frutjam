只需幾分鐘即可安裝 Frutjam，這是純 CSS 的 Tailwind CSS UI 庫。兩次導入、零 JavaScript、開箱即用的 WCAG 可存取元件。適用於 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 專案。

## 如何在 Tailwind CSS 專案中安裝 Frutjam UI 庫？

確保你有一份工作 [順風CSS](https://tailwindcss.com/docs/installation/using-vite) 項目已安裝，以及 [節點](https://nodejs.org/en/download) 以及電腦上的NPM。Frutjam與Tailwind版本4兼容。

### 執行下列指令，將frutjam安裝為Node套件：

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

將Frutjam添加到您的 `input.css` 使用 `@plugin` 指示詞

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

## 無順風： UnoCSS、VITE、Astro或普通CSS

Frutjam是使用Tailwind構建的，但組件編譯為讀取自定義屬性的普通CSS。如果您的專案使用UnoCSS或根本沒有公用程式引擎，請匯入樣式表而不是外掛程式：

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

這就是整個設定。每個組件類都有效，主題切換 `data-theme` 像往常一樣，不需要其他任何東西。它是30 KB gzip壓縮的，並帶有基本樣式，包括主題和所有65 +組件。

請只填寫您需要的資訊：

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

或者根本沒有構建步驟：

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## JavaScript和React ：選填，非必填

Frutjam是* *原生優先和CSS優先* *。絕大多數元件：按鈕、徽章、卡片、表單、提醒等：使用純HTML和CSS ，不需要任何JavaScript。原生HTML元素，例如 `<dialog>`, `<details>` 和  `<input type="checkbox">` 處理瀏覽器已支援的交互性。所有元件都開箱即可存取WCAG AA ，並可與Django、HTMX、Laravel、React、Next.js和任何堆疊搭配使用。

少數元件沒有原生HTML等效項目（ Toast通知、組合方塊篩選、輪播控制項）。僅在這些情況下， Frutjam會運送輕量可選的助手。

### Vanilla JS ： `frutjam/js`

與框架無關的ES模組協助程式，用於需要它們的組件。附加到任何DOM元素，不需要框架。

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### React Hooks ： `frutjam/react`

圍繞相同原生DOM呼叫的精簡React包裝器。每個鉤子都會傳回 `ref` 你附加到元素和方法來控制它，除了React本身之外沒有額外的依賴關係。

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

可使用於： `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.

### 使用CDN

使用frutjam UI庫的CDN版本，無需本地設置即可快速輕鬆集成。僅將此CDN版本的frutjam用於開發目的，而不用於生產。

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>
