Hệ thống màu của Frutjam sử dụng mã thông báo CSS ngữ nghĩa được thiết kế để đáp ứng tỷ lệ tương phản WCAG AA ngay lập tức. Không có JavaScript, nhận biết chế độ tối, tương thích với Tailwind CSS v4. Hoạt động với Django, HTMX, Laravel và mọi ngăn xếp chỉ có CSS.

Frutjam sử dụng các thuộc tính tùy chỉnh CSS làm mã thông báo thiết kế cho tất cả các màu. Mỗi màu được xác định theo chủ đề và tự động hoạt động với các lớp tiện ích CSS của Tailwind mà không cần cấu hình bổ sung. Chỉ CSS, không cần JavaScript. Độ tương phản WCAG AA được đảm bảo trên mọi cặp màu, hoạt động với Django, HTMX, Laravel, React và bất kỳ dự án Tailwind CSS v4 nào.

## Tên màu

Frutjam xác định các vai trò màu ngữ nghĩa sau đây. Mỗi màu có một sự phù hợp `on-{color}` mã thông báo cho văn bản nền trước có thể truy cập.

## Thang màu (50–950)

Mỗi màu tạo ra thang đo 11 bước, được tính từ các biến chủ đề gốc của bạn với `color-mix()` trong OKLCH thay vì tại thời điểm xây dựng. Đặt màu thương hiệu và thực hiện tất cả 11 bước sau đó, do đó bạn không bao giờ đặt chúng bằng tay.

Mỗi bước là một biến CSS và tiện ích Tailwind cùng một lúc: sử dụng `var(--color-primary-700)` trong CSS của riêng bạn, hoặc `bg-primary-700` trong đánh dấu. Di chuột một mẫu để xem cả hai tên.

<ColorScale />

Vì các bước được tính toán từ chủ đề của bạn chứ không phải được mã hóa cứng nên lưới này không phải là hình ảnh về màu sắc của Frutjam. Đó là màu sắc của bạn. Chuyển đổi chủ đề và mọi mẫu màu ở trên sẽ di chuyển theo chủ đề đó, đó cũng là lý do tại sao không có giá trị hex nào được in bên cạnh chúng.

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

Khi văn bản nằm trên một màu, hãy sử dụng cặp màu mà thư viện kiểm tra: <code>bg-primary</code> với <code>text-on-primary</code>.</span></div></div>"} />

## Các lớp tiện ích màu sắc

Tất cả các màu Frutjam đều hoạt động với mọi tiện ích màu CSS Tailwind. Thay thế `{color}` với bất kỳ tên màu nào từ bảng trên, tùy chọn theo sau là một bước từ thang điểm 50-950: `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Lớp học | Sự miêu tả |
| --- | --- |
| `bg-{color}` | Màu nền |
| `text-{color}` | Màu văn bản |
| `border-{color}` | Màu viền |
| `ring-{color}` | Màu nhẫn |
| `outline-{color}` | Màu phác thảo |
| `shadow-{color}` | Màu bóng |
| `fill-{color}` | Màu tô SVG |
| `stroke-{color}` | Màu nét SVG |
| `decoration-{color}` | Màu sắc trang trí văn bản |
| `caret-{color}` | Màu dấu mũ đầu vào |
| `placeholder-{color}` | Màu văn bản giữ chỗ |
| `divide-{color}` | Màu đường viền ngăn cách |
| `{utility}-{color}-{step}` | Bất kỳ điều nào ở trên ở một bước quy mô, ví dụ `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### Công cụ sửa đổi độ mờ

Kiểm soát độ mờ màu bằng `/{value}` công cụ sửa đổi, giống như bất kỳ màu Tailwind nào.

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## Mềm mại & năng động

Các biến thể nhận biết trạng thái dành cho các thành phần tương tác, tự động thích ứng với chủ đề sáng và tối.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Biến CSS | Sự miêu tả |
| --- | --- |
| `--color-{color}-soft` | Nền nhuốm màu tinh tế cho các biến thể mềm mại |
| `--color-on-{color}-soft` | Màu văn bản để sử dụng trên nền mềm |
| `--color-{color}-active` | Bóng tối/sáng cho trạng thái di chuột và hoạt động |
| `--color-body` | Màu văn bản nội dung được tính toán (được làm mềm một chút từ `on-base`) |

</DocTable>

## Biến CSS chủ đề

Đây là các mã thông báo gốc mà bạn xác định khi tạo chủ đề tùy chỉnh. Tất cả các mã thông báo màu khác được tính toán tự động từ những mã này.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Biến CSS | Sự miêu tả |
| --- | --- |
| `--scheme-color` | Cách phối màu: `light` hoặc `dark` |
| `--border-radius` | Bán kính đường viền cơ sở cho các thành phần |
| `--color-base` | Màu nền trang |
| `--color-on-base` | Màu văn bản mặc định trên nền cơ sở |
| `--color-neutral` | Màu bề mặt trung tính |
| `--color-on-neutral` | Màu văn bản trên bề mặt trung tính |
| `--color-primary` | Màu thương hiệu chính |
| `--color-on-primary` | Màu văn bản trên nền chính |
| `--color-secondary` | Màu thương hiệu phụ |
| `--color-on-secondary` | Màu văn bản trên nền phụ |
| `--color-accent` | Màu nhấn |
| `--color-on-accent` | Màu văn bản trên nền có điểm nhấn |
| `--color-info` | Màu thông tin |
| `--color-on-info` | Màu văn bản trên nền thông tin |
| `--color-success` | Màu thành công |
| `--color-on-success` | Màu văn bản trên nền thành công |
| `--color-warning` | Màu cảnh báo |
| `--color-on-warning` | Màu văn bản trên nền cảnh báo |
| `--color-error` | Lỗi màu |
| `--color-on-error` | Màu văn bản trên nền lỗi |

</DocTable>

## Ví dụ về chủ đề tùy chỉnh

Ghi đè mã thông báo gốc để tạo chủ đề tùy chỉnh. Frutjam tự động tính toán tất cả các thang đo và trạng thái.

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
