Yalnızca CSS'ye özgü Tailwind CSS yıldızı ve kalp derecelendirme bileşeni. Boyutlar xs-xl, yarım yıldız desteği, JavaScript gerekmez. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Derecelendirme bileşenleri, kullanıcıların ürünlere, hizmetlere veya içeriğe yıldız veya sayısal derecelendirme atayarak geri bildirimde bulunmalarına olanak tanır. Anlamsal HTML girişleri ve etkileşimli stil ile oluşturulan derecelendirmeler, kullanıcı memnuniyetini ve kaliteli geri bildirimi iletir. Frutjam derecelendirme sistemi birden fazla stili, rengi ve boyutu destekler; ürün incelemeleri, kullanıcı geri bildirim formları ve memnuniyet anketleri için idealdir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
