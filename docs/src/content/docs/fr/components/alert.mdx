## Disposition et comportement des alertes

### Alertes pleine largeur

Utilisez la classe utilitaire `w-full` pour créer une **alerte** sur toute la largeur de son conteneur. Cela fonctionne avec toutes les variantes de couleurs et de styles.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

<Snippet>

```html
<div role="alert" class="alert w-full">
```
