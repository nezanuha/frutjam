Botón CSS Tailwind solo para CSS con variantes primaria, secundaria, de acento, fantasma, contorno y suave. Tallas xs-xl, estado de carga, deshabilitado y botones de íconos. Solo CSS, WCAG AA, funciona con Django, HTMX, Laravel, React.

Los componentes de botones son elementos interactivos que desencadenan acciones o llevan a los usuarios a nuevas páginas. El sistema de botones Frutjam ofrece múltiples tamaños, colores y estilos a través de clases de modificadores, todos creados con el enfoque de utilidad Tailwind CSS para botones livianos y altamente personalizables que funcionan a la perfección en marcos y proyectos.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.
