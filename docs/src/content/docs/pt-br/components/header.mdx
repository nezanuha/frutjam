Cabeçalho de página CSS Tailwind somente CSS – layout da barra superior com marca, navegação e slots de ação. WCAG AA acessível, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes de cabeçalho criam áreas de navegação e branding consistentes para seu site ou aplicativo. Construído com elementos de cabeçalho HTML semânticos, o sistema de cabeçalho Frutjam combina logotipos, links de navegação e ações do usuário em uma barra coesa e responsiva. Suporta vários layouts, opções de alinhamento e integra-se perfeitamente com menus suspensos e funcionalidade de pesquisa.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.

## Uso Básico

O cabeçalho usa uma grade de três colunas via `header-content`: `header-start` (logotipo), `header-center` (navegação centralizada opcional) e `header-end` (ações e alternância móvel).
