Le système de couleurs de Frutjam utilise des jetons CSS sémantiques conçus pour répondre aux rapports de contraste WCAG AA dès le départ. Pas de JavaScript, compatible avec le mode sombre, compatible avec Tailwind CSS v4. Fonctionne avec Django, HTMX, Laravel et toute pile CSS uniquement.

Frutjam utilise les propriétés personnalisées CSS comme jetons de conception pour toutes les couleurs. Chaque couleur est définie par thème et fonctionne automatiquement avec les classes utilitaires CSS Tailwind, aucune configuration supplémentaire n'est nécessaire. CSS uniquement, aucun JavaScript requis. Contraste WCAG AA garanti sur chaque paire de couleurs, fonctionne avec Django, HTMX, Laravel, React et tout projet Tailwind CSS v4.

## Noms des couleurs

Frutjam définit les rôles de couleur sémantiques suivants. Chaque couleur a une correspondance `on-{color}` jeton pour le texte de premier plan accessible.

## Échelle de couleurs (50–950)

Chaque couleur génère une échelle de 11 étapes, calculée à partir des variables de votre thème racine avec `color-mix()` dans OKLCH plutôt qu'au moment de la construction. Définissez une couleur de marque et les onze étapes en découlent, de sorte que vous ne les définissez jamais à la main.

Chaque étape est à la fois une variable CSS et un utilitaire Tailwind : utilisez `var(--color-primary-700)` dans votre propre CSS, ou `bg-primary-700` dans le balisage. Passez la souris sur un échantillon pour voir les deux noms.

<ColorScale />

Parce que les étapes sont calculées à partir de votre thème plutôt que codées en dur, cette grille n'est pas une image des couleurs de Frutjam. Ce sont vos couleurs. Changez de thème et chaque échantillon ci-dessus se déplace avec lui, c'est aussi pourquoi aucune valeur hexadécimale n'est imprimée à côté d'eux.

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

## Classes d'utilitaires de couleur

Toutes les couleurs Frutjam fonctionnent avec n'importe quel utilitaire de couleur CSS Tailwind. Remplacer `{color}` avec n'importe quel nom de couleur du tableau ci-dessus, éventuellement suivi d'un échelon de l'échelle 50-950 : `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Classe | Description |
| --- | --- |
| `bg-{color}` | Couleur de fond |
| `text-{color}` | Couleur du texte |
| `border-{color}` | Couleur de la bordure |
| `ring-{color}` | Couleur de la bague |
| `outline-{color}` | Couleur du contour |
| `shadow-{color}` | Couleur de l'ombre |
| `fill-{color}` | Couleur de remplissage SVG |
| `stroke-{color}` | Couleur du trait SVG |
| `decoration-{color}` | Couleur de décoration du texte |
| `caret-{color}` | Couleur du curseur d'entrée |
| `placeholder-{color}` | Couleur du texte de l'espace réservé |
| `divide-{color}` | Couleur de la bordure du séparateur |
| `{utility}-{color}-{step}` | N'importe lequel des éléments ci-dessus à un échelon d'échelle, par exemple `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### Modificateur d'opacité

Contrôlez l'opacité des couleurs avec le `/{value}` modificateur, comme n’importe quelle couleur Tailwind.

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## Doux et actif

Variantes sensibles à l'état pour les éléments interactifs, s'adaptant automatiquement aux thèmes clairs et sombres.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Variable CSS | Description |
| --- | --- |
| `--color-{color}-soft` | Fond teinté subtil pour des variantes douces |
| `--color-on-{color}-soft` | Couleur du texte à utiliser sur des arrière-plans mous |
| `--color-{color}-active` | Nuance assombrie/éclaircie pour les états de vol stationnaire et actif |
| `--color-body` | Couleur du corps du texte calculé (légèrement adoucie par rapport à `on-base`) |

</DocTable>

| `--color-base` | Couleur d’arrière-plan de la page |
| `--color-on-base` | Couleur du texte par défaut sur l'arrière-plan de base |
| `--color-neutral` | Couleur de surface neutre |
| `--color-on-neutral` | Couleur du texte sur surfaces neutres |
| `--color-primary` | Couleur principale de la marque |
| `--color-on-primary` | Couleur du texte sur les arrière-plans principaux |
| `--color-secondary` | Couleur de marque secondaire |
| `--color-on-secondary` | Couleur du texte sur les arrière-plans secondaires |
| `--color-accent` | Couleur d'accentuation |
| `--color-on-accent` | Couleur du texte sur les arrière-plans accentués |
| `--color-info` | Couleur des informations |
| `--color-on-info` | Couleur du texte sur les arrière-plans d'informations |
| `--color-success` | Couleur du succès |
| `--color-on-success` | Couleur du texte sur les arrière-plans de réussite |
| `--color-warning` | Couleur d'avertissement |
| `--color-on-warning` | Couleur du texte sur les arrière-plans d'avertissement |
| `--color-error` | Couleur d'erreur |

</DocTable>

## Exemple de thème personnalisé

Remplacez les jetons racine pour créer un thème personnalisé. Frutjam calcule automatiquement toutes les échelles et tous les états.

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
