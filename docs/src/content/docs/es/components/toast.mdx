Tostada CSS de Tailwind solo CSS para posicionamiento de notificaciones: ubicación superior, inferior, inicial, final y central. Sin JavaScript para el diseño. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes de Toast muestran notificaciones breves y no intrusivas ubicadas en los bordes de la pantalla. Construidos con componentes de alerta y posicionamiento fijo, los brindis comunican comentarios del sistema, como confirmaciones de éxito, mensajes de error o actualizaciones de estado. El sistema de brindis de Frutjam admite seis posiciones de ubicación, ideal para envíos de formularios, operaciones asíncronas y notificaciones en tiempo real.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.

## Uso básico

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## Entrada Animación

Cada tostada se desvanece y se coloca en su lugar por sí sola. No hay nada que añadir para eso, y no hay clase para encenderlo.

El  `toast-slide-*` los modificadores son para cuando se desea una dirección diferente de la subida predeterminada. Elige el borde sobre el que se asienta la tostada, para que entre desde fuera de la pantalla en lugar de cruzarla: `toast-slide-end` pertenece a `toast-end`, `toast-slide-down` con `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

La distancia es el ancho o la altura de la tostada, no la distancia al borde de la pantalla, por lo que una tostada centrada comienza cerca del centro en lugar de fuera de la pantalla.

No hay animación de salida. Una tostada desaparece en el momento en que se elimina de la página, porque CSS no tiene un estado del que salir. Desvanecer uno significa mantenerlo en el Dom y animarlo usted mismo.

La animación se omite para cualquier persona que haya pedido movimiento reducido.

## Anchura

Cada tostada tiene un límite de `24rem` para que un mensaje largo no abarque la pantalla de un teléfono. Anular `--toast--width` No es así.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
