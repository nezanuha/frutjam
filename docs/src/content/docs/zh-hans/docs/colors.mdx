Frutjam 的颜色系统使用语义 CSS 标记，旨在满足开箱即用的 WCAG AA 对比度。无需 JavaScript，支持深色模式，兼容 Tailwind CSS v4。适用于 Django、HTMX、Laravel 和任何纯 CSS 堆栈。

Frutjam 使用 CSS 自定义属性作为所有颜色的设计标记。每种颜色都是根据主题定义的，并自动与 Tailwind CSS 实用程序类一起使用，无需额外配置。仅 CSS，无需 JavaScript。 WCAG AA 对比度保证每个颜色对，适用于 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 项目。

## 颜色名称

Frutjam 定义了以下语义颜色角色。每个颜色都有一个搭配 `on-{color}` 可访问前景文本的标记。

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| 颜色 | 代币 | 目的 |
| --- | --- | --- |
| <span class="badge badge-sm bg-base border">根据</span> | `--color-base` | 页面背景 |
| <span class="badge badge-sm bg-neutral text-on-neutral">中性的</span> | `--color-neutral` | 表面、侧边栏、覆盖层 |
| <span class="badge badge-sm badge-primary">基本的</span> | `--color-primary` | 主要品牌颜色 |
| <span class="badge badge-sm badge-secondary">中学</span> | `--color-secondary` | 次品牌色 |
| <span class="badge badge-sm badge-accent">口音</span> | `--color-accent` | 强调/突出显示颜色 |
| <span class="badge badge-sm badge-info">信息</span> | `--color-info` | 信息性消息 |
| <span class="badge badge-sm badge-success">成功</span> | `--color-success` | 成功状态 |
| <span class="badge badge-sm badge-warning">警告</span> | `--color-warning` | 警告状态 |
| <span class="badge badge-sm badge-error">错误</span> | `--color-error` | 错误和破坏性状态 |

</DocTable>

## 色阶 (50–950)

每种颜色都会生成一个 11 级比例，根据您的根主题变量计算得出 `color-mix()` 在 OKLCH 中而不是在构建时。设置品牌颜色后，所有十一个步骤都会随之而来，因此您无需手动设置它们。

每个步骤都是一个 CSS 变量和一个 Tailwind 实用程序：使用 `var(--color-primary-700)` 在你自己的 CSS 中，或者 `bg-primary-700` 在标记中。将鼠标悬停在样本上即可查看两个名字。

<ColorScale />

因为这些步骤是根据您的主题计算的，而不是硬编码的，所以该网格不是 Frutjam 颜色的图片。这是你的颜色。切换主题，上面的每个样本都会随之移动，这也是为什么它们旁边没有打印十六进制值的原因。

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

<RawHtml html={"<div class=\"not-prose\"><div role=\"alert\" class=\"alert alert-sm alert-warning alert-soft mt-6\"><span><strong>步骤是为了装饰，而不是正文。</strong> 比例步骤没有匹配 <code>on-</code> 颜色，因此没有什么可以保证与之形成对比。当文本位于某种颜色上时，请使用库测试的颜色对： <code>bg-primary</code> 和 <code>text-on-primary</code>.</span></div></div>"} />

| CSS 变量 | 描述 |
| --- | --- |
| `--color-{color}-50` | 80% 的浅色，20% 的颜色 |
| `--color-{color}-100` | 65% 光，35% 颜色 |
| `--color-{color}-200` | 50% 光，50% 颜色 |
| `--color-{color}-300` | 35% 光，65% 颜色 |
| `--color-{color}-400` | 18% 光，82% 色彩 |
| `--color-{color}-500` | 颜色本身，与 `--color-{color}` |
| `--color-{color}-600` | 18% 深色阴影，82% 彩色 |
| `--color-{color}-700` | 34% 深色，66% 彩色 |
| `--color-{color}-800` | 50% 深色，50% 彩色 |
| `--color-{color}-900` | 65% 深色，35% 彩色 |
| `--color-{color}-950` | 80% 深色，20% 彩色 |

</DocTable>

## 颜色实用程序类

所有 Frutjam 颜色均可与任何 Tailwind CSS 颜色实用程序配合使用。代替 `{color}` 使用上表中的任何颜色名称，可选地后跟 50-950 范围内的一个步骤： `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| 班级 | 描述 |
| --- | --- |
| `bg-{color}` | 背景颜色 |
| `text-{color}` | 文字颜色 |
| `border-{color}` | 边框颜色 |
| `ring-{color}` | 戒指颜色 |
| `outline-{color}` | 轮廓颜色 |
| `shadow-{color}` | 阴影颜色 |
| `fill-{color}` | SVG 填充颜色 |
| `stroke-{color}` | SVG 描边颜色 |
| `decoration-{color}` | 文字装饰颜色 |
| `caret-{color}` | 输入插入符号颜色 |
| `placeholder-{color}` | 占位符文本颜色 |
| `divide-{color}` | 分隔线边框颜色 |
| `{utility}-{color}-{step}` | 例如，以上任意一个规模步骤 `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### 不透明度修改器

控制颜色不透明度 `/{value}` 修饰符，就像任何 Tailwind 颜色一样。

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## 柔和活跃

交互式元素的状态感知变体，自动适应浅色和深色主题。

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 变量 | 描述 |
| --- | --- |
| `--color-{color}-soft` | 柔和的变体的微妙有色背景 |
| `--color-on-{color}-soft` | 用于柔和背景的文本颜色 |
| `--color-{color}-active` | 悬停和活动状态的深色/浅色阴影 |
| `--color-body` | 计算出的正文颜色（从 `on-base`) |

</DocTable>

## 主题 CSS 变量

这些是您在创建自定义主题时定义的根标记。所有其他颜色标记都是根据这些自动计算的。

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| CSS 变量 | 描述 |
| --- | --- |
| `--scheme-color` | 配色方案： `light` 或者 `dark` |
| `--border-radius` | 组件的基础边框半径 |
| `--color-base` | 页面背景颜色 |
| `--color-on-base` | 基本背景上的默认文本颜色 |
| `--color-neutral` | 中性表面颜色 |
| `--color-on-neutral` | 中性表面上的文本颜色 |
| `--color-primary` | 主要品牌颜色 |
| `--color-on-primary` | 主要背景上的文本颜色 |
| `--color-secondary` | 次品牌色 |
| `--color-on-secondary` | 辅助背景上的文本颜色 |
| `--color-accent` | 强调色 |
| `--color-on-accent` | 强调背景上的文本颜色 |
| `--color-info` | 信息颜色 |
| `--color-on-info` | 信息背景上的文本颜色 |
| `--color-success` | 成功色 |
| `--color-on-success` | 成功背景上的文字颜色 |
| `--color-warning` | 警告色 |
| `--color-on-warning` | 警告背景上的文本颜色 |
| `--color-error` | 错误颜色 |
| `--color-on-error` | 错误背景上的文本颜色 |

</DocTable>

## 自定义主题示例

覆盖根令牌以创建自定义主题。 Frutjam 自动计算所有尺度和状态。

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
