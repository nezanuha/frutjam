僅 CSS 的 Tailwind CSS 文字區域，具有主要、次要、重音和語義顏色變體。尺寸 xs-xl，幽靈風格。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

文字區域元件可擷取使用者的多行文字輸入，非常適合訊息、評論、描述和長格式內容。文字區域採用原生 HTML 文字區域元素構建，並透過 Tailwind CSS 樣式進行增強，支援多種尺寸、顏色和狀態。它們可訪問且完全可定制，可無縫整合到表單和通訊介面中。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

## 進階 Markdown 編輯器

使用 `markdown-text-editor` 將任何文字區域變成完整的 Markdown 編輯器。 有兩種模式可用：**純文字**（原始 Markdown 語法）和**混合**（在您輸入時即時呈現格式）。 如需更多配置選項，請參閱[插件文件](https://frutjam.com/plugins/markdown-editor)。

### 普通模式

顯示原始 Markdown 語法。使用者直接在文字區域中編寫 Markdown。

<Snippet>

```html
<textarea id="plain-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#plain-markdown-editor');
```

</Snippet>

### 混合模式

在您鍵入時即時呈現格式 — 粗體、標題、清單等以內嵌樣式顯示。

<Snippet>

```html
<textarea id="hybrid-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#hybrid-markdown-editor', { mode: 'hybrid' });
```

</Snippet>
