Menú desplegable de selección de CSS Tailwind solo para CSS con variantes de color primario, secundario, de acento y semántico. Tallas xs-xl, estilo fantasma. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes seleccionados proporcionan a los usuarios una lista desplegable de opciones mutuamente excluyentes, lo que les permite elegir un valor de un conjunto predefinido. Construidas con elementos de selección HTML nativos y mejoradas con el estilo CSS Tailwind, las selecciones admiten múltiples tamaños, colores y estados. Los menús desplegables de selección, accesibles y navegables por teclado, son ideales para elegir entre grandes listas de opciones, selección de países y paneles de preferencias.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.
