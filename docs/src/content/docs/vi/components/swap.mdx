Trao đổi CSS Tailwind chỉ dành cho CSS để chuyển đổi giữa hai phần tử. Lật, xoay và làm mờ hình ảnh động, không có JavaScript. WCAG AA có thể truy cập được, hoạt động với Django, HTMX, Laravel, React và bất kỳ ngăn xếp nào.

Hoán đổi các thành phần chuyển đổi giữa hai trạng thái nội dung bằng hình ảnh động mượt mà để phản hồi tương tác của người dùng. Được xây dựng bằng các chuyển tiếp HTML và CSS ngữ nghĩa, hoán đổi cho phép thay đổi trạng thái một cách tinh tế mà không cần JavaScript. Hệ thống hoán đổi Frutjam hỗ trợ nhiều kiểu hoạt ảnh—lý tưởng cho việc chuyển đổi chủ đề, chuyển đổi chế độ, trạng thái tải và hình minh họa tương tác.

Chỉ CSS, không cần JavaScript. WCAG AA có thể truy cập và không phụ thuộc vào khung — hoạt động với Django, HTMX, Laravel, React và bất kỳ ngăn xếp nào.

## Cách sử dụng cơ bản

Tạo một trao đổi đơn giản với biểu tượng cảm xúc hoặc nội dung văn bản bằng cách sử dụng hộp kiểm để chuyển đổi trạng thái.

<Snippet>

```html
<label class="swap">
  <input type="checkbox" />
  <div class="swap-on">☀️</div>
  <div class="swap-off">🌙</div>
</label>
```

```jsx
<label className="swap">
  <input type="checkbox" />
  <div className="swap-on">☀️</div>
  <div className="swap-off">🌙</div>
</label>
```

</Snippet>

## Hoán đổi ảnh động

Áp dụng các kiểu hoạt ảnh khác nhau cho chuyển tiếp trực quan: làm mờ (mặc định), xoay và lật.

<Snippet>

```html
<label class="swap">
  <input type="checkbox" />
  <div class="swap-on">Online</div>
  <div class="swap-off">Offline</div>
</label>

<label class="swap swap-rotate">
  <input type="checkbox" />
  <div class="swap-on">➕</div>
  <div class="swap-off">✖️</div>
</label>

<label class="swap swap-flip">
  <input type="checkbox" />
  <div class="swap-on">Yes</div>
  <div class="swap-off">No</div>
</label>
```

</Snippet>
