Sistem warna Frutjam menggunakan token CSS semantik yang dirancang untuk memenuhi rasio kontras WCAG AA yang siap digunakan. Tanpa JavaScript, mendukung mode gelap, kompatibel dengan Tailwind CSS v4. Bekerja dengan Django, HTMX, Laravel, dan tumpukan khusus CSS apa pun.

Frutjam menggunakan properti khusus CSS sebagai token desain untuk semua warna. Setiap warna ditentukan per tema dan secara otomatis berfungsi dengan kelas utilitas Tailwind CSS, tidak diperlukan konfigurasi tambahan. Hanya CSS, tidak diperlukan JavaScript. Kontras WCAG AA dijamin pada setiap pasangan warna, berfungsi dengan Django, HTMX, Laravel, React, dan proyek Tailwind CSS v4 apa pun.

## Nama Warna

Frutjam mendefinisikan peran warna semantik berikut. Setiap warna mempunyai kecocokan `on-{color}` token untuk teks latar depan yang dapat diakses.

## Skala Warna (50–950)

Setiap warna menghasilkan skala 11 langkah, dihitung dari variabel tema akar Anda dengan `color-mix()` di OKLCH daripada pada waktu pembuatan. Tetapkan warna merek dan kesebelas langkah mengikuti darinya, jadi Anda tidak pernah mengaturnya dengan tangan.

Setiap langkah adalah variabel CSS dan utilitas Tailwind sekaligus: gunakan `var(--color-primary-700)` di CSS Anda sendiri, atau `bg-primary-700` dalam penandaan. Arahkan kursor ke contoh untuk melihat kedua nama tersebut.

<ColorScale />

Karena langkah-langkahnya dihitung dari tema Anda dan bukan dari hardcode, grid ini bukanlah gambar warna Frutjam. Itu adalah warnamu. Ganti tema dan setiap contoh di atas akan ikut berpindah, itulah sebabnya tidak ada nilai hex yang tercetak di sebelahnya.

<Snippet>

```html
<div class="bg-primary-100 text-primary-900 p-4 rounded">Light tint, dark text</div>
<div class="bg-success-700 text-success-50 p-4 rounded">Dark shade, light text</div>
<div class="border-2 border-error-400 text-error-600 p-4 rounded">Border and text</div>
```

</Snippet>

## Kelas Utilitas Warna

Semua warna Frutjam dapat digunakan dengan utilitas warna Tailwind CSS apa pun. Mengganti `{color}` dengan nama warna apa pun dari tabel di atas, secara opsional diikuti dengan langkah dari skala 50-950: `bg-primary`, `bg-primary-100`, `text-error-900`, `border-success-300`.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Kelas | Keterangan |
| --- | --- |
| `bg-{color}` | Warna latar belakang |
| `text-{color}` | Warna teks |
| `border-{color}` | Warna perbatasan |
| `ring-{color}` | Warna cincin |
| `outline-{color}` | Warna garis luar |
| `shadow-{color}` | Warna bayangan |
| `fill-{color}` | Warna isian SVG |
| `stroke-{color}` | Warna guratan SVG |
| `decoration-{color}` | Warna dekorasi teks |
| `caret-{color}` | Masukkan warna tanda sisipan |
| `placeholder-{color}` | Warna teks placeholder |
| `divide-{color}` | Warna batas pembatas |
| `{utility}-{color}-{step}` | Salah satu hal di atas dalam skala besar, misalnya `bg-accent-200` |

</DocTable>

<Snippet>

```html
<div class="bg-primary text-on-primary p-4 rounded">Primary background</div>
<div class="bg-secondary text-on-secondary p-4 rounded">Secondary background</div>
<div class="border border-primary text-primary p-4 rounded">Primary border and text</div>
```

</Snippet>

#### Pengubah Opasitas

Kontrol opacity warna dengan `/{value}` pengubah, sama seperti warna Tailwind lainnya.

<Snippet>

```html
<div class="bg-primary/10 text-primary p-4 rounded">10% primary background</div>
<div class="bg-primary/20 text-primary p-4 rounded">20% primary background</div>
<div class="text-on-base/60 p-4">60% opacity text</div>
```

</Snippet>

## Lembut & Aktif

Varian yang sadar negara untuk elemen interaktif, secara otomatis beradaptasi dengan tema terang dan gelap.

<DocTable wrapper="overflow-x-auto" table="table table-sm">

| Variabel CSS | Keterangan |
| --- | --- |
| `--color-{color}-soft` | Latar belakang berwarna halus untuk varian lembut |
| `--color-on-{color}-soft` | Warna teks untuk digunakan pada latar belakang lembut |
| `--color-{color}-active` | Warna gelap/terang untuk keadaan melayang dan aktif |
| `--color-body` | Warna teks isi yang dihitung (sedikit diperhalus dari `on-base`) |

</DocTable>

## Contoh Tema Kustom

Ganti token root untuk membuat tema khusus. Frutjam menghitung semua skala dan status secara otomatis.

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";

[data-theme="mytheme"] {
  --scheme-color: light;
  --border-radius: 0.5rem;

  --color-base: oklch(98% 0 0);
  --color-on-base: oklch(15% 0 0);

  --color-neutral: oklch(20% 0 0);
  --color-on-neutral: oklch(98% 0 0);

  --color-primary: oklch(55% 0.25 260);
  --color-on-primary: oklch(98% 0 0);

  --color-secondary: oklch(60% 0.20 320);
  --color-on-secondary: oklch(98% 0 0);

  --color-accent: oklch(65% 0.22 180);
  --color-on-accent: oklch(15% 0 0);

  --color-info: oklch(68% 0.17 237);
  --color-on-info: oklch(15% 0 0);

  --color-success: oklch(75% 0.20 150);
  --color-on-success: oklch(15% 0 0);

  --color-warning: oklch(82% 0.19 90);
  --color-on-warning: oklch(15% 0 0);

  --color-error: oklch(58% 0.24 27);
  --color-on-error: oklch(98% 0 0);
}
```

</Snippet>
