僅 CSS Tailwind CSS 時間線，用於按時間順序排列的事件清單。帶有圖示、內容和連接線槽的垂直佈局。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

時間軸組件會依時間順序顯示一系列事件、里程碑或敘述過程。時間表採用語意 HTML 構建，可協助使用者了解歷史進展和專案階段。 Frutjam 時間軸系統支援多種方向、顏色和專案樣式，非常適合專案歷史記錄、發行說明和旅程地圖。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
