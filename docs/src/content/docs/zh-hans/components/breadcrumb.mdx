纯 CSS Tailwind CSS 面包屑导航，具有自定义分隔符和可访问的地标标记。 WCAG AA，适用于 Django、HTMX、Laravel、React 和任何 Tailwind CSS v4 项目。

面包屑组件显示导航层次结构并帮助用户了解他们在网站中的位置。面包屑使用语义 HTML 导航元素和 ARIA 地标构建以实现可访问性，允许用户快速导航到父部分，从而提高可用性。 Frutjam 面包屑系统自动呈现分隔符并支持自定义分隔符以实现灵活的样式。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

## 基本用法

如果未提供分隔符，则面包屑项目之间会自动显示一个箭头。

<Snippet>

```html
<nav class="breadcrumb" aria-label="Breadcrumb">
  <ol class="breadcrumb-list">
    <li class="breadcrumb-item">
      <a href="/" class="breadcrumb-link">Home</a>
    </li>
    <li class="breadcrumb-item">
      <span class="breadcrumb-current" aria-current="page">Current Page</span>
    </li>
  </ol>
</nav>
```

```jsx
<nav className="breadcrumb" aria-label="Breadcrumb">
  <ol className="breadcrumb-list">

    </li>

    </li>
  </ol>
</nav>
```

</Snippet>

## 面包屑导航辅助功能

为了确保屏幕阅读器可以访问面包屑：

- 将结构包裹在 `<nav>` 元素与 `aria-label="Breadcrumb"`.
- 最后一项（当前页面）应该使用 `aria-current="page"` 并且优选地是 `<span>` 而不是链接。
- 屏幕阅读器应忽略分隔符（通常通过 CSS 或 `aria-hidden="true"` 如果使用物理元件）。
