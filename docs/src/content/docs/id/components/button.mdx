Tombol Tailwind CSS khusus CSS dengan varian primer, sekunder, aksen, bayangan, kerangka, dan lembut. Ukuran xs-xl, status pemuatan, nonaktif, dan tombol ikon. Khusus CSS, WCAG AA, bekerja dengan Django, HTMX, Laravel, React.

Komponen tombol adalah elemen interaktif yang memicu tindakan atau mengarahkan pengguna ke halaman baru. Sistem tombol Frutjam menawarkan berbagai ukuran, warna, dan gaya melalui kelas pengubah — semuanya dibangun dengan pendekatan yang mengutamakan utilitas Tailwind CSS untuk tombol ringan dan sangat dapat disesuaikan yang bekerja dengan lancar di seluruh kerangka kerja dan proyek.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
