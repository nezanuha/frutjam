Modal CSS Tailwind solo para CSS que utiliza el elemento nativo `<dialog>`. Tamaño responsivo, fondo y trampa de enfoque. Sin JavaScript para uso básico. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes modales muestran información importante o solicitan la acción del usuario en una ventana superpuesta enfocada. Construidos sobre elementos de diálogo HTML semánticos, los modales admiten animaciones, posicionamiento personalizable y superposiciones de fondo. El sistema modal Frutjam es totalmente accesible con navegación por teclado y enfoque de trampa, lo que lo hace ideal para confirmaciones, formularios y diálogos de alerta.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.

## Uso básico

Agregue una identificación única al elemento HTML `<dialog id="myModal">`, luego use esa identificación en JavaScript para llamar a `myModal.showModal()` para abrir el modal y `myModal.close()` para cerrar el modal.

```html
<dialog class="modal modal-center lg:modal-middle modal-slide-end lg:modal-slide-down" id="toggleModal">
  <div class="modal-content">
    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Dialog modal</div>
      <button type="button" class="btn btn-xs btn-square btn-rounded btn-ghost" onclick="toggleModal.close()">
        <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
          <path d="M18 6 6 18"></path>

        </svg>
      </button>
    </div>
    <div class="divider my-3"></div>

  </div>
  <button type="button" class="modal-backdrop" onclick="toggleModal.close()">Close Modal via Backdrop</button>
</dialog>
<button type="button" class="btn btn-xs" onclick="toggleModal.showModal()">Show Modal</button>
```

## Cerrar modal al hacer clic afuera

`.modal-backdrop` proporciona un fondo en el que se puede hacer clic que cierra el modal cuando se hace clic fuera del contenido modal.

<Snippet>

```html

    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Dialog modal</div>
    </div>

  </div>

    Close Modal via Backdrop
  </button>
</dialog>
<button type="button" class="btn btn-xs" onclick="backdropModal.showModal()">Show Modal</button>
```

</Snippet>

## Animaciones de diapositivas modales

Deslícese suavemente hacia adentro y hacia afuera desde la parte superior, inferior, inicial (izquierda en LTR, derecha en RTL) o final (derecha en LTR, izquierda en RTL) con las siguientes clases de utilidad direccionales: `modal-slide-top`, `modal-slide-bottom`, `modal-slide-start` y `modal-slide-end` en el componente modal. Estas animaciones mejoran la experiencia del usuario mediante el uso de transiciones dinámicas basadas en la posición modal.

### Deslizamiento modal desde el inicio (horizontal)

Agregue la utilidad `modal-slide-start` para deslizar el modal horizontalmente desde el lado inicial; en diseños de izquierda a derecha (LTR), aparece desde la izquierda, y en diseños de derecha a izquierda (RTL), desde la derecha.

<Snippet>

```html
<dialog class="modal modal-center lg:modal-middle modal-slide-start" id="slideStartModal">
  <div class="modal-content">
    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Slide start modal</div>

        <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">
          <path d="M18 6 6 18"></path>
          <path d="m6 6 12 12"></path>
        </svg>
      </button>
    </div>
    <div class="divider my-3"></div>
```

## Colocaciones modales

El componente modal está colocado de forma predeterminada en el centro de la pantalla, pero se puede colocar dependiendo del caso de uso usando clases horizontales `modal-start`, `modal-center` o `modal-end`, y clases verticales `modal-top`, `modal-middle` o `modal-bottom`. La ubicación está diseñada teniendo en cuenta la compatibilidad RTL y LTR, lo que hace que el modal se adapte a diferentes direcciones y diseños de idiomas.

Utilice `modal-start`, `modal-center` o `modal-end` para la ubicación horizontal y `modal-top`, `modal-middle` o `modal-bottom` para la ubicación vertical. Estas clases se aplican al componente modal.
