Indicateur CSS Tailwind uniquement CSS pour superposer des badges ou des points sur n'importe quel coin d'élément. Variantes de couleurs et positionnement. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants de l'indicateur affichent l'état, les badges ou les notifications positionnés sur d'autres éléments. Construits avec un positionnement absolu et un style flexible, les indicateurs superposent des informations importantes sur les cartes, les avatars et les boutons. Le système d'indicateurs Frutjam prend en charge plusieurs emplacements, tailles et couleurs, idéal pour les badges de notification, les marqueurs d'état et les repères visuels.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.
