측정항목 표시를 위한 CSS 전용 Tailwind CSS 통계입니다. 값, 레이블, 설명 및 아이콘 슬롯입니다. 반응형 그리드 레이아웃. WCAG AA 액세스 가능하며 Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.

통계 구성요소는 핵심 지표와 수치 데이터를 명확하고 체계적인 형식으로 표시합니다. 시맨틱 HTML과 유연한 레이아웃으로 구축된 통계는 중요한 비즈니스 지표와 분석을 전달합니다. Frutjam 통계 시스템은 대시보드, 성과 보고서 및 데이터 요약에 이상적인 다양한 배열과 스타일을 지원합니다.

CSS 전용이며 JavaScript가 필요하지 않습니다. WCAG AA 액세스 가능 및 프레임워크에 구애받지 않음 — Django, HTMX, Laravel, React 및 모든 스택에서 작동합니다.
