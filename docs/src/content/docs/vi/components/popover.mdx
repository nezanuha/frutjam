Cửa sổ bật lên CSS Tailwind chỉ dành cho CSS bằng cách sử dụng API cửa sổ bật lên gốc. Bảng nội dung nổi dành cho chú giải công cụ và menu thả xuống. WCAG AA có thể truy cập được, hoạt động với Django, HTMX, Laravel, React và bất kỳ ngăn xếp nào.

Các thành phần Popover hiển thị nội dung theo ngữ cảnh liền kề với các thành phần kích hoạt mà không chiếm không gian màn hình cố định. Được xây dựng trên API HTML Popover gốc, hệ thống cửa sổ bật lên Frutjam hỗ trợ trình kích hoạt nhấp chuột và di chuột, định vị có thể tùy chỉnh và hoạt ảnh mượt mà. Hoàn hảo cho menu thả xuống, menu ngữ cảnh, menu hồ sơ người dùng và các tùy chọn bổ sung mà không cần điều hướng trang.

Chỉ CSS, không cần JavaScript — xây dựng các menu thả xuống có thể truy cập và lớp phủ theo ngữ cảnh bằng HTML thuần túy và CSS Tailwind. WCAG AA có thể truy cập và không phụ thuộc vào khung — hoạt động với Django, HTMX, Laravel, React và bất kỳ ngăn xếp nào.

## Hành vi tương tác Popover

Theo mặc định, tương tác nhấp chuột được sử dụng để mở và đóng thành phần cửa sổ bật lên. Ví dụ: đối với megamenus, bạn có thể kích hoạt tương tác dựa trên di chuột bằng cách thêm lớp `popover-hover` và xóa các thuộc tính `popovertarget` và `popover`. Điều này cho phép cửa sổ bật lên được kiểm soát hoàn toàn thông qua logic di chuột thay vì hành vi nhấp chuột gốc.

### Trình kích hoạt nhấp chuột gốc

<Snippet>

```html
<div class="popover">
  <button popovertarget="nativeClickTrigger" type="button" class="popover-toggle btn">Click here</button>
  <div tabindex="0" class="popover-content" popover id="nativeClickTrigger">
      <ul class="menu">
        <li>
          <a class="menu-item">About Us</a>
        </li>
        <li>
          <a class="menu-item">Contact Us</a>
        </li>
        <li>
          <a class="menu-item">Career</a>
        </li>
        <li>
          <a class="menu-item">Terms and conditions</a>
        </li>
      </ul>
  </div>
</div>
```

</Snippet>

## Tùy chọn định vị cửa sổ bật lên (Trên cùng, Dưới cùng, Bắt đầu, Kết thúc)
