Header halaman Tailwind CSS khusus CSS — tata letak bilah atas dengan slot merek, navigasi, dan tindakan. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen header menciptakan navigasi teratas dan area branding yang konsisten untuk situs web atau aplikasi Anda. Dibangun dengan elemen header HTML semantik, sistem header Frutjam menggabungkan logo, tautan navigasi, dan tindakan pengguna ke dalam bilah yang kohesif dan responsif. Mendukung banyak tata letak, opsi penyelarasan, dan terintegrasi secara mulus dengan dropdown dan fungsi pencarian.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Header menggunakan kisi tiga kolom melalui `header-content`: `header-start` (logo), `header-center` (nav terpusat opsional), dan `header-end` (tindakan dan tombol seluler).
