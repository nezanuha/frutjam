仅 CSS Tailwind CSS 星级和心率组件。尺寸 xs-xl，半星支持，无需 JavaScript。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

评级组件允许用户通过为产品、服务或内容分配星级或数字评级来提供反馈。评级采用语义 HTML 输入和交互式样式构建，可传达用户满意度和质量反馈。 Frutjam 评级系统支持多种样式、颜色和尺寸，非常适合产品评论、用户反馈表和满意度调查。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。
