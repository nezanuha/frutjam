Bouton CSS Tailwind uniquement CSS avec variantes primaire, secondaire, accent, fantôme, contour et douce. Tailles xs-xl, état de chargement, désactivé et boutons d'icône. CSS uniquement, WCAG AA, fonctionne avec Django, HTMX, Laravel, React.

Les composants de bouton sont des éléments interactifs qui déclenchent des actions ou orientent les utilisateurs vers de nouvelles pages. Le système de boutons Frutjam propose plusieurs tailles, couleurs et styles via des classes de modificateurs, tous construits avec l'approche utilitaire Tailwind CSS pour des boutons légers et hautement personnalisables qui fonctionnent de manière transparente dans tous les frameworks et projets.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.
