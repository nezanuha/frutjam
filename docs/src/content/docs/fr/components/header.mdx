En-tête de page CSS Tailwind uniquement en CSS : disposition de la barre supérieure avec emplacements de marque, de navigation et d'action. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants d'en-tête créent des zones de navigation et de marque cohérentes pour votre site Web ou votre application. Construit avec des éléments d'en-tête HTML sémantiques, le système d'en-tête Frutjam combine les logos, les liens de navigation et les actions des utilisateurs dans une barre cohérente et réactive. Prend en charge plusieurs mises en page, options d'alignement et s'intègre parfaitement aux listes déroulantes et aux fonctionnalités de recherche.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.
