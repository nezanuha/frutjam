Modal CSS Tailwind somente CSS usando o elemento nativo `<dialog>`. Dimensionamento responsivo, pano de fundo e armadilha de foco. Nenhum JavaScript para uso básico. WCAG AA acessível, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes modais exibem informações importantes ou solicitam ações do usuário em uma janela de sobreposição focada. Construídos em elementos de diálogo HTML semânticos, os modais suportam animações, posicionamento personalizável e sobreposições de pano de fundo. O sistema modal Frutjam é totalmente acessível com navegação por teclado e foco em trap, tornando-o ideal para confirmações, formulários e caixas de diálogo de alerta.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.

## Uso Básico

Adicione um ID exclusivo ao elemento HTML `<dialog id="myModal">` e use esse ID em JavaScript para chamar `myModal.showModal()` para abrir o modal e `myModal.close()` para fechar o modal.

```html

  <div class="modal-content">
    <div class="flex justify-between items-center gap-3">
      <div class="font-medium heading-lg">Dialog modal</div>
      <button type="button" class="btn btn-xs btn-square btn-rounded btn-ghost" onclick="toggleModal.close()">
        <svg xmlns="http://www.w3.org/2000/svg" width="20" height="20" viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round">

  </div>

</dialog>
<button type="button" class="btn btn-xs" onclick="toggleModal.showModal()">Show Modal</button>
```

## Animações modais de slides

Deslize suavemente para dentro e para fora da parte superior, inferior, início (esquerda em LTR, direita em RTL) ou final (direita em LTR, esquerda em RTL) com as seguintes classes de utilitário direcional: `modal-slide-top`, `modal-slide-bottom`, `modal-slide-start` e `modal-slide-end` no componente modal. Estas animações melhoram a experiência do usuário através do uso de transições dinâmicas baseadas na posição modal.

### Slide modal desde o início (horizontal)

Adicione o utilitário `modal-slide-start` para deslizar o modal horizontalmente do lado inicial; em layouts da esquerda para a direita (LTR), ele aparece da esquerda, e em layouts da direita para a esquerda (RTL), da direita.

## Canais modais

O componente modal é, por padrão, posicionado no centro da tela, mas pode ser colocado dependendo do caso de uso usando classes horizontais `modal-start`, `modal-center` ou `modal-end` e classes verticais `modal-top`, `modal-middle` ou `modal-bottom`. O posicionamento é projetado tendo em mente a compatibilidade RTL e LTR, tornando o modal adaptável a diferentes direções de idioma e layouts.

Use `modal-start`, `modal-center` ou `modal-end` para posicionamento horizontal e `modal-top`, `modal-middle` ou `modal-bottom` para posicionamento vertical. Essas classes são aplicadas ao componente modal.
