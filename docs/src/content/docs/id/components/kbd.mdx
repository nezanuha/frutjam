Komponen kbd CSS Tailwind khusus CSS untuk menampilkan pintasan keyboard dan kombinasi tombol. Varian ukuran. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen tombol keyboard secara visual mewakili input keyboard, berguna untuk mendokumentasikan pintasan, tombol pintas, dan navigasi keyboard. Dibangun dengan HTML semantik, elemen kbd mengkomunikasikan tindakan pengguna dan pola interaksi. Sistem Frutjam kbd mendukung berbagai ukuran dan gaya—ideal untuk dokumentasi pintasan, overlay tutorial, dan panduan keyboard.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
