Statistik Tailwind CSS khusus CSS untuk menampilkan metrik. Slot nilai, label, deskripsi, dan ikon. Tata letak grid responsif. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen stat menampilkan metrik utama dan data numerik dalam format yang jelas dan terorganisir. Dibangun dengan HTML semantik dan tata letak yang fleksibel, statistik mengomunikasikan metrik dan analisis bisnis yang penting. Sistem stat Frutjam mendukung berbagai pengaturan dan gaya—ideal untuk dasbor, laporan kinerja, dan ringkasan data.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
