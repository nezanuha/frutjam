Markaya, gezinme bağlantılarına ve eylem yuvalarına sahip, yalnızca CSS'ye özel Tailwind CSS gezinme çubuğu. Yapışkan ve şeffaf çeşitleri. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Gezinti çubuğu bileşenleri, site yapısı ve kullanıcı gezinmesi için yatay gezinme listelerini görüntüler. Semantik HTML gezinme ve liste öğeleriyle oluşturulan Frutjam gezinme çubuğu sistemi, birden fazla düzeni, duyarlı davranışı ve iç içe menü entegrasyonunu destekler. Erişilebilir ve klavyeyle gezinilebilen gezinme çubukları, ana sitede gezinme, içerik kırıntıları ve sekme arayüzleri için idealdir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.

## Gezinme Çubuğu Yerleşimleri

Gezinme çubuğu bileşeni varsayılan olarak başlangıçta konumlandırılmıştır (LTR'de solda). Yatay hizalama için `navbar-start`, `navbar-center` veya `navbar-end`'i ve dikey hizalama için `navbar-top`, `navbar-middle` veya `navbar-bottom`'u kullanın. Yerleştirme RTL dostudur.

Gezinme çubuğu listesini X ekseni boyunca hizalamak için yatay yerleştirme sınıflarını ve gezinme çubuğu özel bir yüksekliğe sahip olduğunda dikey yerleştirme sınıflarını kullanın.

### Yatay Yerleşimler

`navbar-list`'in X ekseni boyunca nasıl oturacağını kontrol edin. Bunlar RTL dostudur (Sol/Sağ yerine Başlangıç/Bitiş).

#### Yatay olarak sola hizalayın (başlat)

<Snippet>

```html
<nav class="navbar navbar-start">
  <ul class="navbar-list gap-x-6">
    <li>
      <a class="link link-xs link-hover">Navbar list 1</a>
    </li>
    <li>
      <a class="link link-xs link-hover">Navbar list 2</a>
    </li>
    <li>
      <a class="link link-xs link-hover">Navbar list 3</a>

</nav>
```
