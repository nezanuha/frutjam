Profil resimleri için yalnızca CSS'ye özel Tailwind CSS avatarı. Boyutlar xs-xl, grup yığınlama ve çevrimiçi/çevrimdışı durum göstergesi. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Avatar bileşenleri, kullanıcı profili resimlerini veya baş harflerini kompakt, özelleştirilebilir bir kapta görüntüler. Frutjam'ın CSS özel özellikleriyle oluşturulan avatarlar, arayüzünüzdeki kullanıcıları, katkıda bulunanları veya ekip üyelerini temsil eder. Avatar sistemi, görselleri ve metni, çoklu boyutları, renkleri, şekilleri, durum göstergelerini, halkaları ve grup düzenlemelerini destekler; kullanıcı listeleri, yorumlar, ekip görünümleri, profil bölümleri ve mesajlaşma arayüzleri için idealdir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.

## Temel Kullanım

Metin baş harfleri veya renkleri ile basit avatarlar oluşturun.

<Snippet>

```html
<div class="avatar">AB</div>
```

```jsx
<div className="avatar">AB</div>
```

</Snippet>

## Görsellerle Avatar

Otomatik görüntü yerleştirme ve duyarlı boyutlandırma ile kullanıcı profili fotoğraflarını görüntüleyin.

<Snippet>

```html

  <img src="https://cdn.frutjam.com/images/avatar-1.jpg?format=webp&width=32&height=32&face_crop=true" alt="Strawbery" loading="lazy" />
</div>

<div class="avatar avatar-md">
  <img src="https://cdn.frutjam.com/images/avatar-1.jpg?format=webp&width=40&height=40&face_crop=true" alt="Strawbery" loading="lazy" />

</div>
```

</Snippet>

## Avatar Boyutları

Farklı bağlamlar için avatarları ekstra küçükten (xs) 2x büyüğe (2xl) kadar ölçeklendirmek için boyut çeşitlerini kullanın.

<Snippet>

```html
<div class="avatar avatar-xs avatar-primary">XS</div>
<div class="avatar avatar-sm avatar-secondary">SM</div>
<div class="avatar avatar-md avatar-accent">MD</div>
<div class="avatar avatar-lg avatar-primary">LG</div>
<div class="avatar avatar-xl avatar-secondary">XL</div>
<div class="avatar avatar-2xl avatar-accent">2XL</div>
```

</Snippet>

## Durum Göstergeli Avatar

Kullanıcının varlığını veya uygunluğunu (çevrimiçi, çevrimdışı, meşgul, dışarıda) göstermek için avatarları durum rozetleriyle birleştirin.

<Snippet>

```html
<div class="avatar avatar-md avatar-online avatar-primary">JD</div>

<div class="avatar avatar-md avatar-offline avatar-secondary">AR</div>

<div class="avatar avatar-md avatar-busy avatar-accent">MS</div>

<div class="avatar avatar-md avatar-away avatar-info">KL</div>
```

</Snippet>

## Avatar Grubu

Ekip üyelerinin ve ortak çalışanların üst üste görüntülenmesi için birden fazla avatarı otomatik negatif kenar boşluğuyla üst üste koyun.

<Snippet>

```html
<div class="avatar-group">
  <div class="avatar avatar-md avatar-primary">A</div>
  <div class="avatar avatar-md avatar-secondary">B</div>
  <div class="avatar avatar-md avatar-accent">C</div>
  <div class="avatar avatar-md avatar-info">D</div>
</div>
```

</Snippet>

### Farklı Boyutlarda Avatar Grubu

Görsel hiyerarşi için birden fazla boyutu bir grup içinde birleştirin.

<Snippet>

```html
<div class="avatar-group">
  <div class="avatar avatar-sm avatar-primary">A</div>
  <div class="avatar avatar-md avatar-secondary">B</div>
  <div class="avatar avatar-lg avatar-accent">C</div>
</div>
```

</Snippet>

### Durumlu Avatar Grubu

Bir ekip grubundaki her üyenin uygunluk durumunu gösterin.

<Snippet>

```html

  <div class="avatar avatar-md avatar-online avatar-primary">A</div>
  <div class="avatar avatar-md avatar-offline avatar-secondary">B</div>
  <div class="avatar avatar-md avatar-busy avatar-accent">C</div>
</div>
```

</Snippet>
