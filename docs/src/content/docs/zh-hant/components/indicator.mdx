純 CSS Tailwind CSS 指示器，用於在任何元素角落疊加徽章或點。顏色變體和定位。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

指示器組件顯示位於其他元素上的狀態、徽章或通知。指示器採用絕對定位和靈活的樣式構建，可覆蓋卡片、頭像和按鈕上的重要資訊。 Frutjam 指示器系統支援多種位置、尺寸和顏色，非常適合通知徽章、狀態標記和視覺提示。

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

| indicator-middle | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 將項目定位在垂直中間 |
| indicator-bottom | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 將項目放置在底部邊緣 |
| indicator-start | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 將項目定位在左邊緣 |
| indicator-center | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 將項目放置在水平中心 |
| indicator-end | <span class="badge badge-xs badge-secondary badge-soft">修飾符</span> | 將物品放置在右邊緣 |

</DocTable>

## 基本用法

<Snippet>

```html

  <span class="indicator-item badge badge-primary">99+</span>
  <button class="btn">Messages</button>
</div>
```

```jsx
<div className="indicator">
  <span className="indicator-item badge badge-primary">99+</span>
  <button className="btn">Messages</button>
</div>
```
