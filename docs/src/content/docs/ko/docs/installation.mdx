CSS 전용 Tailwind CSS UI 라이브러리인 Frutjam을 몇 분 안에 설치하세요. 두 개의 가져오기, 제로 자바스크립트, WCAG 액세스 가능한 구성 요소를 즉시 사용할 수 있습니다. Django, HTMX, Laravel, React 및 모든 Tailwind CSS v4 프로젝트에서 작동합니다.

## 할

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

그런 다음 설정과 일치하는 아래 줄을 선택하십시오. 모두 동일한 구성 요소를 제공합니다.

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| 설정 | 추가해야 할 사항 | 함선 |
| --- | --- | --- |
| [Tailwind CSS v4](#tailwind-css-v4) | `@plugin "frutjam";` | 사용하는 것만 |
| [UnoCSS](#unocss) | `presetFrutjam()` | 사용하는 것만 |
| [바이트, 아스트로, 레일, 플레인 CSS](#no-utility-engine) | `import 'frutjam/css'` | 모든 구성 요소, 30KB gzip |
| [빌드 단계 없음](#no-build-step) | a `<link>` 태그 | 모든 구성 요소 |

</DocTable>

## Tailwind CSS v4

업무용 차량이 필요합니다 [Tailwind CSS](https://tailwindcss.com/docs/installation/using-vite) 프로젝트, 플러스 [노드](https://nodejs.org/en/download) 그리고 npm입니다. Frutjam은 Tailwind 4가 필요합니다.

Frutjam을 `input.css` with the `@plugin` 지침 

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

이것이 전체 설정입니다. 65개 이상의 모든 구성 요소를 즉시 사용할 수 있으며, Tailwind는 마크업에서 사용하는 구성 요소만 배송합니다.

## UnoCSS

Frutjam은 사전 설정을 제공하므로 UnoCSS는 Tailwind 플러그인과 동일한 방식으로 사용하는 구성 요소만 생성합니다.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

모든 클래스는 Tailwind에서 작동하는 것처럼 작동하며 변형도 마찬가지입니다.

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

추가 `presetAttributify()` 구성 요소 이름은 속성이 되며 각 값은 변종으로 처리됩니다.

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

두 번째 줄은 `transformerVariantGroup()` 괄호 구문에 사용할 수 있습니다. 다음과 같은 속성이 있습니다. `btn` 은 (는) 유효한 HTML이 아니므로 마크업을 검증하는 경우 클래스 양식 또는 UnoCSS의 `un-` prefix

### 옵션

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| 옵션 | 기본 | 목적 |
| --- | --- | --- |
| `preflight` | `true` | Frutjam의 토큰, 재설정 및 테마를 방출합니다. 다음으로 설정 `false` 이미 가져온 경우 `frutjam/css/base` 직접 한다. |
| `prefix` | `''` | Tailwind 플러그인과 일치 `prefix`혹 `'fj'` 을 (를) 제공합니다 `fj-btn` 및 `fj-btn="error"`. |
| `layer` | `'frutjam'` | 구성 요소가 방출되는 캐스케이드 레이어. 유틸리티 아래에 정렬되므로 유틸리티는 사전 설정 순서가 무엇이든 항상 구성 요소를 이깁니다. |

</DocTable>

### 링크 구성 요소에는 한 줄의 구성이 필요합니다

UnoCSS 간식 `link` 변형으로 CSS에 대해 `:link` 의사 클래스 및 기본 구분 기호는 다음과 같습니다. `-`플러스가  `link-2xl` "로 읽습니다.`2xl`, 방문하지 않을 때 "클래스 이름이 아닌, 아무것도 생성되지 않습니다. 이 구성 요소에만 영향을 미치며 `link-*` 보조키

UnoCSS에게 콜론만으로 분할하라고 말하거나:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

또는 접두사를 사용하여 `link` 이름 앞면:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

다른 모든 구성 요소는 영향을 받지 않습니다. `link` 57명의 이름 중 유일하게 유사 클래스와 충돌합니다.

## 유틸리티 엔진 없음

Frutjam은 Tailwind로 제작되었지만 구성 요소는 사용자 정의 속성을 읽는 일반 CSS로 컴파일됩니다. 프로젝트에서 유틸리티 엔진을 전혀 사용하지 않는 경우 플러그인 대신 스타일시트를 가져옵니다.

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

이것이 전체 설정입니다. 모든 컴포넌트 클래스가 작동하며, 테마는 `data-theme` 평소와 같이, 그 외에는 아무것도 필요하지 않습니다. 30KB gzip이며 기본 스타일, 테마 및 모든 65개 이상의 구성 요소를 운반합니다.

필요한 것만 가져오세요:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

또는 빌드 단계가 전혀 없는 경우:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## 빌드 단계 없음

태그를 넣고 마크업을 작성하세요. 이것을 프로토타입이나 제작하지 않은 페이지에 사용하십시오. 모든 구성 요소가 배송되므로 프로덕션용이 아닙니다.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

동일한 페이지에서 Tailwind의 유틸리티를 실험하려면 Tailwind의 브라우저 빌드를 옆에 추가하십시오.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript 및 React: 선택 사항, 필수 아님

Frutjam은 * * native-first 및 CSS-first * * 입니다. 버튼, 배지, 카드, 양식, 경고 등 대부분의 구성 요소는 순수 HTML 및 CSS로 작동하며 자바스크립트는 필요하지 않습니다. 와 같은 네이티브 HTML 요소 `<dialog>`, `<details>`, 그리고 `<input type="checkbox">` 브라우저가 이미 지원하는 상호 작용을 처리합니다. 모든 구성 요소는 즉시 WCAG AA에 액세스할 수 있으며 Django, HTMX, Laravel, React, Next.js 및 모든 스택에서 작동합니다.

소수의 구성 요소에는 기본 HTML 동등 항목 (토스트 알림, 콤보박스 필터링, 캐러셀 컨트롤) 이 없습니다. 이러한 경우에만 Frutjam은 경량 옵션 도우미를 배송합니다.

### Vanilla JS: `frutjam/js`

필요한 구성 요소에 대한 프레임워크에 구애받지 않는 ES 모듈 도우미. 모든 DOM 요소에 연결되며 프레임워크가 필요하지 않습니다.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### React Hooks: `frutjam/react`

동일한 기본 DOM 호출을 중심으로 얇은 React 래퍼. 각 후크는 `ref` 요소를 제어하기 위해 요소와 메소드에 연결하고 React 자체 이외의 추가 종속성은 없습니다.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

제공 기간: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
