Yerel açılır API'yi kullanan, yalnızca CSS'ye özgü Tailwind CSS açılır penceresi. Araç ipuçları ve açılır menüler için kayan içerik paneli. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Popover bileşenleri, kalıcı ekran alanını işgal etmeden, tetikleyici öğelerin yanında bağlamsal içeriği görüntüler. Yerel HTML Popover API'sini temel alan Frutjam popover sistemi, tıklama ve vurgulu tetikleyicileri, özelleştirilebilir konumlandırmayı ve pürüzsüz animasyonları destekler. Açılır menüler, içerik menüleri, kullanıcı profili menüleri ve sayfada gezinmeye gerek olmayan ek seçenekler için mükemmeldir.

Yalnızca CSS, JavaScript gerekmez; saf HTML ve Tailwind CSS ile erişilebilir açılır menüler ve bağlamsal katmanlar oluşturun. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.

## Popover Etkileşim Davranışı

Varsayılan olarak, açılır pencere bileşenini açmak ve kapatmak için tıklama etkileşimleri kullanılır. Örneğin mega menüler için, `popover-hover` sınıfını ekleyip `popovertarget` ve `popover` niteliklerini kaldırarak fareyle üzerine gelme tabanlı etkileşimi etkinleştirebilirsiniz. Bu, açılır pencerenin yerel tıklama davranışı yerine fareyle üzerine gelme mantığı aracılığıyla tamamen kontrol edilmesine olanak tanır.

### Yerel Tıklama Tetikleyicisi

<Snippet>

```html
<div class="popover">
  <button popovertarget="nativeClickTrigger" type="button" class="popover-toggle btn">Click here</button>
  <div tabindex="0" class="popover-content" popover id="nativeClickTrigger">
      <ul class="menu">
        <li>
          <a class="menu-item">About Us</a>
        </li>
        <li>
          <a class="menu-item">Contact Us</a>
        </li>
        <li>
          <a class="menu-item">Career</a>
        </li>
        <li>
          <a class="menu-item">Terms and conditions</a>
        </li>
      </ul>
  </div>
</div>
```

</Snippet>
