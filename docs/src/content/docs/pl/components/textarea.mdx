Obszar tekstowy CSS Tailwind obejmujący wyłącznie CSS z podstawowymi, dodatkowymi, akcentowanymi i semantycznymi wariantami kolorów. Rozmiary xs-xl, fason duch. Dostępny WCAG AA, współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

Komponenty Textarea przechwytują wieloliniowy tekst wprowadzany przez użytkowników, co doskonale sprawdza się w przypadku wiadomości, komentarzy, opisów i długich treści. Zbudowane z natywnych elementów obszaru tekstowego HTML i ulepszone stylami CSS Tailwind, obszary tekstowe obsługują wiele rozmiarów, kolorów i stanów. Dostępne i w pełni konfigurowalne, płynnie integrują się z formularzami i interfejsami komunikacyjnymi.

Tylko CSS, nie wymaga JavaScript. Dostępny w WCAG AA i niezależny od frameworka — współpracuje z Django, HTMX, Laravel, React i dowolnym stosem.

## Zaawansowany edytor Markdown

Użyj `markdown-text-editor`, aby zamienić dowolny obszar tekstowy w pełny edytor przecen. Dostępne są dwa tryby: **zwykły** (surowa składnia Markdown) i **hybrydowy** (renderuje formatowanie na żywo podczas pisania). Więcej opcji konfiguracji znajdziesz w [dokumentacji wtyczek](https://frutjam.com/plugins/markdown-editor).

### Tryb zwykły

Wyświetla surową składnię Markdown. Użytkownicy piszą Markdown bezpośrednio w obszarze tekstowym.

<Snippet>

```html
<textarea id="plain-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#plain-markdown-editor');
```

</Snippet>

### Tryb hybrydowy

Renderuje formatowanie na żywo podczas pisania — pogrubienie, nagłówki, listy i inne elementy są wyświetlane w formie wbudowanej.

<Snippet>

```html
<textarea id="hybrid-markdown-editor" name="content"></textarea>
```

```js
import MarkdownEditor from 'https://cdn.jsdelivr.net/npm/markdown-text-editor/+esm';

new MarkdownEditor('#hybrid-markdown-editor', { mode: 'hybrid' });
```

</Snippet>
