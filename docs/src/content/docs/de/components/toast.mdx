Nur CSS-Tailwind-CSS-Toast für die Benachrichtigungspositionierung: oben, unten, Anfang, Ende und Mittenplatzierung. Kein JavaScript für das Layout. WCAG AA zugänglich, funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

Toast-Komponenten zeigen kurze, unaufdringliche Benachrichtigungen an den Rändern des Bildschirms an. Toasts basieren auf festen Positionierungs- und Warnkomponenten und übermitteln Systemrückmeldungen wie Erfolgsbestätigungen, Fehlermeldungen oder Statusaktualisierungen. Das Frutjam-Toastsystem unterstützt sechs Platzierungspositionen, ideal für Formularübermittlungen, asynchrone Vorgänge und Echtzeitbenachrichtigungen.

Nur CSS, kein JavaScript erforderlich. WCAG AA zugänglich und Framework-unabhängig: Funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

## Grundlegende Verwendung

<Snippet>

```html
<div role="status" aria-live="polite" class="toast">
  <div class="alert alert-info">
    <span>New message arrived.</span>
  </div>
</div>
```

```jsx
import { useToast } from 'frutjam/react'

export default function ToastDemo() {
  const toast = useToast()
  return (
    <>
      <button className="btn" onClick={() => toast.info('New message arrived.')}>Show Toast</button>
      <div role="status" aria-live="polite" className="toast">
        {toast.toasts.map(t => (
          <div key={t.id} className={`alert${t.type ? ` alert-${t.type}` : ''}`}>
            <span>{t.message}</span>
          </div>
        ))}
      </div>
    </>
  )
}
```

</Snippet>

## Eintrittsanimation

Jeder Toast verblasst und steigt von selbst an seinen Platz. Dazu gibt es nichts hinzuzufügen und keine Klasse, um es zu aktivieren.

Der `toast-slide-*` Modifikatoren sind für den Fall gedacht, dass Sie eine andere Richtung als die Standardanstiegsrichtung wünschen. Wählen Sie die Kante aus, auf der der Toast liegt, sodass er von außerhalb des Bildschirms eindringt und nicht darüber hinweg: `toast-slide-end` gehört dazu `toast-end`, `toast-slide-down` mit `toast-top`.

<Snippet>

```html
<div role="status" aria-live="polite" class="toast toast-top toast-end toast-slide-down">
  <div class="alert alert-info"><span>Drops in from the top</span></div>
</div>
```

</Snippet>

Der Abstand ist die eigene Breite oder Höhe des Toasts, nicht der Abstand zum Rand des Bildschirms. Ein zentrierter Toast beginnt also in der Mitte und nicht außerhalb des Bildschirms.

Es gibt keine Exit-Animation. Ein Toast verschwindet, sobald er von der Seite entfernt wird, da CSS keinen Status hat, aus dem er übergehen kann. Eines auszublenden bedeutet, es im DOM zu belassen und es selbst zu animieren.

Die Animation wird für alle übersprungen, die eine reduzierte Bewegung gewünscht haben.

## Breite

Jeder Toast ist mit einer Obergrenze versehen `24rem` Daher erstreckt sich eine lange Nachricht nicht über den gesamten Telefonbildschirm. Überschreiben `--toast--width` um es zu ändern.

<Snippet view="code">

```html
<div role="status" aria-live="polite" class="toast [--toast--width:32rem]">
  <div class="alert alert-info"><span>A wider toast.</span></div>
</div>
```

</Snippet>
