Botão Tailwind CSS somente CSS com variantes primária, secundária, sotaque, fantasma, contorno e suave. Tamanhos xs-xl, estado de carregamento, desativado e botões de ícone. Somente CSS, WCAG AA, funciona com Django, HTMX, Laravel, React.

Componentes de botão são elementos interativos que acionam ações ou direcionam os usuários para novas páginas. O sistema de botões Frutjam oferece vários tamanhos, cores e estilos por meio de classes modificadoras - todos construídos com a abordagem de utilitário CSS Tailwind para botões leves e altamente personalizáveis ​​​​que funcionam perfeitamente em estruturas e projetos.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.
