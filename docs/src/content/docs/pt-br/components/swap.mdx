Troca de CSS Tailwind somente CSS para alternar entre dois elementos. Inverta, gire e esmaeça animações, sem JavaScript. WCAG AA acessível, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes de troca alternam entre dois estados de conteúdo com animações suaves em resposta à interação do usuário. Construídos com transições semânticas de HTML e CSS, os swaps permitem mudanças de estado elegantes sem JavaScript. O sistema de troca Frutjam oferece suporte a vários estilos de animação – ideal para alternância de temas, alternâncias de modo, estados de carregamento e ilustrações interativas.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.

## Uso Básico

Crie uma troca simples com emoji ou conteúdo de texto usando uma caixa de seleção para alternar estados.

<Snippet>

```html
<label class="swap">
  <input type="checkbox" />
  <div class="swap-on">☀️</div>
  <div class="swap-off">🌙</div>
</label>
```

```jsx
<label className="swap">
  <input type="checkbox" />
  <div className="swap-on">☀️</div>
  <div className="swap-off">🌙</div>
</label>
```

</Snippet>

  <div class="swap-off">Offline</div>

  <div class="swap-on">➕</div>
