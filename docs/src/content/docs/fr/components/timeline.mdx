Chronologie CSS Tailwind uniquement en CSS pour les listes d'événements chronologiques. Disposition verticale avec emplacements pour icônes, contenus et lignes de connecteur. WCAG AA accessible, fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.

Les composants de la chronologie affichent une séquence d'événements, des jalons ou une progression narrative par ordre chronologique. Construites avec du HTML sémantique, les chronologies aident les utilisateurs à comprendre la progression historique et les phases du projet. Le système de chronologie Frutjam prend en charge plusieurs directions, couleurs et styles d'éléments, ce qui est idéal pour l'historique du projet, les notes de version et les cartes de voyage.

CSS uniquement, aucun JavaScript requis. WCAG AA accessible et indépendant du framework – fonctionne avec Django, HTMX, Laravel, React et n'importe quelle pile.
