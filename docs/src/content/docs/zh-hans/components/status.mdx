仅 CSS Tailwind CSS 状态点指示器，具有主要、成功、警告和错误颜色变体。尺寸为 xs-xl。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

状态组件通过可视指示器显示用户、系统或进程的当前状态或可用性。状态徽章采用语义 HTML 和颜色编码样式构建，可传达重要的状态信息。 Frutjam 状态系统支持多种颜色和尺寸，非常适合用户状态、系统运行状况和工作流程状态。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。
