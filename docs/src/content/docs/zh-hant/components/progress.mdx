純 CSS Tailwind CSS 進度條，具有主要、次要、重音和語義顏色變體。尺寸為 xs-xl。 WCAG AA 可訪問，可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。

進度元件可視覺化任務、下載或多步驟流程的完成狀態。進度條採用語意 HTML 進度元素和 Tailwind CSS 樣式構建，可以清楚地向使用者傳達進度。 The Frutjam progress system supports multiple colors, sizes, and animation states for flexible integration into loading screens, forms, and dashboards.

僅 CSS，無需 JavaScript。 WCAG AA 可存取且與框架無關 - 可與 Django、HTMX、Laravel、React 和任何堆疊配合使用。
