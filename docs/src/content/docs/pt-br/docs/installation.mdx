Instale a biblioteca Frutjam UI somente CSS com Tailwind CSS v4, UnoCSS ou nenhuma etapa de construção. Mais de 65 componentes acessíveis, zero JavaScript, WCAG AA. Funciona com Django, HTMX, Laravel, React e qualquer pilha.

## Instalar

<Snippet view="code">

```bash
npm i -D frutjam
```

</Snippet>

Em seguida, escolha a linha abaixo que corresponde à sua configuração. Cada um fornece os mesmos componentes.

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Sua configuração | O que adicionar | Navios |
| --- | --- | --- |
| [Tailwind CSS v4](#tailwind-css-v4) | `@plugin "frutjam";` | só o que você usa |
| [UnoCSS](#unocss) | `presetFrutjam()` | só o que você usa |
| [Vite, Astro, Rails, CSS simples](#no-utility-engine) | `import 'frutjam/css'` | todos os componentes, 30 KB compactados |
| [Nenhuma etapa de construção](#no-build-step) | um `<link>` marcação | todos os componentes |

</DocTable>

## Tailwind CSS v4

Você precisa de um trabalho [CSS do vento favorável](https://tailwindcss.com/docs/installation/using-vite) projeto, mais [Nó](https://nodejs.org/en/download) e npm. Frutjam requer Tailwind 4.

Adicione Frutjam ao seu `input.css` com o `@plugin` diretiva:

<Snippet view="code">

```css
@import "tailwindcss";
@plugin "frutjam";
```

</Snippet>

Essa é toda a configuração. Todos os mais de 65 componentes estão disponíveis imediatamente e o Tailwind envia apenas aqueles que sua marcação usa.

## UnoCSS

O Frutjam vem com uma predefinição, então o UnoCSS gera apenas os componentes que você usa, da mesma forma que o plugin Tailwind.

<Snippet view="code">

```js
// uno.config.js
import { defineConfig, presetWind4 } from 'unocss';
import { presetFrutjam } from 'frutjam/unocss';

export default defineConfig({
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Cada classe funciona como no Tailwind, assim como as variantes:

<Snippet view="code">

```html
<button class="btn btn-error btn-xl">Delete</button>
<button class="md:btn-error">Red from the medium breakpoint up</button>
<div class="hover:card-primary">Fills on hover</div>
```

</Snippet>

Adicionar `presetAttributify()` e o nome do componente se torna um atributo, com cada valor tratado como uma variante dele:

<Snippet view="code">

```html
<button btn="error xl">Delete</button>
<button btn="md:(error xl)">Red and large from the medium breakpoint up</button>
```

</Snippet>

A segunda linha precisa `transformerVariantGroup()` para a sintaxe do colchete. Observe que um atributo como `btn` não é HTML válido, então se você validar sua marcação, use o formulário de classe ou o UnoCSS `un-` prefixo.

### Opções

<DocTable wrapper="overflow-x-auto w-full not-prose" table="table table-md">

| Opção | Padrão | Propósito |
| --- | --- | --- |
| `preflight` | `true` | Emite tokens, reset e temas do Frutjam. Definir como `false` se você já importa `frutjam/css/base` você mesmo. |
| `prefix` | `''` | Corresponde ao plugin Tailwind `prefix`, então `'fj'` te dá `fj-btn` e `fj-btn="error"`. |
| `layer` | `'frutjam'` | A camada em cascata na qual os componentes são emitidos. Ele é classificado abaixo dos utilitários, de modo que um utilitário sempre vence um componente, independentemente da ordem em que as predefinições estão. |

</DocTable>

### O componente de link precisa de uma linha de configuração

Guloseimas UnoCSS `link` como uma variante, para o CSS `:link` pseudoclasse e seus separadores padrão incluem `-`. Então `link-2xl` é lido como "`2xl`, quando não visitado" em vez de um nome de classe, e nada é gerado. Afeta apenas este componente e apenas o `link-*` modificadores.

Diga ao UnoCSS para dividir apenas com dois pontos:

<Snippet view="code">

```js
export default defineConfig({
  separators: [':'],
  presets: [presetWind4(), presetFrutjam()],
});
```

</Snippet>

Ou use um prefixo, que coloca algo diferente de `link` na frente do nome:

<Snippet view="code">

```js
presets: [presetWind4(), presetFrutjam({ prefix: 'fj' })],   // fj-link-2xl
```

</Snippet>

Todos os outros componentes não são afetados. `link` é o único dos 57 cujo nome colide com uma pseudoclasse.

## Nenhum motor utilitário

Frutjam é construído com Tailwind, mas os componentes são compilados em CSS comum que lê propriedades personalizadas. Se o seu projeto não usa nenhum mecanismo utilitário, importe a folha de estilo em vez do plugin:

<Snippet view="code">

```js
import 'frutjam/css';
```

</Snippet>

Essa é toda a configuração. Cada classe de componente funciona, os temas mudam com `data-theme` como de costume, e nada mais é necessário. Ele tem 30 KB compactado e carrega os estilos básicos, ambos os temas e todos os mais de 65 componentes.

Em vez disso, extraia apenas o que você precisa:

<Snippet view="code">

```js
import 'frutjam/css/base';              // tokens and reset, always needed
import 'frutjam/css/components/button';
import 'frutjam/css/components/card';
import 'frutjam/css/themes/darkberry';  // optional
```

</Snippet>

Ou sem nenhuma etapa de construção:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

## Nenhuma etapa de construção

Insira uma tag e comece a escrever a marcação. Use-o para um protótipo ou página que você não constrói, nem para produção, pois ele envia todos os componentes.

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.components.css">
```

</Snippet>

Para experimentar os utilitários do Tailwind na mesma página, adicione a construção do navegador do Tailwind ao lado dele:

<Snippet view="code">

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/frutjam@2/dist/frutjam.min.css">
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```

</Snippet>

## JavaScript e React: opcional, não obrigatório

Frutjam é **nativo primeiro e CSS primeiro**. A grande maioria dos componentes: botões, emblemas, cartões, formulários, alertas e muito mais: funcionam com HTML e CSS puros, sem necessidade de JavaScript. Elementos HTML nativos como `<dialog>`, `<details>`, e `<input type="checkbox">` lidar com a interatividade onde os navegadores já a suportam. Todos os componentes são WCAG AA acessíveis imediatamente e funcionam com Django, HTMX, Laravel, React, Next.js e qualquer pilha.

Um pequeno número de componentes não possui equivalente HTML nativo (notificações do sistema, filtragem de caixa de combinação, controles de carrossel). Apenas para esses casos, a Frutjam envia ajudantes opcionais leves.

### Baunilha JS: `frutjam/js`

Auxiliares de módulo ES independentes de estrutura para os componentes que precisam deles. Anexe a qualquer elemento DOM, sem necessidade de estrutura.

<Snippet view="code">

```js
import { createModal } from 'frutjam/js'

const modal = createModal(document.getElementById('myModal'))
modal.open()   // calls showModal()
modal.close()  // calls close()
modal.toggle()
```

</Snippet>

### Ganchos de reação: `frutjam/react`

Wrappers Thin React em torno das mesmas chamadas DOM nativas. Cada gancho retorna um `ref` você anexa ao elemento e métodos para controlá-lo, sem dependências extras além do próprio React.

<Snippet view="code">

```js
import { useModal } from 'frutjam/react'

export default function App() {
  const modal = useModal()
  return (
    <>
      <button onClick={modal.open}>Open</button>
      <dialog ref={modal.ref} className="modal">...</dialog>
    </>
  )
}
```

</Snippet>

Disponível para: `useModal`, `useDrawer`, `useCollapsible`, `useTooltip`, `useTabs`, `useToast`, `useCarousel`, `useCombobox`.
