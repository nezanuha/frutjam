Insignia CSS de Tailwind solo para CSS con variantes primaria, secundaria, acento, información, éxito, advertencia y error. Estilos suave, de contorno y fantasma, tamaños xs-lg. Accesible a WCAG AA, funciona con Django, HTMX, Laravel, React y cualquier pila.

Los componentes de la insignia son etiquetas pequeñas y compactas que se utilizan para resaltar, categorizar o mostrar información de estado. Creadas con HTML semántico y CSS Tailwind, las insignias admiten múltiples tamaños, colores y estilos para una integración flexible en tablas, tarjetas, perfiles de usuario y sistemas de notificación. Ligeras y accesibles, las insignias mejoran la jerarquía de la información sin añadir desorden visual.

Solo CSS, no se requiere JavaScript. WCAG AA accesible e independiente del marco: funciona con Django, HTMX, Laravel, React y cualquier pila.
