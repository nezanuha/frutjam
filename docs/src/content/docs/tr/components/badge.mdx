Birincil, ikincil, vurgu, bilgi, başarı, uyarı ve hata çeşitlerini içeren, yalnızca CSS'ye özel Tailwind CSS rozeti. Yumuşak, ana hatlı ve hayalet stiller, xs-lg boyutları. WCAG AA'ya erişilebilir; Django, HTMX, Laravel, React ve herhangi bir yığınla çalışır.

Rozet bileşenleri, durum bilgilerini vurgulamak, kategorilere ayırmak veya görüntülemek için kullanılan küçük, kompakt etiketlerdir. Semantik HTML ve Tailwind CSS ile oluşturulan rozetler, tablolara, kartlara, kullanıcı profillerine ve bildirim sistemlerine esnek entegrasyon için birden fazla boyutu, rengi ve stili destekler. Hafif ve erişilebilir rozetler, görsel karmaşa yaratmadan bilgi hiyerarşisini geliştirir.

Yalnızca CSS, JavaScript gerekmez. WCAG AA erişilebilir ve çerçeveden bağımsız — Django, HTMX, Laravel, React ve tüm yığınlarla çalışır.
