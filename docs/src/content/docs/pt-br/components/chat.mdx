Componente de bolha de bate-papo Tailwind CSS somente CSS. Posições inicial e final para mensagens enviadas e recebidas, com slots de avatar e carimbo de data/hora. WCAG AA, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes de bate-papo exibem mensagens de conversação em um formato legível e organizado. Construídos com HTML semântico e layouts flexíveis, os balões de bate-papo representam mensagens do usuário e do sistema. O sistema de bate-papo Frutjam oferece suporte a várias cores, alinhamentos e estilos – ideal para interfaces de mensagens, painéis de suporte ao cliente e interface de conversação.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.
