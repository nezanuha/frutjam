Kotak centang Tailwind CSS khusus CSS dengan varian warna primer, sekunder, aksen, dan semantik. Ukuran XS-XL, keadaan tidak menentu. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen kotak centang memungkinkan pengguna untuk memilih satu atau beberapa opsi dari serangkaian opsi. Dibuat dengan elemen masukan HTML asli dan disempurnakan dengan Tailwind CSS, kotak centang mendukung berbagai ukuran, warna, dan status. Dapat diakses sepenuhnya dengan navigasi keyboard dan dukungan pembaca layar, kotak centang berfungsi dengan lancar dalam formulir, opsi filter, dan antarmuka manajemen izin.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.
