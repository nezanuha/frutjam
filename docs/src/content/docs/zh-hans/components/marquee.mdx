仅 CSS Tailwind CSS 选取框，用于水平滚动内容和徽标。通过 CSS 控制速度和方向，无需 JavaScript。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

Marquee 组件可创建无限、连续滚动的内容条 - 非常适合品牌徽标、公告横幅、感言或标签云。 Frutjam 字幕完全采用 CSS 动画构建，支持水平和垂直方向、悬停暂停、可逆播放和速度控制。复制 `marquee-track` 元素（与 `aria-hidden`）以获得无缝、无间隙的循环。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

| 班级 | 类型 | 描述 |
| --- | --- | --- |
| marquee | <span class="badge badge-xs">根据</span> | 外部容器——剪辑溢出并保存动画变量 |
| marquee-track | <span class="badge badge-xs badge-secondary badge-soft">修饰符</span> | 滚动内行；重复与 `aria-hidden` 无缝循环 |
| marquee-pause | <span class="badge badge-xs badge-secondary badge-soft">修饰符</span> | 悬停时暂停动画 |
| marquee-reverse | <span class="badge badge-xs badge-secondary badge-soft">修饰符</span> | 向相反方向滚动 |
| marquee-vertical | <span class="badge badge-xs badge-secondary badge-soft">修饰符</span> | 从上到下滚动而不是从左到右滚动 |

## 基本用法

添加两个相同的 `marquee-track` 元素 — 第二个（与 `aria-hidden="true"`）在第一个滚出屏幕时填补空白。

<Snippet>

```html
<div class="marquee">
  <div class="marquee-track">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
  <div class="marquee-track" aria-hidden="true">
    <span class="badge badge-soft">Item 1</span>
    <span class="badge badge-soft">Item 2</span>
    <span class="badge badge-soft">Item 3</span>
    <span class="badge badge-soft">Item 4</span>
    <span class="badge badge-soft">Item 5</span>
  </div>
</div>
```

```jsx
const items = ["Item 1", "Item 2", "Item 3", "Item 4", "Item 5"]

export default function MarqueeDemo() {
  return (
    <div className="marquee">
      <div className="marquee-track">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
      <div className="marquee-track" aria-hidden="true">
        {items.map((item) => (
          <span key={item} className="badge badge-soft">{item}</span>
        ))}
      </div>
    </div>
  )
}
```

</Snippet>
