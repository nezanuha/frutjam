Nur CSS Tailwind CSS-Optionsfelder mit primären, sekundären, Akzent- und semantischen Farbvarianten. Größen xs-xl. WCAG AA zugänglich, funktioniert mit Django, HTMX, Laravel, React und jedem Stack.

Mit Optionsfeldkomponenten können Benutzer genau eine Option aus einer Reihe sich gegenseitig ausschließender Optionen auswählen. Mit nativen HTML-Eingabeelementen erstellt und mit Tailwind CSS erweitert, unterstützen Optionsfelder mehrere Größen, Farben und Zustände. Radios sind zugänglich und über die Tastatur navigierbar und eignen sich ideal für die Präferenzauswahl, Filterung und Single-Choice-Formularfragen.

Nur CSS, kein JavaScript erforderlich. WCAG AA zugänglich und Framework-unabhängig – funktioniert mit Django, HTMX, Laravel, React und jedem Stack.
