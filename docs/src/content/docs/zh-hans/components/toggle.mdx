仅 CSS Tailwind CSS 切换开关，具有主要、次要、重音和语义颜色变体。尺寸为 xs-xl。 WCAG AA 可访问，可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

切换组件是二进制开关，允许用户打开和关闭功能或设置。切换使用本机 HTML 复选框输入构建并通过 Tailwind CSS 动画增强，提供了一种直观的方式来控制布尔状态。 Frutjam 切换系统支持多种颜色、尺寸和禁用状态，非常适合设置面板、功能标志和首选项控件。

仅 CSS，无需 JavaScript。 WCAG AA 可访问且与框架无关 - 可与 Django、HTMX、Laravel、React 和任何堆栈配合使用。

## 基本用法

<Snippet>

```html

<input type="checkbox" class="toggle" checked>
```

```jsx
<input type="checkbox" className="toggle">
```
