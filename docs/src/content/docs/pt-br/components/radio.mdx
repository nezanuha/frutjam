Botões de opção Tailwind CSS somente CSS com variantes de cores primárias, secundárias, de destaque e semânticas. Tamanhos xs-xl. WCAG AA acessível, funciona com Django, HTMX, Laravel, React e qualquer pilha.

Os componentes do botão de opção permitem que os usuários selecionem exatamente uma opção em um conjunto de opções mutuamente exclusivas. Construídos com elementos de entrada HTML nativos e aprimorados com Tailwind CSS, os botões de opção suportam vários tamanhos, cores e estados. Acessíveis e navegáveis ​​por teclado, os rádios são ideais para seleção de preferências, filtragem e perguntas de escolha única.

Somente CSS, sem necessidade de JavaScript. WCAG AA acessível e independente de estrutura - funciona com Django, HTMX, Laravel, React e qualquer pilha.
