Avatar Tailwind CSS khusus CSS untuk gambar profil. Ukuran xs-xl, susunan grup, dan indikator status online/offline. WCAG AA dapat diakses, bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

Komponen Avatar menampilkan gambar profil pengguna atau inisial dalam wadah yang ringkas dan dapat disesuaikan. Dibangun dengan properti kustom CSS Frutjam, avatar mewakili pengguna, kontributor, atau anggota tim di seluruh antarmuka Anda. Sistem avatar mendukung gambar dan teks, berbagai ukuran, warna, bentuk, indikator status, cincin, dan pengaturan grup—ideal untuk daftar pengguna, komentar, tampilan tim, bagian profil, dan antarmuka perpesanan.

Hanya CSS, tidak diperlukan JavaScript. WCAG AA dapat diakses dan tidak memiliki kerangka kerja — bekerja dengan Django, HTMX, Laravel, React, dan tumpukan apa pun.

## Penggunaan Dasar

Buat avatar sederhana dengan inisial teks atau warna.

<Snippet>

```html
<div class="avatar">AB</div>
```

```jsx
<div className="avatar">AB</div>
```

</Snippet>

## Avatar dengan Gambar

Menampilkan foto profil pengguna dengan penyesuaian gambar otomatis dan ukuran responsif.

<Snippet>

```html

  <img src="https://cdn.frutjam.com/images/avatar-1.jpg?format=webp&width=32&height=32&face_crop=true" alt="Strawbery" loading="lazy" />
</div>

<div class="avatar avatar-md">
  <img src="https://cdn.frutjam.com/images/avatar-1.jpg?format=webp&width=40&height=40&face_crop=true" alt="Strawbery" loading="lazy" />

<div class="avatar avatar-lg">
```

</Snippet>

## Ukuran Avatar

Gunakan varian ukuran untuk menskalakan avatar dari ekstra kecil (xs) hingga 2x besar (2xl) untuk konteks berbeda.

<Snippet>

```html
<div class="avatar avatar-xs avatar-primary">XS</div>
<div class="avatar avatar-sm avatar-secondary">SM</div>
<div class="avatar avatar-md avatar-accent">MD</div>
<div class="avatar avatar-lg avatar-primary">LG</div>
<div class="avatar avatar-xl avatar-secondary">XL</div>
<div class="avatar avatar-2xl avatar-accent">2XL</div>
```

</Snippet>

</Snippet>

## Bentuk Avatar

Pilih dari bentuk lingkaran (default), bulat, atau persegi agar sesuai dengan sistem desain Anda.

<Snippet>

```html

<div class="avatar avatar-lg avatar-rounded avatar-secondary">◇</div>
<div class="avatar avatar-lg avatar-square avatar-accent">■</div>
```

</Snippet>

Tampilkan inisial pengguna untuk identifikasi cepat dalam daftar, rangkaian komentar, dan bagian tim.

<Snippet>

```html
<div class="avatar avatar-md avatar-secondary">AR</div>
<div class="avatar avatar-lg avatar-accent">MS</div>
<div class="avatar avatar-xl avatar-info">KL</div>
```

</Snippet>

## Avatar dengan Indikator Status

Gabungkan avatar dengan lencana status untuk menunjukkan kehadiran atau ketersediaan pengguna (online, offline, sibuk, pergi).

<Snippet>

```html
<div class="avatar avatar-md avatar-offline avatar-secondary">AR</div>

<div class="avatar avatar-md avatar-busy avatar-accent">MS</div>

<div class="avatar avatar-md avatar-away avatar-info">KL</div>
```

</Snippet>
